## 验收口径（v1.2 起）

- 模拟器 AVD `tmb35`：pixel_7 / API 35 / arm64，1080×2400 @ density 460 ⇒ dpr 2.875、376 CSS px。
- 探针走 CDP：`adb forward tcp:<port> localabstract:webview_devtools_remote_<pid>`，**pid 必须用 `adb shell pidof cn.agentsbin.tumarknote` 现取**（旧 socket 会留着，连错就读到上一进程的页面）。

- ⚠ **模拟器里的 Chrome 上不了网**（自带 WebView 能）：11-12 想在 Chrome 里点一次真下载，先卡首启、`--disable-fre` 跳过首启后仍报 `No internet connection` 并 ANR。下载通道改用 HTTPS 现读字节数＋md5 四道对齐来证，别再往 Chrome 那条路上耗。

三趟各修了什么：

- **1112q — 死票 401 无限重登**。`_dropAuthForRelogin()` 原来只清内存，`App._doLogin()` 头一件事又是从 `localStorage` 读票 ⇒ 同一枚死票原样读回来 ⇒ 又 401 ⇒ 不收敛。补 `Storage.remove('authToken'/'authUserId')`，再加一道游客态闸（`guestMode && !token` 时不许重登）。同一把尺子（同一台 headless Chrome、同一枚伪造死票、同样 6 秒窗口，两棵树只差这五个文件）：修复前重载后 **375 发**（全是 `/api/user/profile`）、进首页 **443 发**（436 发 profile），首页整屏空白（截图 7,082 B）；修复后 **6 发 / 7 发**，首页正常渲染（470,478 B）。留档 `/tmp/rpt-storm-pre1112q{,-index}.json`、`/tmp/rpt-storm-post1112r{,-index}.json`。
- **1112q — 市场返回底栏不回来**。卡片市场是整屏浮层，进去藏底栏、退出没还回来。改在路由切页时统一复位导航条与底栏。六步真点留档 `/tmp/rpt-market-back.json`：`#/market` 那两步底栏 `none`（本该藏），其余四步 `flex`，退出后底栏三格逐个真点都命中自己。
- **1112r — 空态与「点这里重试」被底栏盖住**。`#idx-loading` / `#idx-empty` 原来是滚动区的兄弟节点，落在纸卡最下沿、被固定在 y700–754（z-index 50）的胶囊底栏整块压住。照小程序 `index.wxml:149/151` 把它们搬进 `<scroll-view class="list">` 里头两个孩子的位置，行内容改挂新的 `#idx-groups`。那一句从 `[153,710,70,21]`（`elementFromPoint` 命中的是 `SPAN.tab-icon`）挪到 `[153,361,70,21]`（命中自己），底栏几何一格没动。留档 `/tmp/rpt-empty-geom{,-after}.json`。
- **1112s — 只改注释**。源码里两处注释引的是没留档的风暴读数（「219 发」「487 发」），换成留档里真量到的 375／443 并点名 JSON 文件。`diff` 逐行核过：三个文件除注释与两枚缓存串外零字节改动，`node --check` 通过。上线后死票回归与五屏重扫都重跑：设备上重载 0.9 秒 7 发收敛完、静置到 11.8 秒仍是 7 发，`/v1/auth/guest` 只打 1 次，游客号仍是 246（没多建账号）；五屏 JS 报错 0、坏图 0、文档宽全等于视口宽。留档 `/tmp/rpt-deadticket-shot.json`、`/tmp/rpt-sweep-1112s.json`。
