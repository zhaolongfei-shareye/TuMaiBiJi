## 1. 五件不查就会踩的事实（今天的样子）

### 1.1 稿的底图不是现网截图，是另一家 AI 画的假界面

三条实测证据：
- 稿上左半那行小字是 `Photo · Link · Tivat`。现网字典是 `modePhoto`/`modeUrl`/`modeWrite` = `照片/链接/文字`、en = `Photo/Link/Text`（`miniprogram/utils/i18n.js:446-448`），全仓 grep `Tivat` **0 命中**。那个词是画出来的，不是我们的。
- 稿上导航条是深底白字、标题写 `TumarkNote`；现网 `miniprogram/app.json` 的 window 是 `navigationBarBackgroundColor:#f4f2ec` + `navigationBarTitleText:图麦笔记`。
- 稿上左半没有人物块。现网 10-10 晚拍定、10-11 又明确"首页不撤人"的那三块（左块人物入口 308 见方 + 右两枚计数）在——对照本机实测图 `docs/design/背景图深浅/实测/上浅下暗-首页.png`（22:01 那台）。

⇒ 处置：**稿只当"结构 + 相对比例"的源**。屏上每一句字、每一个色、每一条几何，落码时以现网字典 / `palette.js` / 视口为准。稿上那些英文字在字典里基本都有对应键（见 §4 N12），只有两枚例外。

### 1.2 稿的色是另一套皮，和已拍的两处决定撞

- 稿：面板实心 `#212221`、快门圆 `#DA794A`、主行动条与右滑条是米金渐变 `#CDB797→#A3947C→#9F886C`、两枚小圆钮 `#DEDEDE` 配 `#434247`。
- 现网：快门固定橙 `#E9723D` 配深字 `#2C1204`、提炼 `#C4541F` 配纯白（`miniprogram/utils/palette.js:578` 一带，口径唯一一份在 `docs/规格-创建入口这一条线.md` §6.1；出处是他 10-08 那句「拍照与提炼那两枚固定橙色，不再跟壁纸色阶走」）。
- 现网：四套莫兰迪壁纸（象牙/天青/樱落/雨雾）+ 169 处写死色的统一规范，是 10-04 五轮拍完的（`docs/配色与界面统一方案-四套莫兰迪.md`）。稿上那块深面板**完全不吃壁纸**——首页这一屏等于退出那套体系。

⇒ 这是本版本最大的一处口径变更，列 D2，我不自作主张。

### 1.3 稿上没有底栏那一排，而首页是 tab 页

`app.json` 的 tabBar 是 `custom:true`，三格 新建/笔记/我的（10-01 晚他本人翻案：撤文字、改纯图标 + 同色阶圆底）。组件高 108rpx、下边距 20rpx（`miniprogram/custom-tab-bar/index.wxss:10-13`）。
稿上面板贴到屏幕底（实测内容区下沿 y=1624，面板底 1623），**没给底栏留位置**。列 D3。

### 1.4 稿的三枚圆钮里没有「文字」那一档

现网录入三档 = 拍照 / 链接 / 文字（`create.wxml` 的 `.modes`）。稿第二屏是 大圆 Camera + 两枚小圆 Album / Link，第三屏标签行同样只有这三枚——**文字档没有落点**，而它是已上线的能力（手动粘贴原文，`modeWrite`）。列 D4。按 [[不许悄悄砍需求条目]]，这一条我不替他推。

### 1.5 几何换算（量法写死，免得下一个人再量一遍）

稿 stage 787×1653，实测屏幕内容区 x∈[27,750]、y∈[29,1624] ⇒ 屏幕宽 723 px = 750rpx，**稿上 1 px ≈ 1.037 rpx**（可当 1:1 起算，绝对数落码时按现网视口重算，因为底图是仿的、机身圆角与导航高度都不作准）。

## 2. 与 2.1 怎么隔、怎么回滚

先讲两条平台事实（不是我的判断）：
- **微信小程序线上只有一个版本**，不存在两版并行（同 `docs/方案-2.0大版本.md` §2 开头那条）。
- **体验版只有一条通道**：一个 AppID 只有一个体验版二维码。2.1.9 现在在审核台上（10-12 15:54:08 重提），他两台手机的验收（#25 真机跨端名片、#78 私密真跑补跑）走的就是体验/预览码——**2.2 一旦上传体验版就会顶掉它**。

### 甲 分支 + 独立 worktree + 2.2 只走预览码（建议）

- `git worktree add /Users/zlfmac/Documents/TuMaiBiJi-2.2 -b release/2.2 dd5f23b`
  主目录 `/Users/zlfmac/Documents/TuMaiBiJi` 继续跑 2.1.x，一行不碰。先例：本机已有 `TuMaiBiJi-1.9.30` 这个 worktree 挂着 master。
- **回滚 = 两条命令**：`git worktree remove /Users/zlfmac/Documents/TuMaiBiJi-2.2` + `git branch -D release/2.2`。主目录与现网没有任何 2.2 的痕迹；已出的预览码到期即失效（预览码有时效，约 25 分钟）。
- 版本号段：2.2 分支上 `utils/appInfo.js` 从 `2.2.0` 起跳，不复用 2.1.x 的任何号；预览包文件名带 `-2.2`，与 2.1 的包在屏幕上分得开。现网 2.1.8 / 审核中 2.1.9 / 本机 2.1.14 三个数各归各，不许互推。
- 代价三条（都有出处）：
  1. `docs/工具/跑尺子.sh` 原来把项目路径写死了（`:14` 那句 `cd`、`:27` 那句 `--project`）→ 2.2 的 worktree 用不了现成的真跑自证。**这一条已在 P0 落成**：脚本改成读 `MP_ROOT`（不给值时走的主目录与原来一个字不差，2.1 那条线不受影响）。
     配套实测：静态尺子读的是 `path.resolve(__dirname,'../..')`＝**脚本自己所在的那个工作树**，所以必须跑目标工作树里那一份脚本；全仓 72 把 `验-*.js` 里只有三把出现主目录绝对路径，且都在文件头的用法注释里（`验-分享链路端到端.js:8`、`验-字眼与模板条.js:4`、`验-热启动归因.js:4`），逻辑里没有一处写死。⇒ 反过来说，**假绿路径是真实存在的那一条**：静态尺子量的永远是"脚本自己那棵树"，所以在主目录跑 `docs/工具/跑尺子.sh` 而 IDE 里开着 2.2 的包，判据全绿而屏幕上是另一版。规矩钉一条：**跑哪条线，就用哪条线工作树里的那一份脚本**（`MP_ROOT` 与 `--project` 都从同一个根出来，两者不会分叉）。
  2. 那把脚本每跑一把会 `cli quit` + 重开 IDE（脚本头注释自己写着：僵尸端口只有重开能救）⇒ **两条线不能同时自证，得排队**。
  3. 主目录里 `deploy/`、`docs/design/10-12首页-搜索框版/`、`docs/工具/跑尺子.sh` 之外的若干文件是未跟踪状态（`git status` 现读 342 条，其中 199 条在 `docs/design/`，是另一条会话的活）→ worktree 里**不会**出现。稿只能按绝对路径只读引用。
- 好处：2.1.x 该修还修、该重提还重提，互不污染；稿不满意整条删掉，主目录零残留。

### 乙 就在主目录改，靠 git 分支来回滚

代价：主目录挂着 342 条未提交，任何 checkout 都可能撞上另一条会话的活（10-08 就发生过一次扫进提交）；2.1.x 若这期间要补丁得来回切。**不划算。**

### 丙 另开 AppID 做全新小程序

代价同 2.0 那份 §2 乙（合法域名重配、提审 1–7 天、openid 是唯一键 ⇒ 要建"同一自然人两个身份"的映射、i18n 与判据两套、云开发配额与混元 token 按两个主体算）。这次没这个必要。

**兼容契约三条（照 2.0 那版，仍然成立）**：① 接口字段只增不改不删，老包读新数据不许炸；② 读不懂的东西整条回退，不跳层继续；③ 数据库迁移只加表加列。
本版本按 §3 的排法**后端一行不动**（N7 复用现成的 `GET /api/user/cards`）。
