## 一、投影：34 枚声明，里面有三套墨底

| 分类 | 枚数 |

那是他没点过的视觉决策。

## 三、描边：两种写法并存，而且**不能互相替换**

同一件"卡边"，一种走 `border:`、一种走 `box-shadow: inset 0 0 0 …`：

- `border: var(--w-edge) solid var(--card-edge)` 6 枚（`app.wxss:329`、detail、profile 等）
- `box-shadow: inset 0 0 0 var(--w-edge) var(--card-edge)` 2 枚（me、pwd-sheet）
- 而 `--w-edge`（3rpx）之外还混着写死的 `1rpx`／`2rpx`／`3rpx`／`5rpx`／`10rpx`／`12rpx`——**profile.wxss 同一页里 `--w-edge` 与裸 `2rpx`/`3rpx` 都在用**。

⚠ **这一族我不建议并**：`border` 占盒子的外沿（吃内容区），`inset box-shadow` 不占位。把 8 枚收成一种写法，
等于给其中一半的盒子加减 3rpx 内空间——那是布局改动，不是"统一"。要收得他先给一张目标图。
能纯整理的是：**宽度那一档收成 `--w-edge`** 之前要先逐枚核对写死的数就是 3rpx，不是的（12rpx 那枚是 `--blk-motif` 的边框宽度、
10rpx 是 `--cp-ring` 的环）——那些本来就不是"卡边"，不该进同一枚令牌。

## 四、压在形象图上的白字：一条令牌都没吃，**13 条规则、9 个 α 档**

`.has-bg` 那几块里的纸白全是字面量，实测分布（同一个数在几个文件里各写一份）：

| α | 处数 | 位置 |
|---|---|---|
| **0.96** | 3 | `index.wxss:1104`、`index.wxss:1125`、`me.wxss:60` |
| **0.62** | 3 | `index.wxss:1112`、`index.wxss:1131`、`me.wxss:162` |
| **0.70** | 3 | `create.wxss:1020`、`create.wxss:1104`、`create.wxss:1108` |
| 0.74 | 1 | `me.wxss:146` |
| 0.78 / 0.56 | 各 1（同一块里两档） | `create.wxss:1000` |
| 0.80 | 1 | `index.wxss:1108` |
| 0.86（纯白） | 1 | `index.wxss:1116` |
| 0.18 / 0.36（纯白，压在渐变上） | 1 处三档 | `index.wxss:1125` |

⇒ 台账里那句"三处各写一份"**数少了**：真实形状是 **9 个档、13 条规则、跨 3 个文件**。
其中 0.96／0.62／0.70 这三档各有 3 份抄本——**改一处漏两处**就是这一族的错法。
纯整理（同值并成一枚令牌，一个像素不动）可以先做；**九档之间要不要并档**是视觉决策，归他。

## 五、圆角：89 枚写死，但"能无痛并"的只有 7 处（我先前那句"约 90 处"要更正）

135 枚 `border-radius` 声明里 46 枚吃令牌、89 枚写死。写死值分布：

```
36 × 50%      6 × 18rpx    6 × 2rpx    3 × 14rpx    3 × 20rpx
2 × 1rpx      2 × 0 0 4rpx 4rpx    2 × 3rpx    2 × 26rpx    2 × 55rpx
2 × 40rpx  ＝ --r-card（40rpx），可无痛并      2 × 999rpx  ＝ --r-pill（999rpx），可无痛并
```

- **36 枚 `50%` 不算"写死该并"**：`--r-pill` 是 `999rpx`，与 `50%` 只在正方形上等价，非正方形上一个是椭圆、一个是同半径圆角 ⇒ 并过去必改形状。
- 逐字等于现有令牌的只有 **7 处**（2×40、2×999，另 3 处要逐枚点名再算）。
- ⚠ **就地更正 §8.256 里我写的那句**「约 90 处写死圆角」：数是对的，但它暗示"这 90 处能整理成令牌"——**能无痛并的只有 7 处**，
  其余要么没有对应令牌、要么 `50%` 与 `999rpx` 不等价。那句话下次会被别人当"可以直接扫一遍"的依据，所以留这条更正。
