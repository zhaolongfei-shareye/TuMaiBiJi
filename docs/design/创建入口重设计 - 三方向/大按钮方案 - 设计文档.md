# 创建入口重设计 - 大按钮方案

## 核心问题
之前三版都是"四个平等的小格子"（Canva 式），用户不知道点哪个。

## 用户原话
> "我希望有个整体感的卡片，然后非常简洁，**大按钮默认是拍照**，然后用户可以点击切换，不同的功能。但整体还是在卡片里面。"

## 国际 App 参考：大按钮模式

### 1. iOS 相机
- **模式**：底部巨大圆形快门键（直径≈屏幕宽度 70%）
- **切换**：上方小字切换模式（照片/视频/人像）
- **特征**：一个操作 dominate 整个界面

### 2. Things 3
- **模式**：右下角大红色"Magic Plus"浮动按钮
- **切换**：点击展开新建任务表单
- **特征**：一眼就知道"这个 App 主要是干什么的"

### 3. Vivino
- **模式**：底部大深红色扫描按钮
- **位置**：占导航栏中央位置
- **特征**：饱和色 + 大尺寸 = 强视觉引导

### 4. Planty
- **模式**：醒目黄色"Identify"相机按钮
- **形状**：圆角矩形占满底部
- **特征**：功能名直接写在按钮上

### 5. Google Keep
- **模式**：右下角大彩色"+"浮动按钮
- **交互**：点击直接开始记笔记
- **特征**：浮动在内容之上，不占布局

### 6. Instagram
- **模式**：底部导航栏中间是巨大的相机图标按钮
- **特征**：在 tab bar 里突出一个主操作

## 共同特征
**一个主操作 dominate 整个界面，其他选项退居次要位置（小 dots、小 tabs、或隐藏）。**

## 新方案：三态设计

### 态 1：默认 — 巨大"拍照"按钮 dominate 卡片

```
┌─────────────────────────────┐
│  9:41                    🔋 │
│                             │
│   ┌─────────────────────┐   │
│   │  📷  🖼️  🔗  ✍️    │   │ ← 4 个小 dots 切换模式
│   └─────────────────────┘   │
│                             │
│      ┌─────────────┐        │
│      │             │        │
│      │     📷      │        │ ← 260×260 渐变大圆按钮
│      │             │        │    占卡片 65% 面积
│      │    拍照     │        │
│      │             │        │
│      └─────────────┘        │
│                             │
│   点击切换模式 · 长按直接拍摄  │
└─────────────────────────────┘
```

**关键设计决策：**
- 按钮尺寸：260×260rpx（占卡片 65% 面积）
- 按钮形状：圆形（像 iOS 相机快门）
- 按钮颜色：橙黄→橙红渐变（#F6C445 → #E9723D → #D64545）
- 模式切换：4 个小 dots（52×52rpx）在按钮上方
- 文字：按钮内写"拍照" + "TAP TO CAPTURE"

### 态 2：切换到其他模式 — 按钮变色

每个模式有独特色相：
- **拍照**：橙黄渐变（#F6C445 → #E9723D）
- **写文章**：草绿渐变（#46A863 → #2d8a4e）
- **链接**：宝蓝渐变（#3F52D6 → #2d3a9e）
- **相册**：墨黑渐变（#23252C → #1a1c22）

```
┌─────────────────────────────┐
│  9:41                    🔋 │
│                             │
│   ┌─────────────────────┐   │
│   │  📷  🖼️  🔗  ✍️    │   │ ← 第 4 个 dot 高亮
│   └─────────────────────┘   │
│                             │
│      ┌─────────────┐        │
│      │             │        │
│      │     ✍️      │        │ ← 按钮变成草绿渐变
│      │             │        │
│      │   写文章    │        │
│      │             │        │
│      └─────────────        │
│                             │
│   点击切换模式 · 长按直接开始  │
└─────────────────────────────┘
```

### 态 3：拍照/写完后 — 卡片压低成横条

内容出现在卡片后面，卡片压缩成 128px 高的横条按钮。

```
┌─────────────────────────────┐
│  9:41                    🔋 │
│                             │
│  ┌───────────────────────┐  │
│  │ 📸 刚拍的照片          │  │ ← 内容出现在后面
│  │ 这张照片显示了...      │  │
│  │ 2 分钟前 · 待提炼      │  │
│  └───────────────────────  │
│                             │
│  ┌───────────────────────┐  │
│  │ 📝 草稿笔记            │  │
│  │ 今天学到了...          │  │
│  │ 5 分钟前 · 编辑中      │  │
│  └───────────────────────┘  │
│                             │
│  ┌───────────────────────┐  │
│  │  ✨  提炼生成笔记      │  │ ← 横条按钮（128rpx 高）
│  └───────────────────────┘  │
└─────────────────────────────┘
```

## 与之前方案的核心区别

| 维度 | 之前方案（Canva 式） | 新方案（大按钮式） |
|------|---------------------|-------------------|
| 视觉重心 | 4 个平等的小格子 | 1 个巨大主按钮 |
| 用户认知 | "我该点哪个？" | "默认是拍照，想换就点 dots" |
| 色彩策略 | 四格同色（白/灰） | 每模式独特色相 |
| 参考 App | Canva（工具型） | iOS 相机/Things 3（动作型） |
| 交互逻辑 | 先选模式再操作 | 默认就是主操作，切换是例外 |

---

## 技术对接

### 现有代码结构
- `create.wxml`：`.bar`（128rpx 胶囊）+ `.panel`（700rpx 面板）
- `create.wxss`：`.bar` 纸白 #f2efe9，`.panel` 纯白 #fff
- 状态管理：`active`（write/camera/album/url），`mode`（分离）

### 新方案需要的改动
1. **布局重构**：
   - 收起态：不是 128rpx 胶囊，而是 260×260 大圆按钮 + 4 个小 dots
   - 展开态：不是 700rpx 面板，而是内容区 + 128rpx 横条按钮

2. **色彩系统**：
   - 每个模式有独立渐变色（橙黄/草绿/宝蓝/墨黑）
   - 按钮颜色随 `mode` 动态变化

3. **交互逻辑**：
   - 默认 `mode='camera'`，大按钮显示"拍照"
   - 点击 dots 切换 `mode`，按钮变色变文字
   - 点击大按钮直接执行对应操作（拍照/打开相册/粘贴链接/开始写作）
   - 有内容后，大按钮压缩成横条"提炼生成笔记"
