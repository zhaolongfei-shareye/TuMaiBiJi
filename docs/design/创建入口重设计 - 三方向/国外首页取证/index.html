先说结论：国外首页到底长什么样

  1. 首页第一屏永远是内容本身，不是功能菜单

    55 张里没有一张把"拍照 / 相册 / 链接"这类录入方式当首页主角。第一屏全是笔记列表（Notion、Simplenote、Todoist）、卡片网格（Keep、OneNote、UpNote）、日历（Fantastical、Daylio、Notion Calendar）或阅读队列（Instapaper、Matter、GoodLinks）。

  2. 创建入口只有四个位置，且都带加号语义

    右下 FAB 14 张、顶栏小图标 16 张、右下圆钮或底部药丸 9 张、干脆没有 16 张。没有一家把创建入口做成首页中央的大按钮——大圆快门是相机类 App（抖音、Snapchat）的语法，笔记类不用。

  3. 加号点开后是带字选项面板，不是直接进相机

    最直接的证据是 GoodNotes：点「New」弹出 Create New 面板，Folder / QuickNote / Scan Documents / Study Set / Image / Take Photo 六行，每行图标加文字。这正是"拍照 / 相册 / 链接 / 直接写"四选一的国外主流画法：一个加号扇出一排带字选项。

  4. 文案极少，标题只有一句

    首页标题通常只有 App 名或一句问候：Evernote 的「Good morning, Jamie!」、OneNote 和 Notion 的「Home」、Readwise 的「Inbox」。列表项自己带摘要，不需要第二行解释文字。

  5. 饱和色只给内容和动作，不给背景

    整屏底色几乎全是白或黑。颜色出现在内容卡片上（Keep 的彩色便签、Daylio 的心情色格、Day One 的照片墙）和那一枚加号上（Things 蓝、Daylio 绿、Joplin 紫、Evernote 绿）。没有一家用大色块铺首页背景。

  6. "已捕获待处理"用一张横卡贴在列表上

    Notion Calendar 的「Upcoming in 19 min」卡、Structured 的底部时间轴、Daylio 的按日条目，都是把"已经录进来、还没处理"的东西做成一张横向卡片叠在首页内容之上，而不是把首页换成另一个界面。这对应你要的"提炼生成笔记"横条。

A. 右下浮动加号 FAB 14 张

Things 3、Google Keep、Google Tasks、Daylio、Joplin、Structured、Capacities、Day One、OneNote。一枚饱和色圆钮钉在右下角，全页只有它是彩色实心，语义只有一个：新建。

B. 右下角圆钮 / 底部药丸 9 张

NetNewsWire、Notion、Notion Calendar、Milanote、Day One、Evernote。和 FAB 同源，只是形状换成小圆钮或带字药丸（Evernote 的绿色「+ New」、Day One 的黑色「+ New Journal」）。

C. 顶栏小图标入口 16 张

Anytype、GoodNotes、Journey、Penzu、Readwise Reader、Simplenote、UpNote、Diarium、GoodLinks、Raindrop。加号收进顶栏右侧，和搜索、设置并排，首页把整块面积让给内容。

D. 首页无显式创建入口 16 张

Bear、Obsidian、iA Writer 同类、Instapaper、Matter、Todoist、Amplenote、Fantastical、Heptabase、Microsoft To Do、Standard Notes、Reflectly、Day One 列表态。这一族认为首页只负责"看"，新建要么在别处、要么点列表项就地展开。

方法与剔除清单

  • 来源：美国区 App Store 官方宣传截图（iTunes search API 的 screenshotUrls，尺寸改 1286x0w 取高清），共 60 个国外 App、374 张原图。
  • 判读：先按 App 拼成 63 张对照图逐格目视，剔掉营销大图、功能讲解页、编辑器内页、设置与付费墙，只留"启动后第一眼"的首页；再逐张复核标签。
  • 剔除：Pocket 已于 2025 年停运、商店无此 App；Logseq 为国内团队产品，按"不要国内"剔除；iA Writer 与 Zoho Notebook 的商店图全是营销合成或画板页，没有可用的真首页，整家剔除；TickTick 为国内公司产品，剔除。
  • 呈现方式分三档：整屏截图（无外框，最可信）9 张；营销框内整屏（有大标题但手机屏完整可读）42 张；斜置样机（手机倾斜或被裁，只作辅证）4 张。
