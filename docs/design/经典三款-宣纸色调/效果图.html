经典三款：只换色调，版式一格没动

三张图里的尺寸、圆角、色块位置、编号圆点、码贴纸那套，全部照 poster.js 现在的 planCard / planQuote / planBlock 抄， 唯一变的是"分类蓝"那一档颜色。左边方向 A 是整套都退到纸的深浅里，只留一枚朱印当饱和色； 右边方向 B 是纸底不变、只把那条大色带换成低饱和的黛青。两档都还沿用信笺那枚朱 #9E3B2F，这样四套经典款是一家人。

方向 A · 纯宣色带 = 旧宣纸的深一档，字用墨

方向 B · 宣纸 + 黛青色带换成低饱和黛青，其余同 A

模板名建议（都收在"宣 / 笺"这一族里，和已有的「素宣信笺」连成一套）
经典卡片 → 玉版宣　Jade Paper
金句大字 → 摘句　Verse Slip
撞色块 → 叠翠　Layered Paper
素宣信笺 → 不改　Vertical Letter
「玉版」是宣纸里最细白的那一档，「摘句」是古人挑别人句子成集的旧称，「叠翠」指这张上面一层色、下面一层纸。
