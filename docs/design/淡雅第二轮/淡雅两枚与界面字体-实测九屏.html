已验：三套外观的类名由自动化脚本从 appservice 读回（不是猜的）；九屏全部是模拟器渲染后截的； 切完最后一步把两份本机偏好放回默认，并补截了一屏确认回到原样。 色板侧另有一把尺子 docs/工具/验-色板零回归.js，30 条断言全过， 其中一条是拿 git show HEAD 那份 palette.js 和新那份跑同一批输入逐字节比，证明现有六枚一个色都没变。

还没验的三件事：① 真机上安卓命不中 STSong / Kaiti SC，会回落到系统黑体，这一条只能他手机上看； ② 这三档字体下的字重（宋体 700 不合成重粗，上一轮已实测），现在按现状字重原样发出去，标题会比苹方轻一档； ③ 淡雅两枚下"未分类"那一块深褐/深绿与卡底的对比度，截图里看着够，但没跑过对比度脚本。
