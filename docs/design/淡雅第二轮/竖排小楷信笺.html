变体三 · 乌丝栏加题签栏线从朱退成墨灰，分类做成右上那条黑底竖题签（这块色就是首页方块那个分类色，认颜色的逻辑不断），底部一条横栏收尾：名字、印章、二维码并排。三版里最耐看、又最全的一版
这三张要落地的话，动的是引擎哪一块（先说清楚，免得拍完板才发现坑）
① 现在的海报引擎是"图层清单 + 通用落笔器"，文字原语只会横着写：一个 text 层、一次 fillText、按 measureText 量宽再换行。竖排要新加一个原语（逐字沿 Y 轴落笔、自己算列高、列满换到左边一列、标点要旋转或换形），这是这一轮真正的开发量，不是改改坐标。
② 效果图这三张是浏览器用 CSS 画的，不等于 canvas 能画成一模一样：字距、栏宽、印章那层做旧的混合模式，落到 canvas 都要重写一遍再逐张对图。所以定了方向之后我还要用真引擎渲一张给你对，不能拿这三张当成品。
③ 字体：系统里没有"小楷"，只有楷体（上一轮实测 Kaiti SC / STKaiti 在模拟器命中）。要真"小楷"必须下发字体文件，几 MB 起、走 https、主包上限 2M——这条最贵，建议先用楷体。
④ 竖排 + 二维码 + 印章凑在一起，安卓上楷体基本命不中，会回落成系统黑体：那时竖排还在、气质会掉一截。要不要给安卓单独退一条（比如退成横排），是另一个决定。
⑤ 上一轮那三套（素纸/书眉/留白）你说布局差异不大，我同意：它们只差在线条和居中方式。这一轮如果只留一套竖排，建议把"留白"那套撤掉，由变体二顶替它的位置。
