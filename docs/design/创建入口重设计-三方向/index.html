创建入口重设计 · 三方向

每列上方 = 收起态（首页那一条） · 下方 = 展开态（点进去那屏） · 示意非终稿

A · 圆点胶囊 + 色浸面板

收起：胶囊里三枚大圆各带两字标签。展开：选中那枚颜色"浸"满面板顶部并渐淡到白底。参考 iOS 26 action circles。

B · 四枚色胶囊横排

取消单条胶囊概念，直接铺四枚高饱和色块（拍/图/链/写），每枚自带图标+文字。展开后选中那枚变成面板顶部色条。参考 Things 3 / Raycast。

C · 圆角方块组 + 毛玻璃

取消胶囊概念，4 枚 12px 圆角方块（squircle）配极短标签。展开后选中那枚微放大，面板用白色高透明度浮层（类似 iOS 26 玻璃质感）。参考 iOS 26 / Arc。

三方向均使用现有色板 TONES（芥末黄/宝蓝/橙/草绿），不新增色。关键差异在：收起态的形态（胶囊 vs 横排 vs 方块组）和展开态与横条的关联方式（色浸 vs 同色药丸 vs 微放大）。
