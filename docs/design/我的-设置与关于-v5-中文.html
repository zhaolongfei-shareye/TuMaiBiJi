④ 打开私密笔记时（探测到生物解锁才长这样） 指纹优先、旁边一行退到密码。凭证还是服务端那条 15 分钟短命 JWT，只存内存不落 storage， 杀了重进照样要解锁，所以开指纹不会让"手机在别人手里翻不开"这句承诺变弱。
这一版按什么标准收的，六条，每条都有出处：
① 小字对比度。现网右值和组标题用的 --text-tertiary #9A9EA6，压白卡实测 2.69:1、压页面底 2.40:1；这两处是 24/20rpx（≈12px / 10px）常规字重，WCAG 要求 4.5:1，不合格。这一版全改 --text-secondary #5C6068，实测 6.31 / 5.64。这不是这一屏的事——列表页、详情页、关于页的右值今天都用着这一档，属于全站要一起判的一条。
② 颜色只在有语义时出现。只有「卡片模板」「外观」两枚块上色，值取自代码里的真实常量：模板纸色 PAPER_A #E4DCC7（poster.js）、当前壁纸那套的 --accent #1B2A21（app.wxss .theme-tint-celadon）。块上的母题颜色也跟着用该色自己的 ink——palette.js 里 TONES 每档都自带 ink（芥末黄配白字实测只有 1.63:1，所以它配 #2A2005），这件事色板早就回答过了，我不另判。
③ 层级要有对比。v4 九行全挂副标，等于每行都强调、结果谁都没被强调。这一版只给"第一次见会问这是什么"的四行副标，其余行干净。
④ 对齐。组标题左沿从卡片 padding 挪到跟色块左沿同一根 x；右侧箭头统一占位宽，没箭头的行留同宽空位，右边缘那根线才齐。
⑤ 行高写死两档。无副标 104rpx、有副标 128rpx，都在 88rpx 最小触控之上；不再靠 padding 撑出第三种高度。
⑥ 补空态。新用户那一屏画了（第②屏）：空值如实写"未设置 / 0 个 / 未设"，状态点在没开的时候是灰圈不是绿点，「解锁方式」整行不出现。

还有一处我没自己做主：上一轮你说"不要加 ICON"，这一轮要"图文结合"。我按不引任何图标资源处理——用系统里已有的色块 + 母题当图，跟放大镜、把手、海报母题一样全是 CSS 画的。如果你想更活泼，只要一句"中性块换成色板轮换"，那一版每行都会有颜色，但语义就没这么干净了。
