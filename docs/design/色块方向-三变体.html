V3 彩底白卡

最贴你给的第一张参考图：整页一个高饱和底色，白色大圆角卡浮在上面，色块缩成 52px 的小图标位。
一屏 5 条，最"透气"，但彩色从"每条不同"退成"整页一色"，分类识别变弱。

抽象元素怎么生成（确定性，不随机）：输入是笔记本来就有的字段——分类 id 决定色相，笔记 id 取模决定用哪个母题（圆 / 弧 / 条带 / 点阵 / 半药丸）和它的位置大小，标签数决定要不要再叠一层。所以同一条笔记永远画成同一个样子，同分类色相一致但构图不重样。全部用 view + border-radius + linear-gradient 画，列表里零性能开销，也不产生任何文件。

一个必须先说的限制：参考图里的圆润感有一半来自字体本身（那是圆体几何无衬线）。小程序默认可靠的只有苹方，它偏中性、不圆。要真拿到那种圆胖字形，得自己托管一个中文字体文件走 wx.loadFontFace——中文全量字体动辄几 MB，得裁子集、要算首屏加载。不加载的话，圆润感只能靠"特粗字重 + 收字距 + 放大字号"近似，也就是效果图里现在这样。这条会明显影响最终像不像，你决定要不要为它付这个成本。
