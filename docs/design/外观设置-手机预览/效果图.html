外观设置 · 手机预览 + 压缩壁纸条

同一个设计的两个状态。左边是刚进页，右边是点了「天青」在试看、还没换。
这一屏改了什么。原来八枚壁纸是两列大卡，一屏放不下要滚到底；现在上面给一部手机预览，下面压成一条横滑的"色块 + 两字名"，八枚一屏收完。
怎么点。点条子上任意一枚 → 只换上面手机里的画面，这一页本身不动；觉得对了 → 点一下那部手机，才真的换上（导航条、tab 栏一起变）。点错不用回退，再点一枚就行。
条子进来先滚到"在用的那枚"。不然米白那套排在最左、在用的象牙在最右，进来只看得见前五枚，会以为没存上。
名字收成两个字。「米白一色」改叫象牙，「雨过青」改叫天青——都是釉色本名，和海报那三套（玉版宣 / 摘句 / 叠翠）一个路子。PRD 和官网交接文档里的旧名要一起改。
「整套色阶」那个角标没了，是换地方说。象牙 / 天青这两枚连左侧方块一起换色，在手机预览里直接看得见（方块深浅跟着变），不必再挂角标解释；上面那行说明留着。
