这一版不再从外面的 App 搬画风。图麦笔记自己已经有一套图文语言：左块右文 + 描边卡（投影已退役）+ 五个抽象母题 + 一套带语义的分类色——首页、列表、详情、新建四屏全在说这套话，只有「我的」这一屏没说：一张 logo 位图加清一色文字行。它看着"乱、不搭"的技术原因就在这儿。下面三个方向都是让这一屏回去说这套话，差别只在图给多少。共同的改动已经定死：LOGO 和名称固定在头部、设置 / 关于 是第二层、大卡片和实心大按钮撤掉、分享在关于最后、额度在分享下面。

关于这一栏（甲乙丙共用，不随方向变） 分享和额度就是两行普通行，跟上面一模一样；两行都不给箭头——一个弹原生面板、一个只能看。 原来那行「关于图麦笔记」整行撤掉，它的三块内容提到这一栏来。
右侧那三种写法就是"交互清晰"的全部规则，三屏共用：
名字 + 箭头 ›点了进入另一个页面（卡片模板 / 外观 / 分类 / 私密 / 介绍 / 功能 / 隐私）
名字 + 灰值，无箭头点了不换页，只是复制（反馈 / 官网）或弹系统面板（分享好友）
名字 + 绿点 + 已设这是一项状态，不是一次跳转；状态点只用在"开没开"这类二元上
名字下面那行小字只回答"点进去会动什么"，不复述名字（这条是上一版说明太啰嗦的教训）

一处冲突我按现有系统判了，你可以推翻：你上一轮说过"不要加 ICON"，这一轮要"图文结合"。 我的处理是不引任何图标资源（这项目从不为一个符号引图片，放大镜、把手、母题全是 CSS 画的）， 用系统里已有的色块 + 母题当"图"。所以甲乙丙三版都不含 icon 位图。
