分类名文字色明 / 暗两套值

分类取模关系不动（产品 id 4→紫、技术 1→蓝、阅读 3→绿、工作 2→橙、灵感 5→黄、未分类→墨），只把"面"那一档换成"字"那一档。括号里是压在实际卡底上的对比度，小字要求 4.5。

新建 笔记 我的
行卡结构标题两行（31/800/1.30）→ 摘要一行（28/400/1.40，无则整行不占位）→ meta 一行：分类名（分类色 · 700）· 来源（次级）· 标签（三级）· 日期（三级，右端对齐成一列）。左侧 176rpx 色块整块取消，行末那个 › 也撤了——一行只能有一个右端对齐的东西，它和日期会打架。卡与卡 10、节与节 18、卡内 20/30/16、描边 3、圆角 40，五个数沿用现网令牌。
分组就是设计语言按日期分节：节标题 21/700 三级灰 + 一条拖到行尾的细线 + 篇数。节距 18 大于卡距 10，分组完全靠留白，不靠底色、不靠分隔卡。筛选后只剩两条也照样分节，不因为结果少就改版式。空列表也不放图形：一条 64 的细线 + 两行字，文艺全来自留白和字号，不来自插画。
颜色只剩两处分类名那几个字（明暗两套值见③屏表格：浅色档 5.06~15.3 压白卡，深色档 7.49~12.0 压 #181828）、日期与分隔符的三级灰。深色那屏六个分类：薰衣草紫 / 青蓝 / 草绿 / 橙 / 黄 / 无彩，逐档读得清、互相分得开。最险的一对是灵感黄与工作橙，色相差只剩 20°，靠把橙压暗一档换到 1.43 的相对亮度差兜住；同一套深色档压深海卡（约 #192634）还有 6.5~9.4，两套深色壁纸共用一档、不再分叉。筛选胶囊的选中态只填墨、不上分类色：那排一旦着色，整屏颜色就又回来了。
字体：不挂包界面全部走系统黑体（苹方链），一处没用 font-family 去命中衬线——这个 webview 只认 @font-face，上一版"可选字体"因此已撤，本稿也不提议重新挂。真要为"书脊感"上宋体，代价是主包 2MB 上限里塞进 900KB~1.5MB 中文字子集，我不建议；文艺感改由字号差、字重差、行高与那一条分节细线来做。
额度（现网位置照画）笔记额度12/100这一行在「我的」页，只能看不能点，数字全来自接口。列表页不自带额度，本稿也不给它新加位置。
这一版牺牲了什么① 分类涨到七八支时纯文字色第一个撑不住：黄/橙现在只剩 20° 色相差，再加两支必撞车。② 母题图形（圆/弧/条带/点阵/药丸）随色块一起退场，同分类不再"每条构图不同"，屏上差异度下降。③ 第一个标签从色块上的 32rpx 大字降级进 meta 第三档，弱了一档。④ 未分类在深色下用字色本体，反而比五支彩色更显眼。⑤ 色觉障碍用户的兜底只剩一条：分类名本来就是汉字，颜色是加速器不是唯一编码——代价是扫读速度回到"逐条读字"。
