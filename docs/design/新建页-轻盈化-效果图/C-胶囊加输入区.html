从打开到存下一条：四步压成两步

现状 4 步选方式 → 展开 → 填 → 存
新版 2 步填 → 存
  • 「选择一种方式」这行大标题整行删掉：它把一次决策塞在用户动手之前。胶囊不给标题，直接贴着输入区。
  • 默认胶囊 = 撰写（三种方式里唯一"打开就能写"的一个），光标已经在标题行上；不碰胶囊也能一路存到底。
  • 点胶囊只换输入区那张脸，块的位置、大小、边缘全不动——它读起来是"同一张纸的模式开关"，不是"再选一次"。
  • 防误读三招：选中胶囊下面一个小三角指向这块地；卡片顶边渗同一支饱和色；保存按钮跟着换色。胶囊高度只有旧卡片的一半。
  • 胶囊这一排在 750rpx 上三枚正好放下、不需要横滑；只有换到更窄的机型才滚，滚动条不画。真机留 scroll-view scroll-x 兜底。

这版必须砍掉 / 让步的地方

  • 三块大色块缩成三枚小方块，首屏的"色块冲击"变弱：饱和色只留在选中的胶囊、卡片顶边那道 8px、保存按钮这三处。
  • 「取消」从大按钮降级成小描边圈——它只是清草稿，不值得和保存同权重。
  • 分类只在撰写那一格里出现（沿用现有那个 selector，一个入口）。链接 / 截图本来就没有分类输入，提炼出的标签在详情页改，这一版不在这里加口子。
  • 9 张图用 aspect-ratio 三列等分，小屏上格子会自动变小，不给它横滑（横滑会藏图，藏掉的看不见也点不到）；满 9 张时「加图」自己消失，计数换成「9 / 9 已满」。
  • 「中 / EN」从大标题右侧退到页脚最右，缩成一行 20rpx 灰字。英文半成品不外露，但入口不删。

异常文案照抄现网，一条不改

链接可用 · 保存后自动提炼
!
链接要以 http:// 或 https:// 开头
  • 链接校验失败：输入框下方那行绿点变红点（上面第二条），保存同时压成不可点，不用弹窗。
  • 撰写标题为空被拦：同一位置 写个标题再保存（红字，不做 toast）。
  • 提炼不可用：照存 + 标完成，不报错——所以稿子里没有"失败"这一态，只有 已存入笔记。
  • 没相机 / 相册权限：在「拍照 / 相册」那两枚下面顶出 没拿到相机权限，点这里去设置。
  • 没选图就点提炼：先选一张截图再开始。

字体口径（别拿这张稿当"已换字体"）

  • 全稿仍用界面现在那套系统栈。小程序 webview 只认 @font-face 挂进来的字体，上一版"可选字体"因此整批撤了，这里不再画第二张饼。
  • 文艺感全靠不吃字体的四件事：横线纸感 + 留白、印章「麦」、竖排一行小字、饱和色块；这三样在 CSS 里即刻可落。
  • 真想要衬线观感（印章/竖排那两处最见效）要挂字体包，有包体代价：主包 2MB 上限，一个中文衬线子集包 300～800KB 起，得先决定砍哪几页共用。
  • 顶部标题条「新建」是微信原生画的，页面 CSS 改不动它；tab 栏是自定义组件，颜色要在那份 wxss 里写死。
