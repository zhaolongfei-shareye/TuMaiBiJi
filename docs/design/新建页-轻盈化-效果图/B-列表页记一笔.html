另外两条也照抄现网，一次点击都没多：链接 4 步 → 4 步（切 tab / 选卡 / 粘贴 / 保存 = 印章 / 贴纸 / 粘贴 / 盖下）， 图 5 步 → 5 步。省下的不是数字，是三样东西：①「选一种方式」那一整屏消失，②整页切换和随之而来的白一下消失，③存完的落点从"回列表找"变成"就在眼前排在最上面"。 若再加一条"薄纸记住你上次用的是哪枚"（本机偏好，不算新能力），链接那条第二次起就是 3 步——这条要不要做由你定。

留下的文艺母题，一个没丢

纸 / 墨 / 一枚印章 / 饱和色块 / 竖排，全部纯 CSS，一处都没依赖字体包。
印

印章 = 全页唯一的强调。圆角方石 + 里圈一道发丝白环 + 一个字（记 / 存），转歪 2.5° 像真盖的；底下衬一圈米白光晕把它从卡片上"抬"起来。只有它带浮影，眼睛一定先找到它。

纸

薄纸不是弹窗。底色 #FFFDF8 比卡片更纸一点，铺两层极淡的经纬纤维；顶边一排邮票齿孔（和印章是一对），页脚一条虚线撕口把"存"这一行分出来。遮罩只盖 webview，导航条不跟着变暗。

竖

竖排小字。纸左沟槽里一条竖排眉标「薄纸一张 · 盖下即存」+ 一根发丝竖线，只吃 60px 留白、不占正文。writing-mode 是排版不是字体，一定命中。

块

左块右文照旧。176 见方的饱和块 + 块里的分类名 + 白底描边卡 + 那条饱和蓝搜索横线，一个值都没改。录入换了地方，产品还是那个产品。

字体这条要说死：这一稿没有靠 font-family 命中系统字体

机身里所有字都按现网默认苹方画（和真机一致）。有两处如果要衬线/宋体观感——印章里那个「记 / 存」、以及「我的笔记」这个大标题——必须挂字体包：wx.loadFontFace 或 @font-face，中文 subset 实测 1.5~2.5MB，要自己托管并加下载域名白名单，包体和首屏下载都得算进来。上一版"可选字体"就是因为这个整体撤掉的。我的建议：界面不挂，只给分享海报那类模板挂一套 subset 宋体——海报是一次性出图、不承担交互，文艺感放那儿最划算。

必须砍掉 / 让步的地方

这一版换走的是"单独一屏选择"，代价也得一次摊开。
1

「新建」tab 删掉，不留两头。tabBar 只剩「笔记 / 我的」两枚（微信允许 2~5 枚，居中不空），pages/create/create 整页撤掉——tab 也留、印章也留等于把复杂度留在原地。原来挂在「新建」页标题右侧那枚「中 / EN」语言切换跟着搬进「我的」第一组；这一版界面只露中文，所以稿子里不出现它。

2

薄纸上不放开"要点 / 标签 / 长正文"。纸上只有标题一条线 + 正文一袋（500 字上限照旧）+ 分类一排。几百字的长文、以及链接图那条提炼出来的要点标签，仍走详情 → 编辑那一条路（现网 pages/write 已经只服务编辑，入口不变、不新增）。长文在纸里写会憋，这是"轻"的价钱。

3

键盘和薄纸的规矩写死。输入框 adjust-position=false，纸监听 wx.onKeyboardHeightChange 后整张纸上抬（纸高固定 640 不变）：键盘 500 → 纸顶落在 484，遮罩上面还剩 308 px 的列表头，看得见"我在往哪本里记"。低端机上只做一次 220ms 的 transform，不做逐帧跟随，否则每敲一个字抖一次。选完图回本页时纸要留在原地——现网那个"onShow 冲掉草稿"的坑必须一起防住。

4

首屏变了，空状态要接住。新用户打开不再看到三张大色块，而是空列表 + 一枚印。空状态那句改成「点右下角那枚印，记下第一条」，配新手期那圈虚线（盖一次永久消失）。这条不做，"看不见入口"会变成新的第一投诉。

5

额度 23/100 是只读复用，不是第二个入口。它仍然只在「我的」里管，纸上这一行只是盖之前看一眼，数字同一份 /api/user/quota。额度用满时纸不掀：点印章直接给现网那句拦截提示，别让人写完 200 字才告"存不下"。

6

存的动作没有独立按钮了。好处是少一个控件，代价是"点在纸上哪都是存"这个误解会出现一次——所以新手期纸右下角要挂一句「盖一下就存好」（图②那条虚线），并且纸上的 ✕ / 收起永远在右上、和印章对角，不会误收。标题为空时盖下去只顶出那句原文「写个标题再保存」。

7

不新增任何东西。没有协作、没有 AI 对话入口、没有语音、没有标签云、没有积分商城。保留的既有入口只有：搜索、分类筛选、外观设置（壁纸）、卡片模板（分享形象）、关于、额度。

本图为纯 CSS 画的示意稿，不是真机截图——每部手机 750 × 1624（px 当 rpx 用），屏上那三条斜打的「示意 · 非真机截图」就是水印。 稿内所有图形（状态栏、胶囊、色块母题、三枚贴纸、齿孔、印章、键盘、缩略图）都是 CSS 形状与 Unicode 字符，零外部资源、零 <img>、零网络请求。 顶部导航条是微信原生画的，页面 CSS 管不到它，所以只画成朴素系统样式、不放设计重点。
