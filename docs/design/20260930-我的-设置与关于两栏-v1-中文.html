三条要你点的判断，我按推荐写在了图上，不认可直接说哪一条：
一、「笔记额度」算设置还是关于。按你给的定义它是"只能查看"，该去关于；但它是你这个账号的状态，不是这个产品的信息， 放进关于会被埋在版本号旁边找不到。我放在设置的「账号」组、跟分享并排。
二、组标题要不要。加了就能一眼看出分界，代价是列表多三行小字。你要"轻盈"，我压到 --fs-label 20 + 最淡那档灰， 比正文小两档、不抢。不要的话整块撤，只留两个 tab 也成立。
三、「介绍 / 功能 / 隐私」提到这一栏以后，还要不要保留那个独立的关于页。 图上按"保留"画的（点这三行还是进那一页，只是直接落在对应那一栏），这样功能面零改动。 要更彻底就把那一页的内容直接摊在这一栏里，页面撤掉——那是结构改动，得你点头我才动。
