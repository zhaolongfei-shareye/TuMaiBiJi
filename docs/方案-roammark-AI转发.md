# 方案与规格：RoamMark 景点初稿转发（一根管道，key 不进包）

落码日期 2026-10-25。这一份写的是**现在长什么样**，不是计划；没做的格子全在最后一节。

落在**图麦笔记**后端 `TuMaiBiJi/backend`，两个口：`POST /api/roammark/spot-draft`、`GET /api/roammark/health`。
文件三处：`app/api/routes/roammark.py`（门与形状）、`app/services/spot_draft.py`（管道本身）、
`app/core/config.py` 里新增那一组 `DEEPSEEK_*` ＋ `ROAMMARK_APP_GATE`。

⚠ **今天现网还没有这一组口**：这一趟只落码、只上本地，没有部署（站长没点头，且现网 `.env` 里
还没有 `ROAMMARK_APP_GATE` 那一行——就算误上了，两个口也一律 503）。

## 二、现在长什么样（口径）

- **收图走 JSON＋base64，一口都不吃 `multipart`**。`File(...)` 底层是 Starlette 的 `UploadFile`，
  超过 1 MiB 的那部分会**临时写到服务器磁盘**再删——我们的口径是"照片只在用户手机上"，
  所以宁可自己读体：换来两条承诺得住的东西，边读边数字节、超限立刻回，以及图一个字节都不碰磁盘。
  iOS 侧就是 `Data.base64EncodedString()`，没有额外成本。
- **请求体形状**：`{"images": [base64…], "lang": "en", "captured_at": ["2026-10-25T10:09"], "place_hint": "...", "lat": 35.0, "lon": 135.7}`。
  后四样都可省；`captured_at` 收数组也收它的 JSON 字符串形状，只认 ISO 那一型正则，别的整条丢掉。
- **回体只有七键**：`spot` / `where` / `draft` / `provider` / `model` / `usage` / `took_ms`。
  键名单被用例钉住——多一个键就红，所以"顺手把图带回去"这种坏法当场拦住。
- **错误形状是第三种口径**：`{"code": …, "detail": …}`，`detail` 是**英文**。
  `/api/*` 回一句中文、`/v1/*` 回中文加四个 code，这一路回英文：RoamMark 面向全球、界面是英文的。
  `tests/test_error_text_language.py` 两把尺子分开钉——对本文件放行中文产品那条纪律，
  同时要求这一文件的 `detail` 必须真是英文；哪一天串线，红的是尺子，不是用户的屏。
  code 八枚：`not_configured`／`unauthorized`／`busy`／`bad_request`／`too_large`／`upstream`／
  `upstream_timeout`／`rate_limited`（客户端按 code 分支，`detail` 只做兜底文案）。
  后两枚是 10-25 审计补的，各修一处"这一路唯一的例外"：`upstream_timeout` 之前 httpx 的连接与超时异常
  一条都没接、冒成 500 且无 code（B1）；`rate_limited` 之前 429 只有**我们自己的 `_fail()`** 那一条遵守
  这句契约，限流器那一条回的是中文且没有 code（B2）——它由 `core/rate_limit.py` 里按
  `/api/roammark/` 前缀分出来，**没有**动 `error_codes.attach()`（那句"`/api/*` 一个字都不许多"
  由 `tests/test_v1_error_codes.py` 逐格钉着，现网小程序全在读 `/api/*`）。
  ⚠ 同一发 429 今天有两个名字：取不到在飞位是我们说的 `busy`，敲得太快是限流器说的 `rate_limited`。
  两句话在用户屏上必须分开（"服务器忙"与"你按太快"责任不同），客户端也就分支成两条。
- **钥的读法只有一处**：`current_key()` = 库里那一行 `DEEPSEEK` 优先，删掉回落到 `settings.DEEPSEEK`。
  现网 `.env` 里那行 `DEEPSEEK_API_KEY`（10-25 现读：长度 24、是个占位符；指纹不写进仓）**这一路不吃**——
  吃两个名字就会有两处真相，后台那句"删掉这一行会回到哪一层"也就没法说对。
  过 `key_usable()`：占位符一律当"没配"，回 503 说人话，不打出去挨一次 401 再猜为什么。
- **状态码分得很细，因为责任不同**：`NotConfigured`→503（服务器没开门，不是用户送错了东西）、
  `UserError`→400、字节超了→413、在飞位取不到→429（`busy`）、敲得太快→429（`rate_limited`）、
  上游非 200→502、**上游没在 90 秒内回话→504**。最后这一格单开是因为它对用户的句子不一样，
  而且那一发**钱可能已经算了**——服务端不扣客户端那道每日闸，但日志留了用时给站长对账。

## 三、四条锚点（缺一条这一组口就不能开）

1. **不留、不存、不回放图片。** 回体里没有图的一个字节、库里一行都不写（`db.add`／`SessionLocal()`
   在本路两文件里被用例当禁词扫）、日志只打计数与形状。这条不是合规姿态，是体积：
   10-25 实测一次 9 图请求体 **6.27 MiB**，而 DeepSeek 那侧 48 MiB 上限的**拦法是直接切 TLS 连接**
   （`SSLEOFError`、没有 HTTP 状态码）——不在门口按字节拒，用户手机上留下的就只有"网络异常"。
2. **一根管道不许变成一扇门。** 这是无账号、匿名可调的 AI 出口，别人拿它刷就是刷站长的钱。三道闸：
   来源 IP 限流（10/分钟）＋**同时只放三发在飞**＋包头那枚 App 常量。
   ⚠ `ROAMMARK_APP_GATE` **不是密钥**：它编在包里，逆向我就能拿到，它只把"随手 curl 刷"抬到
   "得先从包里扒出这一串"。真兜底是前两道闸＋客户端那道本机每日闸（已拍＝5 条/天，见 §八）。**别拿它当凭据轮换。**
3. **闸在解析与读体之前。** 顺序是：门闩 → 取在飞位 → 流式读体数字节 → 校字节 → 打上游。
   取不到位直接 429、**不排队**：第 4 发不该为了"发现自己要被判 429"而先上传几十 MB；
   排队会让用户等到看不见的时间，不如立刻告诉他稍后再试。
4. **屏上的句子不许泄露服务器形状。** 503 那句是 `AI drafting is not available right now.`，
   不提后台那一栏叫什么；给站长的提示走 `logger.error`。401 不区分"没带头"与"头不对"，
   也不告诉对方"差一点了"。`/health` 只回布尔值与配置数，不含凭据的任何形状。

## 四、为什么这一枚口长在图麦笔记后端（记下来的取舍）

站长拍的是"密钥配置放图麦笔记后台、我自己去加"——**钥只有一处正身**这一条，决定了转发必须和
`service_secrets` 那张表住同一棵树。RoamMark 与图麦笔记是两条产品，所以代价是：这台机器上多了一个
匿名 AI 出口，而它的邻居是现网的登录与笔记链路。

三条隔开：三发在飞的舱壁（单发实测 **19.6 秒**，档位取 3 时已经把本服务默认的连接/线程占位压满）、
来源 IP 限流、以及口令没配时整组 503（现网今天就是这个状态）。
⚠ 舱壁那个计数是**单进程**的整数（现网 uvicorn 单进程那两个 unit）；哪天改成多 worker，
这一闸会变成"每个 worker 各 3 发"——那时候换 redis，别用内存数自欺。

**什么时候该拆出去**：RoamMark 真开始有量（免费档放开、日发数上到三位数），或者这台机器
已经因为这条链排过队。到那天拆的是路由那一层，`spot_draft.py` 跟着钥走还是跟着 RoamMark 走要重新拍一次。

## 五、提示词口径（改这里必须连着改解析）

- 协议三行是解析器的锚，只有这一个出处：`SPOT | 地标` / `WHERE | 城市 国家` / 空行 / 1–2 段第一人称正文。
- 硬约束写进提示词：**不许编日期**（只准用带过去的 EXIF 拍摄时间，没有就说不确定）、
  **画面没证据的话不许说**、认不出地标就明说认不出，**不许猜名胜**。
- 坐标是**辅助线索不是判据**：§六第 1 条实测境外地名反查三条路全回空，所以那句写的是
  `device GPS; may be off — trust the picture`。
- 语言标签走白名单正则换成英文说法（`en`→English、`zh`→Chinese (Simplified)…），落不进的回落英文。
  不直接把标签塞进提示词：那是用户可控串，塞进去等于往系统提示词里 injections。
- 拆不动就**整段当正文**：标识只是辅助，正文才是产品要的东西。协议没对上时该"少拿到一点"，
  而不是把整发判失败。全角竖线 `｜` 也认（模型会写成那个）。
- 输出封顶 `max_tokens = 700`、正文再按 2000 字截一次。

## 六、这一趟的证据（10-25 实跑，不是推断）

- 用例：`backend/tests/test_roammark_spot_draft.py` **48 条**；整套后端 **1340 条，除别人那一格外 0 失败**
  （唯一那条红是 `test_admin_poster_preview.py::test_副本与客户端那一份逐字相同`——另一支在改的
  `miniprogram/utils/appInfo.js` 抬号没跑同步脚本，与本趟无关，没替它改）。
- 尺子按"这一路最可能怎么坏"分八组，不是按文件分：门闩／钥来源／出去的形状／字节闸／不留痕／
  协议拆解／舱壁／代码形状。
- 反向探针 **5 把**，登记进共用变异表 `backend/probes/mutation_check.py` 的 **RM1~RM5**
  （打法与其余条目一致：打上 → 跑对应用例 → 立刻还原；跑完这一份 48 条重跑过）。五把现在全 `CAUGHT`。
  其中**三把在第一版尺子下是扑空的**，第四把（RM3）露出的是另一种假绿——这一趟真正的产出不是那 48 条，是这四格：
  - **RM2** `INFLIGHT_LIMIT` 改成 99 → 第一遍没红：那条用例是拿 `INFLIGHT_LIMIT` 自己算的，改常量它跟着动。
    补了"就是这个数字 3"那条尺子才咬住。
  - **RM4** 回体里多塞一个带图字节的键 → 第一遍没红：原来那两把尺子是"扫 base64"与"扫原字节"，
    塞一段 hex 两边都搜不到。补了**键名单**那条（多一个键就红）才咬住。
  - **RM1** 留一枚没人叫的旧函数 → 本趟自己长出来的雷：舱壁从 `Semaphore` 换成一个整数后，
    旧那枚读 `_inflight.locked()` 的函数成了当场会 `AttributeError` 的死码，而整套用例全绿。
    补的第八组尺子**第一版走全文搜串，还是没红**——两处骗它：本文说明里提了那个名字、
    `ops_page.py` 里那串 JS 有自己的 `one._busy`。改成走 AST（只数真引用、不数串）之后才红。
  - **RM3** 摘掉合计字节那道闸 → 这一格是**另一种坏法**：我用例第一版把上限缩到 300 字节，而样本是
    5 张 × 44 = 220，**根本没穿过 300**——那条用例红在"分支没跑上"，不是闸坏。要是当时顺手把断言放宽，
    就把它变成了一条永真的假尺子。现在缩到 150，并由用例自己断言样本形状（单张 < 上限 < 五张合计）。
  - **RM5** 口令比对改成"没配就当不检" → 一遍就红（一、门闩那组本来就咬得住）。

⚠ **没量过的格子**（不做没量的断言）：
- 服务端这两个口**一次都没真打**：上一刀那七发是在服务器上**直连 DeepSeek** 跑的（`TmNote/取证-DeepSeek-real-usage/`），
  没经过 `spot-draft` 这一路——所以"这条链在现网跑得通"到今天为止仍是没量的。
- 真机侧端到端**还不存在**：RoamMark 里今天一个网络请求都没有，缩图与发送那一层是 §八 第一格。
- 免费档每天几次**已拍＝5 条**（§八 那一格），但那是**客户端本机**的闸；服务端这一版仍只有上面那三道，一行都没为它改。

## 七、上线那一趟要做的三件事（现在一件都没做）

1. 现网 `.env` 加一行 `ROAMMARK_APP_GATE=<口令>`。⚠ 不加就整组 503；口令**不是凭据**，别当密钥轮换，
   但也不许进对话、进 commit、进记账——走剪贴板交付。
2. 后台「密钥配置」那一行 `DEEPSEEK` 保持有值（他 10-25 已经填了真钥，长度 35；凭据的指纹不进仓）。
   库里那一行删掉 ⇒ 这一路回落到 `settings.DEEPSEEK`（现网没写那一行）⇒ 503。
3. 部署：`backend/upload.sh`（整树打包，排除 `.env`／`*.db*`／`.venv`／`keys`）→ `backend/deploy.sh`。
   **本趟没有迁移**（不加表、不改列），`deploy.sh` 一个字不用改。
   上完先看 `GET /api/roammark/health`：`ready` 与 `gate_open` 都得是 `true` 才算开成。

回退一条就够：`.env` 删掉那一行再重启 = 整组 503，不动用户数据、不动图麦笔记任何链路。
