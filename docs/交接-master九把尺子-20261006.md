**一句话**：跑 2.0 回归抓到**九把尺子在 master 上要么红、要么根本跑不起来**。两类：
**五条判据过时**（实现没错，代码合法地动过而判据没跟着改）＋**五处端口写死 9420**（`跑尺子.sh` 统一 9431，这五把从 runner 里连都连不上）。
修法只写在 `release/2.0` 这一支，**master 上今天仍然那样**。

**载体**：`docs/补丁-master九把尺子-20261006.patch`——240 行，`9 files changed, 58 insertions(+), 21 deletions(-)`，
只碰那九个 `docs/工具/` 文件，**一行产品代码都不动**。

## 为什么不能靠 merge 带回去

这一支还带着 2.0 的东西（`appInfo.VERSION = 2.0.0`、图片那条链、张数常量）。
把分支 merge 回 master 去修尺子，等于顺手把没做完的 2.0 一起塞进 1.9.x 的出包线上。
所以债不走 merge，走一份能直接 `git apply` 的补丁。

## 五条判据各自红在哪

1. **`验-列表D2`「点开大图取的是台账里那一张」**：判据拿包内 `poster.TEMPLATES` 去"认不认"那个模板 id。
   实现早就换成合并后的 `templateList()`（包内十套 ＋ 下发的）。台账那一格完全可能指着一条远端模板，
   照旧判据会把真存在的模板判成不认识、开成默认那一套。
2. **`验-列表D2`「删除只动本机这本账」**：原来是一条 240 字符窗口的长正则。10-04 给 `onDropCard` 加了三行注释
   （说的是"按钮一律用系统默认那对"），把距离撑过了窗口——**红的是尺子，代码一个字没错**。
   改成位置比较：取函数体、剥掉注释，钉"`dropNote` 在 `_closeTemplate` 之前"＋"整段没调过 api"。
3. **`验-列表头部铺图`「三块都在容器里」**：判据要求 `class="sheet"` 紧挨着 `">`，而那一格后来多了"加宽"那一档
   （`sheet {{listWide ? 'ix-wide' : ''}}`）。要钉的是**先后与归属**，不是那个 class 一字不变。
4. **`验-录入面板沉底-真跑`「原文区仍是 300rpx 高」**：`.face-area` 在 10-04 下午已经从 300 降到 228
   （按钮行上面加了「原文翻译」那一行，56 + 16 = 72，正文让出那 72；`create.wxss` 的 `.wr-body` 注释里写的就是 228）。
   判据两天没跟着改。
5. **`验-列表v19-真跑`「小字跟着变成『关闭二维码』」**：`d8c5076`（10-05，站长要两态各带一句说明）把 `qrOff`
   改成「关闭二维码｜只发这张图，扫不出原文」，判据还钉着老那半截——红的不是药丸。
   改成从字典现读（`=== ZH.qrOff`）。**这条是 10-06 全量真跑才抓到的，前面四条是同日第二轮**。

## 五处端口：为什么这也算债

`验-关于页版本号`、`验-分享链路端到端`、`验-字眼与模板条`、`验-热启动归因`、`验-转存与作者`
这五把的默认端口是 `9420`（更早那批尺子统一到了 `9431`，这五把漏了）。
`跑尺子.sh` 起会话只用 9431，所以**这五把从 runner 里跑必然连接红**——而连接红不是判据红，
它只说明"这一把今天没人真正跑过"。真正的代价在这儿：全量回归的清单里有它们，跑完一片红里混着五把连不上的，
人就顺手当"环境红，跳过"，于是这几把可以从 10-04 一直跳到今天没人看一眼。
改成 `const PORT = process.env.APORT || '9431'`，旧写法还在（`APORT=9420 node …`），只是不再是默认。

## 顺带一条纪律（这五条就是这么攒下来的）

改完界面那一轮，收尾动作必须包含"**把受影响的尺子当场再跑一遍**"。
五条里四条是 10-04 那几轮攒的、第五条是 10-05 攒的，隔了一两天才被 2.0 回归第一次抓到。
还有一条：这些红**不许用"重生成基线"糊过去**——`验-模板配方等价.js` 那种基线才是"改一下就要解释"的东西，
判据写错了就改判据，别把实现改去迁就旧尺子，也别把旧的错值重新钉一遍。
端口那五处同理：一把连不上的尺子出现在清单里，和一把从没写过的尺子没有区别。
