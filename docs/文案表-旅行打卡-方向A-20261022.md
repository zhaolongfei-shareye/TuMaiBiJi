# 文案表 · 旅行打卡 App（方向 A）v1

**2026-10-22 起。这张表是这个新产品的"现网字典"——在它之前，新工程没有现网可抄，所以先落这张表。**

## 0. 三条用法（先立规矩，再谈字）

1. **屏上每一句字必须先在这张表里出现**。表里没有的字，不许写进界面、也不许写进代码里的字符串常量。
2. **改字＝先改这张表**，再改屏；反过来做就是两边漂（这条在图麦那两条线上各漂过不止一次）。
3. **英文是主语言**（10-22 拍板①＝海外为主、美区优先），中文是第二列不是备份列。两句都要填，填不出中文的格子标「待补」。

## 1. 术语统一（只许用左边这些词，右边那些是禁用同义替换）

| 只用 | 不许用 | 为什么 |
|---|---|---|
| **note** | entry / journal / memory / post | 产品本体是"一条笔记"，与图麦那套同源，别在旅行版换名 |
| **place** | location / spot / destination | "location" 留给系统权限语境（定位服务），屏上指"一个地方"一律 place |
| **check in** | log / record / add place | 主动词只有一个。名词态用 "check-in"，别混 |
| **pin**（动词＋名词都用） | drop a marker / tag | 地图点选那一条腿的专有名 |
| **precise / approximate** | exact / rough | 对齐 iOS 系统里那枚 "Precise Location" 开关的字，用户从设置回来能对上 |
| **manual pin** | 手动 / by hand | 单地点页右侧那个来源词的固定写法 |
| **backup** | export / sync / cloud | 「sync」是禁词（见第 4 节）；导出动作写作 "Export a backup" |
| **feed / map / search** | timeline / explore / find | 底部 tab 三个词，短、不重名 |
| **place name / unnamed place** | location name / no location / 无位置 | **「地名」是反查回来的那一串字，「地点」是这条笔记归进去的那一格**——两回事，屏上不许混。10-22 夜读数之后这一条变成硬要求：地名可以没有，地点一定有一个 |
| **name it / name this place** | label / tag / rename / 重命名 | 用户自己给一个无名点起名字，全 App 只有这一种说法。"rename" 意味着原来有名字，不许用 |

## 4. 禁词清单（每一条都对着一次拍板，不是审美偏好）

| 不许出现 | 依据 |
|---|---|
| `AI summary` / `整理` / `智能摘要` | 拍板⑤＝不补 AI 摘要。**没做的能力不许在屏上许诺** |
| `sync` / `iCloud` / `cloud backup` / `自动备份` | 拍板①＋代码隔离口径：本机优先、无云。只有 "backup / export" 成立 |
| `share` / `公开分享` / `scan to open` | 拍板：不做分享回流、不做公开页 |
| `track` / `auto track` / `足迹自动记录` / `timeline of your life` | 拍板④＝只在手动打卡时取一次，不做后台定位。**"track" 会暗示自动记录** |
| `Pro` / `订阅` / `unlock` / `upgrade` | 拍板⑦＝第一版全免费 |
| `unlimited` / `无限` | 老规矩：界面不许诺服务端没做的事（这版连服务端都没有） |
| `offline maps` / `下载地图` | 没做，且地图数据源本身还没取证（T1） |
| `示例数据` / `demo note` | 空态规矩：不摆假入口、不摆假内容 |
| `Search nearby places` / `找附近地名` / `Pick a landmark` / `Retry name` | **10-22 夜真机读数**：境外坐标上 `MKLocalSearch` 与两条反查（`CLGeocoder`、`MKReverseGeocodingRequest`）**一起回空**。摆一枚点了拿不到东西的按钮，比不摆更坏——所以 N7／N8 那两屏上**没有**"搜附近地名"这一枚，只有"你自己命名"和"先不命名"两条 |

## 5. 表里现在还有六个占位，都不许进开发

| 占位 | 等谁 |
|---|---|
| `checkin.accuracyLine` 与 `save.accuracy` 里那个 `{m}` | **T3**（定位四态实测） |
| `approx.body` 里那个 `{granularity}` | **T3** |
| `checkin.placeLine` 在**离线**时到底填什么 | **T2**（离线反查行为） |
| **境外到底拿不拿得到地名**（决定 `ladder.level1` 是"划掉"还是"能用"，也就决定 N7 是主路还是罕见态） | ⚠ **新增，且比上面三条都大**：10-22 夜那批读数只证了「**这台中国区设备＋这个网络**」上拿不到，**没换过非中国区设备复量**。这一格空着之前，N7／N8 只能按"两种可能都成立"来画 |
| `create.write.counter` 里那个 `{max}` | 等你点：2000 是母体那一档的数值，不是这一档的结论 |
| `place.unnamedBar` 那串坐标取几位小数 | 只有真机能判（小屏折不折行）；效果图上取 4 位**只是排版选择** |

**另：效果图上有三类字不是屏上文案，别抄进表**——`map is illustrative`、`photo slot 示意`、`全部 CSS 画的示意` 这三句是**效果图自己的标注**，产品里不存在。新建稿上的 `keyboard` 同属这一类。
**但 N4 那块 `Link kept` 是屏上的字**，已进表（`create.link.keptCard`）——它和上面那三句的区别是：它回答用户"我这条还留没留下"，那三句只回答我"这图是怎么画出来的"。
