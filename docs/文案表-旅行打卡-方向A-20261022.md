# 文案表 · 旅行打卡 App（方向 A）v1

**2026-10-22 起。这张表是这个新产品的"现网字典"——在它之前，新工程没有现网可抄，所以先落这张表。**

## 0. 三条用法（先立规矩，再谈字）

1. **屏上每一句字必须先在这张表里出现**。表里没有的字，不许写进界面、也不许写进代码里的字符串常量。
2. **改字＝先改这张表**，再改屏；反过来做就是两边漂（这条在图麦那两条线上各漂过不止一次）。
3. **英文是主语言**（10-22 拍板①＝海外为主、美区优先），中文是第二列不是备份列。两句都要填，填不出中文的格子标「待补」。

---

## 1. 术语统一（只许用左边这些词，右边那些是禁用同义替换）

| 只用 | 不许用 | 为什么 |
|---|---|---|
| **note** | entry / journal / memory / post | 产品本体是"一条笔记"，与图麦那套同源，别在旅行版换名 |
| **place** | location / spot / destination | "location" 留给系统权限语境（定位服务），屏上指"一个地方"一律 place |
| **check in** | log / record / add place | 主动词只有一个。名词态用 "check-in"，别混 |
| **pin**（动词＋名词都用） | drop a marker / tag | 地图点选那一条腿的专有名 |
| **precise / approximate** | exact / rough | 对齐 iOS 系统里那枚 "Precise Location" 开关的字，用户从设置回来能对上 |
| **manual pin** | 手动 / by hand | 单地点页右侧那个来源词的固定写法 |
| **backup** | export / sync / cloud | 「sync」是禁词（见第 4 节）；导出动作写作 "Export a backup" |
| **feed / map / search** | timeline / explore / find | 底部 tab 三个词，短、不重名 |

## 2. 逐屏文案（键名按"屏.位置"取，开发直接照抄）

### A1 首页 · 正常

| 键 | EN | 中文 | 这一句为什么这么写 |
|---|---|---|---|
| `home.todayPill` | `Today · {place}` | `今天 · {地方}` | 地图右上角只回答"今天在哪"，不写日期格式（跟随系统） |
| `home.weekCount` | `{n} places this week` | `本周 {n} 个地方` | 计数句必须能在 0 时隐藏（见 A2 空态规矩） |
| `home.sectionNotes` | `Notes near today` | `今天附近` | 不写 "Recent"——"near" 是这条产品的差异化词（近＝地点＋时间双关） |
| `home.meta` | `{p} photos · {w} words · {accuracy}` | `{p} 图 · {w} 字 · {精度}` | 三段用中点分隔；缺项整段不显示，不许留空段 |
| `tab.feed` / `tab.map` / `tab.search` / `tab.me` | `Feed` / `Map` / `Search` / `Me` | `笔记` / `地图` / `搜索` / `我的` | 四枚；中央那枚不是 tab |
| `action.checkIn` | `Check in` | `打卡` | **全 App 唯一主动词**，黄色那枚 |

### A2 首页 · 空态（第一次用）

| 键 | EN | 中文 | 规矩 |
|---|---|---|---|
| `home.emptyTitle` | `Nothing here yet` | `还没有东西` | 不写 "No notes" —— 用户第一次见，"notes" 还没建立含义 |
| `home.emptyHow` | `Take a photo, drop a link, or write it out` | `拍一张、丢一条链接，或自己写` | 三个入口一句话列完，与新建页三入口一一对应 |
| `home.emptyPromise` | `Your first note will appear here with the place you made it` | `第一条笔记会连同它是在哪儿记下的，出现在这里` | 这句是产品主张，**不许改成营销话** |
| `home.emptyCta` | `Check in here` | `就在这里打卡` | 空态只给一个动作；**不摆"示例数据"、不摆假卡片** |

### A3 打卡抽屉 · 正常

| 键 | EN | 中文 | 依赖 |
|---|---|---|---|
| `checkin.title` | `Check in here?` | `就在这里打卡？` | — |
| `checkin.placeLine` | `{poi}, {district}, {city}` | `{POI}，{区}，{市}` | **地名快照**：这一串在存下那一刻冻结（等 T2 读数确认离线行为） |
| `checkin.accuracyLine` | `±{m} m · precise location on` | `±{m} 米 · 精确位置已开` | ⚠ **数字来自 T3 实测**；量不到不许印 |
| `checkin.use` | `Use this place` | `就用这个地方` | 主按钮 |
| `checkin.pickInstead` | `Pick on map instead` | `在地图上另选` | 次按钮，**永远在**（这是第二条腿的入口） |
| `checkin.privacy` | `Saved on this device only · travels with a backup only if you export one` | `只存这台设备 · 只有你导出的备份里才会带走` | **这句是隐私承诺，改字要同步改 App Store 隐私标签** |

### A4 打卡 · 权限被拒

| 键 | EN | 中文 | 规矩 |
|---|---|---|---|
| `denied.title` | `Where was this?` | `这是在哪儿？` | **不许出现红色报错、不许第二次弹系统框** |
| `denied.body` | `We can't read your position — that's fine, drop the pin yourself.` | `读不到你的位置——没关系，自己在图上点一下就行` | 语气：不催、不道歉式卑微 |
| `denied.pick` | `Pick on map` | `在地图上点` | 这一态里它是**主按钮** |
| `denied.skip` | `Save without a place` | `先不标地点，存下` | **必须存在**：不标地点也能存笔记 |
| `denied.hint` | `You can turn location on later in Settings — nothing is lost meanwhile` | `以后可以在设置里打开，这期间什么都不丢` | 半句"什么都不丢"要有依据才许写（本机存储＝成立） |

### A5 打卡 · 精确位置关闭

| 键 | EN | 中文 | 状态 |
|---|---|---|---|
| `approx.title` | `Approximate area` | `大致区域` | 定 |
| `approx.body` | `Your iPhone shares an approximate position ({granularity}). We'll file this note under **{city}**, not a specific spot.` | `这台 iPhone 只给到大致位置（{粒度}）。这条会归到 **{城市}**，不是某个具体点。` | ⚠ **`{粒度}` 是占位**，等 T3 量出城市级到底多粗；**量完之前这一屏不进开发** |
| `approx.use` | `Use {city} as the place` | `就归到{城市}` | 定 |
| `approx.pick` | `Pick exact spot on map` | `在图上点准位置` | 定 |
| `approx.hint` | `Turn on Precise Location in Settings for street-level filing` | `想要街道级归位，去设置里打开"精确位置"` | 定（"Precise Location" 要跟系统字一致） |

### A6 单地点页

| 键 | EN | 中文 | 规矩 |
|---|---|---|---|
| `place.subtitle` | `{district}, {city} · {n} notes · {dateRange}` | `{区}，{市} · {n} 条 · {日期跨度}` | — |
| `place.srcLive` | `±{m} m` | `±{m} 米` | 两条腿之一 |
| `place.srcManual` | `manual pin` | `手动点选` | 两条腿之二。**没有第三种，也不许出现 "unknown"** |
| `place.add` | `Add note here` | `在这里记一条` | "here" 有实指（当前地点），别写成 "Add note" |

## 3. 系统弹层用途串（草稿，写法照母体那两句的口径：一句大白话＋一句不出本机）

| 键 | EN | 中文 |
|---|---|---|
| `NSLocationWhenInUseUsageDescription` | `We use your position only to file a note under the place you're standing at. It stays on this device.` | `位置只用来把这条笔记归到你当下所在的地点，不会离开这台设备。` |
| `NSCameraUsageDescription` | `Take a photo of a menu, a ticket, or a sign — the text is read on this device, the photo isn't uploaded.` | `拍下菜单、门票或路牌——文字在这台设备上识字，原图不上传。` |
| `NSPhotoLibraryAddUsageDescription` | `Save the card you made as an image. We don't read what's already in your library.` | `把你做的卡片存成一张图。不读取相册里原有的内容。` |

⚠ **这一格有两条没定**：① 10-22 拍板"照片自动取位整条不做"⇒ **不申请相册读权限**，所以上表**没有** `NSPhotoLibraryUsageDescription`，将来重开那条腿要另加一句；② 中文列是草稿，**没做过母语校对**。

## 4. 禁词清单（每一条都对着一次拍板，不是审美偏好）

| 不许出现 | 依据 |
|---|---|
| `AI summary` / `整理` / `智能摘要` | 拍板⑤＝不补 AI 摘要。**没做的能力不许在屏上许诺** |
| `sync` / `iCloud` / `cloud backup` / `自动备份` | 拍板①＋代码隔离口径：本机优先、无云。只有 "backup / export" 成立 |
| `share` / `公开分享` / `scan to open` | 拍板：不做分享回流、不做公开页 |
| `track` / `auto track` / `足迹自动记录` / `timeline of your life` | 拍板④＝只在手动打卡时取一次，不做后台定位。**"track" 会暗示自动记录** |
| `Pro` / `订阅` / `unlock` / `upgrade` | 拍板⑦＝第一版全免费 |
| `unlimited` / `无限` | 老规矩：界面不许诺服务端没做的事（这版连服务端都没有） |
| `offline maps` / `下载地图` | 没做，且地图数据源本身还没取证（T1） |
| `示例数据` / `demo note` | 空态规矩：不摆假入口、不摆假内容 |

## 5. 表里现在还有三个占位，都不许进开发

| 占位 | 等谁 |
|---|---|
| `checkin.accuracyLine` 里那个 `{m}` | **T3**（定位四态实测） |
| `approx.body` 里那个 `{granularity}` | **T3** |
| `checkin.placeLine` 在**离线**时到底填什么 | **T2**（离线反查行为） |

**另：效果图上有两类字不是屏上文案，别抄进表**——`map is illustrative`、`photo slot 示意`、`全部 CSS 画的示意` 这三句是**效果图自己的标注**，产品里不存在。
