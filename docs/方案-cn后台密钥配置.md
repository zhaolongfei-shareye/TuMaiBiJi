落码日期 2026-10-25。这一份写的是**现在长什么样**，不是计划；计划部分只在最后一节留着没做的格子。

同一套东西 10-24 夜先落在了图麦克（`AgentsWatermark/cloud/image-service`）并上过现网，

## 一、需求原文对照

站长 10-24 两句，第二句是对第一句的更正：

| 原话 | 落在哪 |
| --- | --- |
| 「密钥配置功能请加到cn的官网后台，我自己去加」 | `/ops` 那一页新增一节「密钥配置」；值由他自己在页面上填，我们不接触原值 |
| 「配置功能放错地方了，你放在图麦克，应该放在图麦笔记下面进行配置」 | 实现位置＝图麦笔记后端（本页）；图麦克那一处已回退并验过（§六） |

第一句里那句"我自己去加"决定了这一节的核心判据：**页面上不允许出现任何需要我们把密钥值交给他
或他把值交给我们对话的环节**。值只在他浏览器 → HTTPS → 服务端 → SQLite 这一条线上走一次。

## 二、现在长什么样（口径）

- 一张表 `service_secrets`：`name`（主键，规范化成大写）/ `value`（明文）/ `note` / `created_at` / `updated_at`。
  没有历史行——改一次覆盖一次，历史上只留最后一次的时间。迁移 `c9f2a6d4e831`（父级＝当时的链尾
  `b7f2c4d9a310`）**一行都不预建**。
- 三个口，全在 `admin_access` 那把独立的钥匙后面（`/api/admin/secrets` GET、
  `/api/admin/secrets/{name}` PUT、DELETE）：口令没配一律 503，不是 401，也不是放行
  （与运营图那四个口同一条纪律）。
- 读侧唯一的覆盖点：`app/services/service_secrets.py:resolve(name, fallback)`。库里那一行优先，
  查不到 / 那一行是空的 / 读库抛异常 → 三种都回 `fallback`，也就是调用方从 `settings`（`.env`）拿的那一份。
- 今天真被 `resolve()` 读的三个消费者（两处微信凭据必须一起改，否则"登录用新钥匙、取 token 用旧的那把"）：
  - `app/services/wechat.py:_token_body` —— `WECHAT_APP_SECRET`
  - `app/core/auth.py:_wechat_code2session` —— `WECHAT_APP_SECRET`
  - `app/services/llm.py:_call_hunyuan_cloud_function` —— `HUNYUAN_CF_KEY`
  名单在 `service_secrets.CONSUMED_NAMES`，且有一条用例把"名单"与"源码里真出现过的 `resolve("…")` 字面量"
  做双向相等判定——名单与消费者谁先跑偏，用例就红。
- 界面上每一条给四样能确认"刚那一趟真存进去了、存的是不是同一把"的东西：长度、sha256 前 8 位、
  更新时间（**浏览器本地那一天**，不是切 UTC 串）、备注，加一句"生效值从哪一层来"和"删掉会落到哪一层"。
  还没代码在读的名字，界面直接补一句「还没有代码读这个名字」，不假装生效。

## 三、四条锚点（缺一条这一节就不能上现网）

1. **值只进不出。** `describe()` 交出去的是长度与指纹，接口回体里没有 `value` 这个键，
   所以"忘了删敏感字段"这类坏法从源头上不成立。日志同样只打 `name / 长度 / 指纹`。
2. **库里只是覆盖层，不是第二套配置系统。** 只有 `CONSUMED_NAMES` 里点名的那几个名字真有读法；
   删一行 = 当场回到 `.env`。这一条是"撤回一次改动不需要知道旧值"的落地，也是它敢上现网的前提。
3. **读侧不许抛。** `resolve()` 里那一句 `except Exception` 不是装饰：表还没建（迁移没跑）、库被锁、
   连接打满，三种情况都只该有一个结果——照旧用 `.env`。它挂在登录那条链上，坏了不能变成登录 500。
4. **屏上那一句不许替 `.env` 那头下断言。** `env_present` 实读的是 `settings`（回退那一路真拿得到的那一份），
   不是那个文件：现网两个 unit **没有 `EnvironmentFile=`**，全部值经 pydantic 从 `.env` 装进 `settings`；
   一个没在 `config.py` 声明过的名字（例 `DEEPSEEK_API_KEY`），`.env` 里真写着那一行也读不进来
   （`extra="ignore"`）。所以屏上只写「库里这一行（删掉就没有值了）」，不写「.env 里没有这一行」。

## 四、负面清单（这一版明确不做，每条附依据）

- **不做多管理员、不做审计流水。** 现网这把钥匙只有站长一个人（`admin_access.py` 文件头：多管理员在
  运营图方案的负面清单第 4 条，今天不建）。所以没有 `updated_by` 这一栏。
- **不做值加密存放。** `.env` 里也是明文，这台机器上没有任何一层加密能假装保护它；真做了只会让
  "读侧不许抛"那条多一个失败面（密钥环挂了 = 全线退回空值）。
- **不做值的回显、复制、导出。** 一旦能回显，就多出页面、浏览器历史、截图三条外流路径。
  换错了只能重新粘贴覆盖，这是刻意的。
- **不做"启动时打印当前覆盖了哪几个名字"。** 现网 `deploy.sh` 的配置自检只报有无不打印值，
  加这一句要单独议；界面上那一句"生效值从哪一层来"是目前唯一的可见处。
- **不做 `.env` 里没有的键的自动注册**：存进去只是躺在库里，等代码接上同名读法。
  界面已经会把这一格说出来。
- **不把 `.env` 整份搬进后台。** `HUNYUAN_CF_URL`、`APPLE_CLIENT_ID` 这类**配置**值今天仍只能改文件——
  这一节管的是凭据。

## 五、这一趟的证据（10-25 实跑，不是推断）

- 用例：`backend/tests/test_service_secrets.py` **46 条**；整套后端 **1286 条，除别人那一格外 0 失败**
  （唯一那条红是 `test_admin_poster_preview.py::test_副本与客户端那一份逐字相同`——另一支在改的
  `miniprogram/utils/appInfo.js` 抬到 2.4.17 没跑同步脚本，与本趟无关，没替它改）。
- 四把反向探针（改坏源码看用例抓不抓得住），逐条跑过、跑完还原并核过字节一致：
  - 往 `describe()` 里加回 `value` → 红 1 条（「值不在回体里」）。
  - 让 `resolve()` 无条件回 `fallback` → 红 5 条（三个消费者、空白剥离、删行回到 .env）。
  - 写侧 `canonical_name` 去掉 `.upper()` → 红 1 条（「库里只有一行」）。
  - 读侧 `resolve` 去掉 `.upper()` → **第一遍没红**：库里存着大写行、用小写名去读那一格没人量过。
    补了 `test_库里是大写那一行而读侧传小写也要拿得到它` 之后红 1 条。⚠ 这一条是这一趟唯一一个
    "探针先扑空、才知道格子是空的"，记在这里是因为它证明了**绿过不等于量过**。
  - 读侧去掉 `strip()`（空行也算覆盖）→ 红 1 条。
- 浏览器真点（`node docs/工具/验-后台密钥配置栏.mjs`，本机临时库 + 真页面 + headless Chrome）：
  **35 条过／0 条红**。里面四类只有真点量得出来：① 那一栏真画出来（左栏 `.navitem` 点得动、
  `#view-config` 不藏着）；② 三把哨兵值在**屏上文字、卡片 innerHTML、接口回体、uvicorn 日志**四处
  都搜不到，值输入框存完即清空且是 `type=password`；③ 「删掉」第一下只把话术换成「再点一次=删掉」、
  行还在，第二下才没；④ 存一把假的 `WECHAT_APP_SECRET` 进临时库后 `resolve()` 回的是库里那把，
  删掉那一行当场回到调用方传的 fallback。屏照留在 `docs/design/后台密钥配置-自证-20261025/`。

## 六、部署与回退

- 上传走 `backend/upload.sh`（整树打包，排除 `.env`／`*.db*`／`.venv`／`keys`），部署走
  `backend/deploy.sh`（语法闸 → 系统库 → 备份＋恢复演练 → `alembic upgrade head` → 重启双 unit → 校验）。
  这一节的迁移在链尾，`deploy.sh` 一个字不用改。
- **空表 = 现网行为一行不变**：三条消费者在没有覆盖行时读到的就是 `.env` 那一份——这是这一趟敢直接上的理由。
- 回退有两条，都不动用户数据：
  1. 只撤某一把 → 后台点删除（回到 `.env`），或 `delete from service_secrets where name='…'`。
  2. 撤整节 → 回退代码 + `alembic downgrade -1`（删表）。⚠ 如果有人已经改成"只用后台管凭据、
     `.env` 里留的是旧值"，删表那一刻线上会退回旧值——先核 `.env` 再 downgrade。
- 图麦克那一处（10-24 夜误放的同一套东西）：**已撤并验过**。现网 `/admin/secrets` 本机与公网都回 404、
  `admin.html` 里没有那一节；回退点是镜像 tag `image-service-watermark-image-api:withsecrets-20261025-011048`
  与服务器上那三枚 `*.bak.withsecrets.20261025-011048`；`/healthz` 200。
