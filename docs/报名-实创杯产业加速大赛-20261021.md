**项目概述（约 480 字，只写我或你验过的东西）**

> 图麦笔记是一款把"看到的好内容"变成"能用的知识笔记"的 AI 工具。用户在日常阅读中遇到的图文、网页链接、拍照、截图、手写内容，过去要么收藏后再也没打开，要么手工复制粘贴整理；图麦笔记把这些一次性转成一条结构化笔记——标题、摘要、要点、标签，并可一键生成适合分享的卡片图。
>
> 技术上采用"网关＋服务端 API Key"的生产调用链路，以混元大模型完成提炼，配自建 FastAPI 后端与云开发存储；外链图文可按来源规则转存配图随笔记存档，多语言内容（16 国语言实测通过）统一整理成中文。分享侧是一层可撤回、可过期的公开快照页＋二维码，读者扫码即可在浏览器打开，也可一键转存进自己的库。
