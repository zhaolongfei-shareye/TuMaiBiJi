## 一、这一屏现在长什么样

代码：`miniprogram/pages/share/view.wxml` ＋ `view.wxss` ＋ `view.js`（页面路径 `/pages/share/view?token=…`，
小程序码、好友那条、朋友圈那条三个入口开的都是它）。

从上到下：

1. 页眉外那两行：**「分享笔记」那一枚 eyebrow** ＋ **作者行**（圆形墨底标记取昵称首字 ＋「原创作者：×××」）。
   这两行在窗**外面**——作者行说的是"谁写的"，不是这一篇的内容，图二那一窗里没有对位的东西，所以照旧留着。
2. 白卡（`.sv-sheet`，圆角 `--r-card`、描边 10% 墨、`overflow:hidden`）里面按图二那一窗的排布：
   **大标题 → 标签一排（灰字、无底色、无加粗，每枚前面带 `#`）→ 通栏配图 → 「摘要」＋正文 → 「核心要点」＋小黄点逐条 → 「来源链接」＋链接 ＋ 那句"链接无法直接打开，可复制链接在浏览器打开" → 底部动作条**。
3. 卡外下面那枚品牌行（「麦」＋来自图麦笔记）留着——撤了就把这一屏唯一的回流口撤掉了，他这句没提这一条。

**数是从代码里抄的，不是目测**：标题 46rpx／1.3／字距 −0.9rpx／90% 墨，内缩 34rpx，图区定高 395rpx，
圆点 11rpx、当前那枚换成 25×11rpx 的横杠、间距 6rpx，数字那一枚 78×51rpx 浅灰（`#BFBFBF`）压白字，
动作条那枚 72rpx 胶囊、描边 3rpx。这些与 `pages/index/index.wxss` 的 `.ds-*` 一族同一份数。

**色不抄**：详情窗那几档灰吃 `--text-tertiary`／`--accent-soft`，这两枚**随四套莫兰迪与五档心情换底色的墨**
（`app.wxss` 里一套一档）。这一屏是外人打开的，借过来就成了"读者自己那套壁纸决定别人这篇的字色"，
所以按这一屏自己的墨 `#23252c` 现出 alpha，档位与详情窗一致但钉死。

## 二、配图那一块（这一轮唯一的新交互）

原来是九格 150rpx 小方格（`.sv-shots`／`.sv-shot`，`aspectFill` 裁着放），现在换成图二那种**通栏大图轮播**：

- 一格两层：底＝同一张放大到 112% 且左上各外挪 6% 后 `blur(30rpx)`（不外推会把模糊带出的半透明渐隐圈露在四边上），
  上＝`aspectFit` 完整放进 395rpx 那个盒子（不裁；被留白盖不住的部分由底那一层铺）。
- 点上面那张还是拉全屏大图（`wx.previewImage`，`urls` 给整排，与详情页同一个动作）。
- 张数与那一排点都吃**同一个数** `figAt`（`swiper` 的 `bindchange` 是唯一写口）；只有一张时数字与点都不画。
- 换 token 时 `figAt` 归零（这一页会被复用：好友那条与朋友圈那条开的都是本页）。
- ⚠ 这一排画不画得出来**不取决于这一页公不公开**，取决于云开发存储「读」那一档：
  默认「仅创建者可读写」时别人打开就是空白（10-12 站长报的那条 BUG，当天由他在控制台放开）。

## 三、图二有、这一屏故意不画的三样（外加一句按钮的话）

| 图二那一窗里的 | 这一屏为什么不画 |
|---|---|
| 窗顶那行「左右滑动看下一篇／点一下收起」 | 落地页只有一篇，划不走；也没有"收起"这个动作（它不是一扇窗，是一页）。画了是假 affordance |
| 正文与动作条之间那枚「显示更多」 | 它跳的是「原文内容」那一栏，而**公开快照里没有 `original_content`**（`ShareResponse` 只有标题/摘要/标签/要点/关键链接/来源/作者/配图） |
| 抬头那行「分类·公众号文章·2026-10-21 19:04」 | 分类与来源类型都不在公开快照里；`ShareResponse.created_at` 是**这条分享建起来的时刻**，不是笔记的时间，拿它冒充那一栏是假话。要真画得先扩对外字段＝动数据口径（迁移＋送检登记＋部署），他这句没提 |
| 底部那三枚（编辑／分享／删除） | 换成他点名的那一枚。字照他原话念**「存入笔记」**（原来是「存到我的笔记」六个字；这一键只有这一屏在用，英文保持 `Save to my notes` 没动）。存完那一句跟着短一档：「已存入笔记」 |

「存入笔记」这条链**一行没改**：`api.importFromShare(token)` → `POST /api/notes/from-share`，
落地页免登录可读但存进自己库必须有身份，所以点的时候先兜一下 `getLoginPromise()`；抄的是服务端那份公开快照，
来源那一栏由服务端钉在笔记上，客户端改不掉。

## 四、判据
