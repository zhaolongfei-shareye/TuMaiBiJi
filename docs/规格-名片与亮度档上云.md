代码状态：`release/2.0` 上已写完，本地全绿；**现网还没部署**（`/api/user/profile` 目前 404）。

## 一、这一条要解决的那一句话

站长把 2.1 的跨端定成：**同一个微信号，换手机或重置手机之后再登录，依旧是自己那批东西。**
实测下来笔记那一路本来就成立（笔记、分类、分享、卡片行、配图、私密锁、壁纸全在库里），
真正只写在这台手机上的只有：名片那四格形象图、名片的名称与一句话、背景亮度档、卡片模板选的那一套。
所以这一条不是"备份文件"，是**把这三样搬上服务器，用户一步都不用做**。

## 二、数据长什么样

库里一行一人（`user_profiles`，唯一索引 `ix_user_profiles_user_id`）：

| 列 | 含义 | 空的意义 |
|---|---|---|
| `name` / `slogan` | 名片名称与一句话 | 没填过（画布落回兜底那个"麦"字） |
| `slots` | 四格，**存的时候永远补齐四个位置**，每格 `{file_id, card, bg, width, height, size}` | 一格 `null` ＝ 那个位置没放图（不是"少一项"） |
| `bg_dim` | 背景亮度档 0/1/2 | 没登记过 → 客户端落回本机默认那一档 |
| `tpl` | 卡片模板选的那一套 | 没登记过 → **保持本机那一套**（null 不等于「回到默认」，清成默认会让人莫名其妙换了套皮）|
| `updated_at` | **这一栏是"云上到底有没有这一行"的判据**，不是显示用 | `null` ＝ 从没登记过 |

`file_id` 存的是云开发 `cloud://` 地址（与卡片成品、笔记配图同一路子）：图片字节不经过这台服务器，
客户端先直传拿到地址、再来这里登记一行账。

**界面字体档（`uiFont`）不在这一张表里，也不许进任何请求体。** 它不是"没备份"，是不该同步：
安卓上那三档字体基本命不中，跟着账号跑到别人设备上只会让人看到"没生效"。这条钉在
`docs/工具/验-背景亮度圆点.js` 第⑥节。

## 三、三个口

- `GET /api/user/profile` — 没登记过回一份全空 **200**（不是 404：那会把"第一次用"和"读不到"混成一个）。
- `PUT /api/user/profile` — **补丁语义**：只改请求体里出现的那几栏（只提交 `bg_dim` 那一趟不许抹掉名称）。
  回体 `{profile, file_ids}`，`file_ids` 是这次被换下／撤掉的旧对象地址。
  `tpl` 只校形状（长度 ≤50），**服务端不抄模板 id 白名单**——模板走的是「不走发版」那条线，抄一份名单就得跟着每次新模板发一次后端（同 `routes/cards.py` 第 2 条）。
- 没有 DELETE 口：界面上的"清空名片"就是 PUT 一份空的。
- 归属三道闸：`file_id` 必须 `cloud://` 开头且不是空地址；这个地址若已在别人的 `assets`／
  `note_cards`／`user_profiles` 账上 → **400**（不回 403，多一档就多一个探测面）；`card` 与 `bg`
  各自单选，两格都勾 → 400。
- 名片图**不进任何配额口**（配图那 5GB 是一项、卡片是一项，名片今天只登记字节不动数）。

## 四、客户端那三种走法（`utils/profileCloud.js`）

挂在 `_doLogin` 成功那一刻，**不 await、不出声**：

1. **读不到** → 本机这一份照用，一个文件都不动。
2. **云上没这一行**（`updated_at` 为 null）→ 反方向：把本机这份推上去登记（bootstrap）。
   **这一趟绝不许删本机任何一张**——写错的后果是老用户升上来名片被清空，那是数据丢失不是显示问题。
3. **云上有一行** → 服务器权威，逐格对齐：
   - 地址没变且本机文件还在 → 沿用原路径（重下会顶掉画布正在用的那个文件）；
   - 地址变了 → `wx.cloud.downloadFile` 拉回来，落成本机**一个新名字**的文件（同路径换内容是另一坑），
     旧那张收掉（本机目录只有 10MB）；
   - 拉不下来 → 本机那张还在就照画它。宁可画一张云上已经换掉的旧图，也不把这一格画成空的；
   - 云上这一格是空的 → 本机这一格跟着撤。

写的那一头只有三个出口：`profile` 页的 `_commitSlots`（放图／换图／勾角色／撤格全走它）、
`onSave`（名称、一句话、选的那一套模板）、`app.cycleBgDim`（亮度档）。**页面里再出现第二处 PUT 就是红。**
登记不 await：附属品失败不许把"本机已经存好"这件事报成失败。

换身份／注销 → `signOut()` 只清内存那一份，本机四张文件一个都不动；
注销时那四格的地址会并进 `deactivate` 那份 `file_ids`（第七类），因为那是最后一次能把地址交回去的机会。

## 七、这一条里没做的两样（不是漏，是不同类）

· `cardLog` 本机那本账仍在本地——服务端 `note_cards` 已经是权威，本机那份是缓存，够用。
