## 2. 闸门：只有铺了形象图那一态才有玻璃

规则一律写成 `.container.has-bg <那一枚>`。三页的 `.container` 现在都带这枚闸（`me.wxml` 是 10-11 才补上的——
之前那条规则在这一页**一条都没落上**，纯空转）。没铺图 ⇒ 这些面退回各自的纯色底，界面不残缺。

**页面里凡挂了模糊的面，底色必须是 `var()`**，不许出现第二支白纱字面量（同一条尺子扫）。

## 3. 四处玻璃面

### 3.1 列表卡顶（`pages/index`）
`.container.has-bg .sheet` 的 `background` 是**同一张渐变的四个色标**（不是叠一层皮）：

```
0 → 158rpx  纯白纱 var(--glass-veil)
158 → 198   渐退到 var(--glass-fade-card)
198 → 238   退到 var(--bg-card)（实心）
```

- 白纱那一段盖住的是**两枚 tab 那一行＋分类那一行**；实测两行下沿 138rpx、第三行字顶 170rpx（都相对卡顶），158 落在中间。
- 底下必须有图可糊：这一页的玻璃带到 **740**（＝头部 542 ＋ 罩层延段 198），图底实测 748rpx ≥ 实心线 739rpx。
  ⚠ 10-11 11:2x 起"把图摆到哪"不再由这一枚决定：递给 `poster.bandGeom` 的是全站那一枚 **`poster.HEAD_IMG_H`(740)**，
  本页那枚 `GLASS_BAND_H = 542 + 198` 只留作版式账（两者今天同值，但**各写一个数就是"切 tab 背景图上下跳"**，见 §3.5）。
- 延段挂在 `.head-scrim::after`（`top:100%`），**跟着「调亮度」那枚 opacity 一起沉**；值取罩层渐变的末档 `rgba(18,20,26,.52)`＝只延长不换色。

### 3.4 三枚居中弹窗

### 3.5 头部那张形象图的落点：全站一枚锚点（R15）

列表与「我的」两屏的那张头图都走 `poster.bandGeom(w, h, boxH)`：**按宽铺满（750rpx），超出盒子那截的 15% 顶给上面**（留头顶空间）。
`boxH` 现在**只有一枚**：`poster.HEAD_IMG_H = 740`。

- 为什么收成一枚：那句 `top = -(byWidth - boxH) × 0.15` 里带着 boxH，两页各写一个数＝同一张照片两页顶边不一样＝**切 tab 时背景图上下跳**。
  实测过：两页分别写 740／646 那态，列表图顶 −1.9rpx、「我的」−15.4rpx，差 **13.5rpx ≈ 7.0 视口 px**（`docs/工具/探-头部图两页对位.js`，改前红、改后绿）。
- 取 740 不取 646：取小的那一档，列表玻璃带 646～740 底下会没图（"中间镂空"他抓过）。所以对齐方向是**「我的」往下挪去配列表**，列表不动。
- 带高与锚点是两件事：列表 `.head` 542 ＋ 延段 198、「我的」`.head-band` 646，这两笔账留在各页 wxss 里（由 `验-玻璃令牌齐不齐` 钉等式），**不再递给 bandGeom**。
- 首页那一屏不吃这一枚：它是 `.page-bg` 全屏 `aspectFill`（750×100vh），本来就没有"带"。
- 首页详情窗那一态仍递 `this._webviewH()`（图要贯穿整屏，站长 10-03 拍的），算法同一条、不分第二份公式。

## 5. 退化行为（说准，别写假话）

- **某一枚 `--glass-*` 在那套壁纸里没定义** ⇒ `var()` 替换后非法值在 CSS 里是 IACVT＝整条声明按 `unset` 用，
  而 `background` 简写会把底色归成 `transparent` ⇒ **整张卡透空露出原图**，不是"退回实心"。所以令牌必须五块皮肤齐。
- **机型不认 `backdrop-filter`** ⇒ 只剩一层 .30 白纱压在照片上、不糊。要不要为这一档加 `@supports not (...)` 抬 α，
  他 10-11 拍**甲＝不加**（§6.1），所以代码里一条 `@supports` 都没有，他拍的 .30 全站一个值。
- iOS 的 WKWebView 只认 `-webkit-backdrop-filter`，所以每一行 `backdrop-filter` 后面**必须紧跟** `-webkit-` 那一行（尺子逐页钉）。
