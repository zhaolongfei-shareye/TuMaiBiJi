### 1.5 上面又叠了一层「心情」（10-14 五档彩色玻璃）

站长 10-14 那句让玻璃有颜色，所以上面那一叠值现在分**三层**，源码顺序就是优先级（同 specificity，后面的赢）：

```
page{}  ← 兜底（白纱那一族，机型没挂上类时也读得清）
.theme-* ← 壁纸决定：页面底色、卡片底、渐退那一段
.mood-*  ← 心情决定：玻璃／面板／压在玻璃上的字（10-14 新增，压过前两档）
```

五档由 `utils/palette.js` 的 `MOODS` 一处出口，`app.wxss` 里那五块 `.mood-*` 是 `moodVars()` 输出的**镜像**，逐字等值由 `验-五档彩色玻璃.js` 钉：

| 档 | 玻璃（面板／底栏那块面） | 底带（左下那一格） | 压在上面的字 | 这三个数从哪来 |
|---|---|---|---|---|
| 墨 `mood-ink` | `#23252C` | `#12141A` | `#F2EFE9` | **今天那一屏**：五个 α 与 `page{}` 逐字相同，`.blk-count` 现网的 #12141A 也照抄 |
| 象牙 `mood-ivory` | `#B1A299` | `#8D7564` | `#352E1D` | `docs/design/毛玻璃参考图三张/` 现量（174×384 那三张的中间那一行像素均值） |
| 天青 `mood-celadon` | `#9BBCA3` | `#799C81` | `#1D3522` | ⚠ **参考图里没有这张**，由雨雾那支往绿的色相推——**这支是我推的，他没拍过** |
| 樱落 `mood-blush` | `#B5A8BF` | `#9E95B0` | `#351D29` | 参考图现量 |
| 雨雾 `mood-mist` | `#A4B0C0` | `#6D8DAA` | `#212431` | 参考图现量 |

三条要说清的：

- **α 梯子一档都不动**：纱 .30／卡顶纱 .60／面 .50／井 .20／描边 .55／第二屏 .72·.42，五档共用同一组数。这一层里那两档 α 现在有**六份**（`page{}` 兜底 ＋ 五块 `.mood-*`），`验-玻璃令牌齐不齐` 每一份都扫——只改 `page{}` 那一份实测不红（反向刀试出来的），所以判据是"六份一个值"。变的是**色相**，不是深浅。
- **只跟着心情变六枚**：纱／卡顶纱／面／井／第二屏那两档（`--glass-veil`／`-veil-band`／`-plate`／`-fill`／`-plate-dock`／`-fill-dock`）。
  **描边 `--glass-hair`（白 .55）、糊 `--glass-bf`、白条 `--glass-jot` 三枚不跟**——五档共用白描边那一份值，这是我自己定的（他没逐枚点过哪几枚该变色），要改是一枚的事。
  另外跟着心情变的还有两族：底栏那块面（`moodChromeOf`，见 §4 那一行）与第二屏那块深色面板（`--stage-face`／`--stage-face-open`），
  加上首屏最上面那一行的那条底（`--stage-strip`，站长 10-14 22:4x「底部加一层同色毛玻璃」先落成那一支玻璃的 .55 平涂，23:5x 追「通栏的渐变毛玻璃，与下方的面板渐变方向相反。浅在下，深在上」，10-15 00:2x 附真机截图打回「太暗了…会浅一点，露出的透多一点」⇒ **现在是面板那条坡反着走：`.94 0% → .16 100%`，两个端点、连续的坡、没有实心平台**。⚠ 中间那一版写成"把面板整条镜像"（`.95 → 56.2% → .16`），连面板底部那 43.8% 的实心地板一起翻到顶上＝一整块黑板，账在 §8.245；字色与面板其余几行同一枚 `--stage-ink-strong`，**底与字必须同档**，否则就是 §8.240 量出来的"纸白压浅玻璃 2.35～2.79:1"那一档）。
  `--stage-strip` 与那两枚 face 一样是 `moodVars()` 出、`app.wxss` 五块 `.mood-*` 逐字镜像；`page{}` 那一族**不带这三枚**（兜底态没有心情，就不该有彩色面）。
- **深色面板那一整面是"一层一条渐变"**（10-14 20:0x 那一刀之后）：`create.wxss` 的 `.stage-panel::before` 铺满（`top:0;bottom:0`、**不写 height**），一条渐变走完 `.16 → .94 → .95`；带高 240rpx 以**百分比停点**表达——闭合那一档 240/548＝43.8%，展开那一档 240/666＝36%，两态各发一条令牌。三条约束钉在这：① 本体必须透明（.95 写回本体就与渐变相乘，band 顶只剩 4.2% 透出，他 10-13 打过回）；② **只许一枚层**（原来 `::before` 高 240rpx ＋ `::after` 从 240rpx 起两枚并排，交界那一行少铺一点 ⇒ 面板正中一条亮线，他 10-14 19:3x「黑色面板中间多了条线」；两枚层重叠又会变成一条暗线，所以只能并成一条渐变）；③ 停点不写 rpx（长度落在 `linear-gradient()` 参数里，微信换算不保证跟得进去，换算不下来整条 background 掉下来＝面板透明，看不出来）。
- **小件不能和面板同色**：彩色那四档的 piece 取"玻璃色往白并 .55"，因为同色的 .50 压在同色的 .95 上等于没画；墨那一档走另一支（纯白），五个数与 `page{}` 逐字相同。
- **心情与壁纸是一对**：`cycleGlassMood()` 按下去同时 `setWallpaper(m.theme)`，所以整屏（页面底、卡片、底栏、玻璃）一起换——他要的是"一起换"，不是只换面板那一层。墨与象牙共用 `tint-paper`，这一对**只能由本机那一档区分**（服务端那一列表达不了），读的时候先跟壁纸对一次账：对不上以壁纸为准（`app.js` 的 `glassMood()`）。

### 3.5 头部那张形象图的落点：全站一枚锚点（R15）

列表与「我的」两屏的那张头图都走 `poster.bandGeom(w, h, boxH)`：**按宽铺满（750rpx），超出盒子那截的 15% 顶给上面**（留头顶空间）。
`boxH` 现在**只有一枚**：`poster.HEAD_IMG_H = 740`。

- 为什么收成一枚：那句 `top = -(byWidth - boxH) × 0.15` 里带着 boxH，两页各写一个数＝同一张照片两页顶边不一样＝**切 tab 时背景图上下跳**。
  实测过：两页分别写 740／646 那态，列表图顶 −1.9rpx、「我的」−15.4rpx，差 **13.5rpx ≈ 7.0 视口 px**（`docs/工具/探-头部图两页对位.js`，改前红、改后绿）。
- 取 740 不取 646：取小的那一档，列表玻璃带 646～740 底下会没图（"中间镂空"他抓过）。所以对齐方向是**「我的」往下挪去配列表**，列表不动。
- 带高与锚点是两件事：列表 `.head` 542 ＋ 延段 198、「我的」`.head-band` 646，这两笔账留在各页 wxss 里（由 `验-玻璃令牌齐不齐` 钉等式），**不再递给 bandGeom**。
- 首页那一屏不吃这一枚：它是 `.page-bg` 全屏 `aspectFill`（750×100vh），本来就没有"带"。
- 首页详情窗那一态仍递 `this._webviewH()`（图要贯穿整屏，站长 10-03 拍的），算法同一条、不分第二份公式。
- **那只盒子有封顶（10-16 审计第八条）**：`poster.BAND_MAX_H = 3000`。按宽铺满那条式子原来没有任何上限，
  1080×20000 那张微信拼长图（约 1:18.5）会算出一只 **13889rpx ≈ 5.8 个视口高**的 `<image>`——
  而长截图正是这个产品最自然的素材。封顶之后 1:4 以内（含 9:16、1:2、1:3、正好卡在 3000 那一档的 1:4）
  那一串 style **逐字不变**，只有超过 1:4 的才开始改取景。
  ⚠ 两处必须说在前面：① 3000 是**我选的数，不是量到的平台上限**，那块白我也没在真机上复现过（症状是从算式推的），
  这一刀钉的是"不许再长出一只一万三千 rpx 的盒子"；② 封顶之后 `aspectFill` 居中那一刀取的是**中段那一条**，
  不再是整篇 15% 那一档——要连取景一起保住原样，得在选图那一步就裁掉长图（要 `wx.cropImage`，那条得真机验），**他没拍过，没做**。
- **取景只有一处说法**：上面那只盒子的算法 10-16 起抽成 `poster.bandBox(w, h, boxH, anchor)`，
  `bandGeom` 只是它的排版输出。为什么要抽——`utils/imgBrightness.js` 要照**同一只盒子**算"屏上那一条落在原图哪几行"来定字色深浅，
  它原来自己抄了一遍 `(750 * h) / w`。两处各写一遍的代价不是猜测：把第二份真跑起来量一次，
  1:18.5 那一档画面覆盖的是画布**第 13..15 行**、抄的那一份读的是**第 4..6 行**，**判出来的深浅直接相反**
  （`验-头部图封顶.js` 反向②就是这一把，两个数都是它跑出来的，不是我算的）。`HEAD_IMG_H`／`BG_ANCHOR` 交出来的是同一条路。

## 5. 退化行为（说准，别写假话）

- **某一枚 `--glass-*` 在那套壁纸里没定义** ⇒ `var()` 替换后非法值在 CSS 里是 IACVT＝整条声明按 `unset` 用，

- **机型不认 `backdrop-filter`** ⇒ 只剩一层 .30 白纱压在照片上、不糊。要不要为这一档加 `@supports not (...)` 抬 α，

- iOS 的 WKWebView 只认 `-webkit-backdrop-filter`，所以每一行 `backdrop-filter` 后面**必须紧跟** `-webkit-` 那一行（尺子逐页钉）。

## 8. 框框抬起来那一枚投影（10-14 20:5x 起全站一枚）

站长那句：「笔记列表和笔记卡片框框与背景之间有一点向上阴影，这个是对的，要复制到其他页面，首屏，二屏，关于，设置等都要加上阴影，风格和高度全局一致。」

**一枚令牌，三处消费**——值只写在 `app.wxss` 的 `page{}` 那一枚 `--sh-lift`（正本就是列表页那张纸卡 10-09 起身上那一串 `0 -12rpx 28rpx rgba(18, 20, 26, 0.16)`，一个字没改），页面里只写 `box-shadow: var(--sh-lift)`：

| 落点 | 管到哪几屏 |
|---|---|
| `pages/index/index.wxss .sheet` | 笔记列表／笔记卡片（正本，像素零变化） |
| `pages/me/me.wxss .sheet` | 设置、关于两档——两块内容都排在这枚名片行之后，一处管两档 |
| `pages/create/create.wxss .stage-panel` | 首屏、二屏——两屏是同一枚元素的两个高度（548／666），一处管两屏 |

**为什么是"一处"而不是"逐页抄"**：他这句要的是"风格和高度全局一致"。逐页抄字面量＝四份真相，下次调必漏改（这条正是 `验-向上阴影全局一枚` 那把反向刀要抓的）。

**钉法**：静态 `验-向上阴影全局一枚.js`（正向 8/8、反向 7/7 有牙：删令牌／改正本／页面里另抄一份／撤掉某一处／同屏另一档规则补 `box-shadow: none`）；真跑在 `验-五档彩色玻璃-真跑.js` 第⑥节（三屏各实读一次计算样式，并钉**三处逐字相同**）＋第⑦节量像素。

**没做的（不在他这句里，要动先问）**：详情浮窗 `.float-sheet`、三枚居中弹窗、卡片模板那一屏、笔记卡片页——那些不是"通栏框框压着背景"这一类（弹窗四周都离底，投影方向不是"向上"）。
