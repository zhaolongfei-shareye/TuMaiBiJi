## 1. 一处出口：`app.wxss` 里那一组 `--glass-*`

| 令牌 | 值 | 用在哪 | 谁拍的 |
|---|---|---|---|
| `--glass-veil` | `rgba(255,255,255,0.30)` | 所有玻璃面的白纱（卡顶、名片行、录入面板外框、三枚居中弹窗） | 他（「α = .30」，校准条上点的那一档，**全站唯一**） |
| `--glass-bf` | `blur(23px) saturate(1.8)` | 上面那些面的 `backdrop-filter` | 效果图第 **59** 行那档（`--g-blur: blur(46px) saturate(1.8)`），按"图上 1px＝1rpx≈0.52 真机像素"换算（46→23）——**换算这一步是我做的，他没逐字点过数** |
| `--glass-hair` | `rgba(255,255,255,0.55)` | 玻璃面的白描边（`inset 0 0 0 2rpx`）与井的边 | 效果图，同上 |
| `--glass-fill` | `rgba(255,255,255,0.20)` | 录入面板里那三口"井"的底（输入框／右滑条／两枚小圆） | 效果图，同上 |
| `--glass-jot` | `rgba(255,255,255,0.38)` | 白条那一档（`.blk-jot`／`.blk-strip`），配 `blur(10px) saturate(1.6)` | 效果图，同上 |
| `--glass-fade-card`／`--glass-fade-page` | 本套壁纸的 `--bg-card`／`--bg-page` @.62 | 渐退那一段的中间色标 | 效果图第 **229／332** 行那两枚色标（**必须跟着壁纸走**，写死白色在天青那套会露馅） |

五块皮肤（`page` ＋ 四套 `.theme-*`，其中雨雾那套的类名是 `.theme-blue`）**各存一份镜像值**，由 `验-玻璃令牌齐不齐` 逐枚钉：少一枚、或某一套里被改成别的色，当场红（反向刀 **10 把**，10/10 有牙）。

## 2. 闸门：只有铺了形象图那一态才有玻璃

规则一律写成 `.container.has-bg <那一枚>`。三页的 `.container` 现在都带这枚闸（`me.wxml` 是 10-11 才补上的——
之前那条规则在这一页**一条都没落上**，纯空转）。没铺图 ⇒ 这些面退回各自的纯色底，界面不残缺。

**页面里凡挂了模糊的面，底色必须是 `var()`**，不许出现第二支白纱字面量（同一条尺子扫）。

## 3. 四处玻璃面

### 3.1 列表卡顶（`pages/index`）
`.container.has-bg .sheet` 的 `background` 是**同一张渐变的四个色标**（不是叠一层皮）：

```
0 → 158rpx  纯白纱 var(--glass-veil)
158 → 198   渐退到 var(--glass-fade-card)
198 → 238   退到 var(--bg-card)（实心）
```

- 白纱那一段盖住的是**两枚 tab 那一行＋分类那一行**；实测两行下沿 138rpx、第三行字顶 170rpx（都相对卡顶），158 落在中间。
- 底下必须有图可糊：`GLASS_BAND_H = 740`（＝头部 542 ＋ 罩层延段 198）递给 `poster.bandGeom`，图底实测 748rpx ≥ 实心线 739rpx。
- 延段挂在 `.head-scrim::after`（`top:100%`），**跟着「调亮度」那枚 opacity 一起沉**；值取罩层渐变的末档 `rgba(18,20,26,.52)`＝只延长不换色。

### 3.2 「我的」名片行（`pages/me`）
同一条式子，四个数是 `0 → 56 → 108 → 144`，末档是 `--bg-page`（这一屏那张面用的是页面底，不是卡底）。
`GLASS_BAND_H = 646`；这笔账分居四处（`.head-band` 高 646／`.sheet` margin-top −144／`.head-scrim` bottom 104／`.head-scrim::after` 高 104），由 `验-我的页改版-真跑` 与 `验-玻璃令牌齐不齐` 两头钉等式。

### 3.3 录入面板与第一屏那三块（`pages/create`）
| 哪一枚 | 现在是什么 |
|---|---|
| `.panel` 外框 | 白纱＋`--glass-bf`，描边走 `--glass-hair`；自己的那道投影留着 |
| `.card` 内框 | **转透明**（控件直接落在玻璃上＝他那句"集体变半透明…沉浸式"） |
| `.field`／`.sld` 两口井 | `--glass-fill` ＋ `--glass-hair` 边 |
| `.mini-c` 两枚小圆 | `--glass-fill`（它本来就没有边，所以只换底） |
| `.blk-person`／`.blk-stat-notes`／`.blk-stat-cards` 第一屏那三块 | 白纱＋`--glass-bf`＋`inset 0 0 0 2rpx var(--glass-hair)` 那圈白内环 |
| `.blk-jot`／`.blk-strip` 白条 | `--glass-jot`＋`blur(10px) saturate(1.6)`（比大面轻一档） |
| `.hint-bubble` 报错气泡 | `--cp-ink-78`＝`rgba(35,37,44,.78)` **墨面**＋`--glass-bf`（他 10-11 拍「不用」＝不换白纱，见 §6.4） |

**不碰的**：快门那枚橙圆、两枚小圆里的图形、粘贴图形、三枚标签的字。
⚠ `.mini-c` 这一枚 10-11 修过一次**静默不生效**：规则原来写的是 `.mini .c`，而 markup 是 `class="mini-c"` ⇒ 命中零个节点。

### 3.4 三枚居中弹窗
`.ci-card`（卡片上的信息）／`.pwd-card`（私密密码）／`.me-email-card`（我的邮箱）各挂 `glass-dialog`，
整块均匀白纱＋模糊，**不做渐变**——他 10-11 拍「弹窗不用」（§6.2；它们四周都压在暗遮罩上，底下没有"接纯色"那一说）。
这三枚里的**说明字**（`.ci-hint`／`.pwd-scene`／`.me-email-scene`）在 `has-bg` 那两枚闸以内提到整档墨，
这是他那句「甲」落的两行样式（§6.3）；**闸外（没铺图那一态）和 `pages/share` 那屏的淡墨一个字没动**。

## 5. 退化行为（说准，别写假话）

- **某一枚 `--glass-*` 在那套壁纸里没定义** ⇒ `var()` 替换后非法值在 CSS 里是 IACVT＝整条声明按 `unset` 用，
  而 `background` 简写会把底色归成 `transparent` ⇒ **整张卡透空露出原图**，不是"退回实心"。所以令牌必须五块皮肤齐。
- **机型不认 `backdrop-filter`** ⇒ 只剩一层 .30 白纱压在照片上、不糊。要不要为这一档加 `@supports not (...)` 抬 α，
  他 10-11 拍**甲＝不加**（§6.1），所以代码里一条 `@supports` 都没有，他拍的 .30 全站一个值。
- iOS 的 WKWebView 只认 `-webkit-backdrop-filter`，所以每一行 `backdrop-filter` 后面**必须紧跟** `-webkit-` 那一行（尺子逐页钉）。
