1 产品介绍

1.1 产品简介

图麦笔记是一个把你已经看到的好内容，变成能用下去的笔记的工具。

你大概有过这种时刻：读到一篇文章、看到一张图、听人讲了一个方法，当时觉得有用，随手存了。然后就想不起存在哪儿了。存下来这一步不难，难的是存下来之后还能用上。

图麦笔记做的就是中间这一段：

随手记下来 → 自动整理成清楚的笔记 → 需要时找得回来 → 排成一张能分享的图 → 别人扫一下，能把它存回他自己的笔记里

四条它坚持的原则：

  1. 不要求你先写。 三条录入路——拍照截图、贴链接、贴文字——都是把你手上已经有的东西接进来。
  2. 原文永远留着。 自动整理出来的是标题、摘要、要点、标签，你的原文一个字不动，随时能回去核对。
  3. 公开是你主动选的。 笔记默认只属于你。要给别人看，必须你明确操作一次。
  4. 整理只是辅助，不是替你判断。 自动摘要可能不准，所以原文和出处一直在。

一条必须先知道的事实：小程序端没有任何 wx.cloud.callFunction。两只云函数都由自建后端调用；小程序只碰云开发存储（miniprogram/utils/cloudUpload.js:17 环境 id、:64 uploadFile）。看代码时别去找"前端调云函数"的地方，没有。

架构层的三条设计纪律（后面每一节都在遵守它们，先在这里定下来）：

  1. 长任务一律异步。录入／整理／外链贴图落账都走队列，绝不在请求线程里同步调上游——这是图麦那条线踩过的真教训（检图同步跑在事件循环里把整站按住十秒）。
  2. 云函数当哑管道。规则、鉴权、重试、记账全在自建后端；云函数只做一次格式转换。好处是换模型、换供应商时不动客户端。
  3. 唯一来源。色板、文案、域名、版本号各只有一处定义（§2.2）。第二处出现就是漂移的开始。

3.1 录入

要解决的问题：好内容散在相册、聊天记录和网页里，先要能把它们不费力地接进来。

屏上所见：打开小程序，底部三个标签：新建 / 笔记 / 我的。记录从"新建"开始，一块面板里切换三种起点，切换入口不会把你跳走。

档怎么进一次能进多少
拍照或截图从相册选图或直接拍一批最多 9 张；系统先读图上的文字，再走同一套整理流程

3.2 整理

要解决的问题：存下来只是把东西搬了个家，"整理成能看懂"才是能用的前提。

屏上所见：不管从哪条路进来，出来的都是同样四栏。

标题     一句话结论
摘要     这段内容在讲什么
要点     编号的几条，可长可短
标签     帮你之后归类和搜索

你的原文单独留着，和整理结果并存。想核对机器有没有理解偏，回原文看就行。

「原文翻译」这一枚开关：只有"直接写"这一路有它，而且要把面板展开才看得见，默认关着。开着时，不管贴的是英文、日文还是阿拉伯文，整理出来的四栏写成中文；关着时，整理结果跟着原文的语言走。

规则与边界：

  • 整理没成功，笔记照样存下来，只是少那四栏——不会因为你贴的东西机器读不了，就把你的记录吞掉。
  • 它不翻译原文。原文一个字都不动、不译，它只管"整理结果用什么语言写"。
  • 它不在链接和截图那两路上。那两路的输出语言由模型自己判断，不受这枚开关影响。
  • 它是一次性的。存好一篇之后开关自动归零，不会默认带到下一篇。
  • 界面语言只有中文和英文两种，跟着微信语言走。"多种语言整理成中文"说的是上面这个能力，不是界面有几十种语言。
  • 摘要可能不准；这产品不做"替你判断"。

技术链路与现状：

  • 开关落点：create.js:124 writeTranslate:false；create.wxml:295 那条 wx:if="{{active === 'write' && panelOpen}}" 就是"只在文字档＋展开态可见"的实现。

3.5 分享、公开与转存

要解决的问题：一张图发出去就断了；产品想要的是"看到的人也能把它变成自己的笔记"。

屏上所见：

你点分享、创建公开之后——系统为这一篇存一份内容快照，公开的是那一刻的标题、摘要、要点、标签和配图，不是你的整个笔记库；生成一个公开入口，别人不用登录也能读；同一篇笔记只保留一张有效的码，不会越分享越多份。

别人扫你的码——打开是一个公开落地页，先读到内容，不用先注册、不用先装什么；页面上有一枚「存入笔记」，按下去这一篇作为独立副本存进他自己的笔记库，之后他怎么改、删、再分享都跟你无关；你的其他笔记他看不见；页面上有举报入口。

这条链是双向的：你转存别人的，和你被别人转存，是同一个机制。你的笔记被别人转存了几次，会在你列表那一格留一个标记。

规则与边界（这一段是整个产品里唯一"对外"的一层，边界必须说清楚）：

  • 你之后改了笔记：已经发出去的图片和已经被别人转走的副本不会跟着变。 快照就是快照。
  • 你撤回公开：公开入口关掉，别人再打不开。但这收不回已经转存走的副本——那已经是别人的笔记了。
  • 隐藏图上的小程序码 ≠ 撤回公开。前者只是让这张图不带入口，后者才真正关掉访问。
  • 个人记录 ≠ 默认公开。公开永远需要你做一个明确动作。
  • 分享出去的链接不设过期，一直有效，直到你主动关掉。
  • 私密笔记不能分享（§3.6）。

技术链路与现状：

学生与阅读者。 课堂截图、文章摘录存了一堆，复习还是要重读一遍、手抄一遍、再想归到哪。图麦笔记把这三步合成一步：扔进来，出来就是带编号要点和标签的笔记，之后按关键词搜得到、按分类翻得到。

年轻创作者。 有观点、有资料，但要发出去还得花时间把文字排成一张好看的图。这里选好内容，挑一套卡片样式，直接出图存相册。

日常记录者。 旅行攻略、灵感、生活清单散在相册和聊天记录里。首屏一个入口，拍一张、贴一段就进来了。

7 产品边界

写清楚，免得有人期待错。

  • 不做手写识别。 "写"那一档是你打字或粘贴，不是识别笔迹。
  • 不做商品识别、不做估价。 拍照读的是图上的文字。
  • 不做语音录入。 这条能力已经下线。
  • 不支持 HEIC 格式的图片。
  • 不做多端实时同步。 手机是主，云端是备份与找回，不是多人协作。
  • 没有团队、席位、权限管理。
  • 不做内容审核豁免。 你发布的内容会过内容安全检查；违规的会被挡下并提示。
  • 卡片上的 AI 生成标识和来源信息不提供"去掉"的付费档。
  • 不承诺任何一篇内容"永久保存"。 图片有留存周期，公开链接以你主动撤回为准。
