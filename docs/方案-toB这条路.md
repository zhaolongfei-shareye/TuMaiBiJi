# 图麦笔记 to B 这条路（10-20 他一句「如果图麦笔记 H5 要改成 to B，能否给个建议」）

**结论先给**：**不建议把产品改成 to B，建议把"客户画像"改成 to B。**
理由不是省事——是我把这四张表现场读了一遍：**产品真正的资产已经长在"对外发布"那一路上了，而"企业协同"那一层一行代码都没有**。
要走 to B，最便宜的那条是把已有的发布层卖给**靠内容吃饭的经营者**；最贵的那条（团队知识库）会把他手上所有读口重写一遍。

分工照旧：本路只出方案与判据，**不写码、不部署、不出包、不提审、不动现网**。

## 一、先把家底读清楚（今天当场从代码里取的，不是印象）

**好消息：地基里已经有"对外那一半"。**

- **`backend/app/models/share.py`**：`shares` 这张表把 `title / summary / tags / key_points / key_links / source_url / author_name / cover_asset_id`
  **全部冗余存了一份快照**——公开落地页读它、不读 `notes`。这就是天然的"发布单元"：一条可撤回（`is_active`）、可过期（`expires_at`）、
  可被扫码匿名打开、还带举报表（`share_report.py`）的**对外页**。要加"企业门面"，不用从零造发布模型。
- **`backend/app/models/note.py`**：`imported_from`（JSON）已经在记"这一篇是从谁的分享转存来的" ⇒ **内容溯源链现成**，
  "谁的资料被采纳进了谁的库"这件事今天就有数据，只是没被讲出来过。
- **`backend/app/models/invitation.py`**：`inviter_id / invitee_id / source_note_id` ⇒ **"谁把谁带进来、靠哪一篇带进来"已经有表**。
  这是"拉人"的起点，但注意：**它只有归因，没有归属**（不是成员关系表）。
- **账号层**：`users.account_id` ＋ `account_identities(provider, provider_uid)`  unique 索引那一行已经写死过——
  **平台 id 不当业务主键**，所以"加邮箱登录"是插一行 provider，不是把历史数据搬家。**这一条让 to B 的"多人"有一块地基，但地基不等于楼层。**
- **模板下发**：`poster_template.py` ＋ 现网 `POSTER_TEMPLATES` 闸门（`deploy.sh` 1.7）——**给某个行业出十套门面＝灌种子，不走小程序发版**，
  这条通路 10-19 已经双端验过（服务端探针 66/66、客户端 10/10、`recipeSource` 全 `remote`）。

**坏消息，三条都很硬。**

- **`grep -rniE "organization|org_id|tenant|team|workspace|member|role|permission|collab" backend/app --include=*.py` 命中文件数＝0**。
  ⇒ **组织、成员、角色、权限、协同，今天一行都没有**。这不是"差个页面"，是**差一层模型**。
- **所有业务表都以单个 `user_id` 划界**：`notes.user_id`、`categories.user_id`、`shares.user_id`。
  要做"多人共用的池子"，要么引入 owner_scope（每个读口都要跟着改），要么把这些列的语义改掉（迁移＋全量回归）。**工作量在这儿，不在界面上。**
- **私密的粒度是"账号"不是"篇"**：`users.private_password_hash` 一把密码开全账号的私密内容。
  ⇒ **不能拿它当企业权限用**（一人一把锁，多人就无法区分谁能看）。这一格要 B 侧权限，得重做一套。

## 二、三条路的形，和各自真正的代价

### 甲（我建议）：**不改架构，改客户画像**——卖给"靠内容吃饭的人"

**是什么**：产品继续是个人的"链接/截图/网页 → 结构化笔记 → 一张能分享的卡"，但对外叙事与付费对象换成
**一人公司／工作室／门店／老师／自媒体／知识工作者**——他们的"产业经营痛点"就是"每天都要把外面看到的资料变成能发出去的东西"。
**这句话是逐字对着珠海那条方向写的**（「轻量化 AI 工具」「依托差异化技术解决产业经营痛点，实现低成本部署与快速商业化」）。

**要动的（都是加法，不动 `user_id` 语义）**：
1. H5 第 0 段（已定稿、零阻塞）——公开只读页就是"能挂在他们自己域名／公众号菜单／门店物料上"的那一页；
2. **甲里唯一的新模型：`publish_pages`（一页挂多篇）** ＋ 一张关联表，把今天"一篇一个 `share`"升级成"一辑一个门面"；
3. **行业预设**＝往 `poster_templates` 灌几组行业模板（餐饮探店／课程资料／行业情报／旅行攻略），**零发版**；
4. 收款走**微信虚拟支付个人版道具直购**（卖模板包、卖多语言整理额度），**不签企业合同、不开票、不做实施**。

**收益**：4–8 天能出样子；叙事直接能拿去报珠海、报 36 氪、报技术经济学会；主体不用动。
**风险（必须写在这儿）**：
- 虚拟支付个人版的禁项里有「**需办理电信业务相关资质的服务**……**信息发布平台、信息搜索查询**」这条（10-19 逐字读到）
  ⇒ **卖的是"工具与模板"，不是"发布服务"**，一句话写歪就踩禁项。
- 我 10-19 读到 `quota.py`：`BASE_QUOTA=100` 是**起始值不是上限**（10-01 他拍的"笔记不限量"）⇒ **甲这条路不能靠"容量"收费**，
  只能靠"模板／多语言／导出／协作门面"这类功能收费。这条是货架设计的前提。

### 乙：最小多人（工作室版）——**这才是真 to B，也是真要花钱的那条**

要加：**org / org_member / role / 审核态**四张表＋迁移，然后把 `notes`／`categories`／`shares` 三条读口按池子重写；
再加"H5 端后台"（今天 H5 计划里只有登录与阅读，没有管理面）。**我给的诚实估算：开发那一路 2–4 周**（不含设计）。

**开工前必须先过门的三格**（都在下面第三节，不是我劝退）：主体、发票与对公收款、AI 按量成本。

### 丙：真企业 SaaS（团队知识库＋权限＋SSO＋审计＋私有化）

**我不建议**，列出来只为让他看到边界：这要吃掉一个专职实施与销售，而他"每项目不超过 3 人"。而且这一条会跟他 iPhone 那条线（本地为主、无社交）**口径打架**。

## 三、三把硬门（to B 真正的墙，一道比一道贵）

1. **主体与发票**。企业采购要合同＋发票；个人主体开不出对公发票。
   ⚠ **这一格我今天没有读官方文档，是按规则判断**，要落地前必须核实；但方向很清楚：**微信虚拟支付个人版只能小程序内道具直购、月支付限额 10 万**，
   **它替代不了对公收款**。⇒ **真要乙/丙，得先有个体工商户或公司**。这一格和珠海那场比赛其实是同一格：**"要不要注册一个主体"这个决定，本来就该由 to B 逼出来，不该由比赛逼出来。**
2. **AI 成本结构**。成长计划那 10 亿 Token 逐字「**AI 资源包仅限小程序和云函数中使用，其他来源均不可使用**」
   ⇒ **H5 与 to B 那一路吃不到免费包**（他 10-19 已拍"AI 额度我自己付"）。
   to B 是**按人头／按调用量**卖，而单次提炼的 Token 成本他材料里那几个数（1,900 Token／次）**从没回读过**——
   **不先把单位成本现算出来，卖得越多亏得越多**。这是乙的开工前置，不是上线后再补。
3. **对外内容的机器审核**。`msgSecCheck` 文本可用，但个人主体未上架**只有 100 次/天**（打光是静默 fail-open，10-16 记过）；
   **`imgSecCheck` 个人主体拿不到**（那道硬门记在 `wtsj-platform-capability-costs`）。
   ⇒ 一旦"企业门面页"上跑的是**图片卡片**，我们**没有机器审图这一道**，只能人审。
   **一人公司吃不下人审**，这是 to B 对外发布最实际的风险，也是我建议"甲只做个人自投自用、不做 UGC 池子"的原因。

## 四、负面清单（这几件事我不替他做，也不许顺手做）

- **不为那场比赛临时改产品**。为了"契合方向"去加一层假的组织概念，是我上一句"会被问穿"的反面版本，更糟。
- **不许在任何对外材料里写"团队共享／多人协作／企业知识库"**——`grep` 命中 0 个文件，**代码一行没有**。
- **不在没有主体之前对企业报价、签合同、承诺开票**。
- **不把「支持以上平台的图文」那半句搬进 B 侧材料**：现网矩阵里只有公众号那一格站得住，小红书 5/5 落登录壳、微博 302 访客壳、知乎 403 反爬壳、**抖音与视频号一次都没测过**。
  to C 材料上都算假话，挂到企业门面上风险更大。
- **不拿 `private_password_hash` 当权限模型用**（粒度是账号，不是篇，更不是人）。
- **不在甲里引入"容量收费"**（10-01 那条"笔记不限量"是他拍的，动它就是打他自己的脸）。
