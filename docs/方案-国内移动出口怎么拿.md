## 一、最要紧的那枚读数先摆出来：单个移动出口是**按请求掷硬币**

本机这条真实移动出口（`〈本机家宽出口 IP·已抹〉`，广东广州移动），同一条带 `xsec_token` 的小红书笔记，连打 50 次：

| 这一把怎么打 | 次数 | 命中真笔记 | 前半 vs 后半 | 延迟中位 |
|---|---|---|---|---|
| 分享址·带令牌，间隔 0.4 秒 | 20 | **13/20** | 7 vs 6 | 477 ms |
| 短链·跟完跳转，间隔 0.4 秒 | 20 | **10/20** | 6 vs 4 | 800 ms |
| 分享址·带令牌，间隔 3.0 秒（慢速对照） | 10 | **6/10** | 3 vs 3 | 465 ms |
| 合计 | 50 | **29/50 ＝ 58%** | — | — |

**只有两种形状**：真笔记 69,040 B、登录壳 36,211 B，**交替出现、不是单调变坏**；
把间隔从 0.4 秒抬到 3 秒**也没有回血**（6/10）。
⇒ 结论：**这不是"IP 被我的流量刷污了"，而是站方对每一发请求单独掷硬币。**
⇒ 直接后果：**一个住宅 IP 撑不起"用户粘一条就能存图"这句承诺**（今天 50 发里 21 发失败）。
⇒ 顺带一条：跨这 4 分钟、50 发请求，那枚 `xsec_token` **一直有效**（长期时效仍未量）。

**算术而不是读数**：如果失败的那一发当场重试一次，按 58% 的独立命中率算，成功能抬到 ≈82%
（1 − 0.42²）。这是拿今天的比率推的，**我没打过"重试一次"这一把**，要落码前必须先量它，
因为一旦"重试"变成同一 IP 短时间内的第 2、3 发，站方完全可能改成按次数判——那 58% 就不再是 58%。

## 二、要"稳态服务"就必然走向多 IP 轮换 —— 这一步是整件事的性质转折点

58% 要做成产品，唯一办法是让失败那发换个 IP 再来 ⇒ **需要 IP 池** ⇒ 形态上就是"动态住宅/秒拨"那一类服务。
而这一类服务在中国大陆的公开定性（不是我给的判断，是官方口径与判例）：

- 公安部 2022-05 部署**「清理整治动态 IP 代理服务乱象」**（天目新闻转载那份通告）。
- 北京朝阳政府网转载《反侦查手段堪比谍战片，"秒拨IP"成网络黑产地基》：云南一案**已宣判**，团伙用大量宽带短时间制造**百万量级 IP 池**绕开限制。
- 人民网《"IP属地"想改就改？小心违法！》：警方打掉为境外不法分子提供动态 IP 代理／动态 VPS 的团伙，**抓获 34 人**，查获 24 个秒拨 IP、VPS 平台。
- 央视新闻那篇把话说得最准：**对普通网民这样用代理上网，法律中没有相关处罚规定，但请求会经过代理服务器传递，有风险。**
- 百度百科那一条把「动态IP代理服务」直接归入《网络安全法》《刑法》语境下的网络运营者入网服务类型。

⇒ **运营方有明确判例；使用者一侧目前没有专门罚则。** 但我们如果买它，位置是"使用者"，
风险不在这条读数里消失：**用户粘进来的那条链接会经过第三方代理机器**（它看得见完整 URL 与返回的正文），
这是这条链上新增的一个数据暴露面，比"我们服务器自己抓"多一个外人。

## 四、我这一条线上的判断（他可以驳）

1. **第 1 条我劝你别花钱**：换云不改变"机房 IP"这个标签，形状与现网一样。
2. **第 2 条我不建议**：不是道德判断，是**收益撑不起这个形态**——买了也只是 58% 那一档，
   要多 IP 才稳，而多 IP 就是被点名整治的那件事；再加一层"用户链接经第三方"。
3. **第 5 条本来是六条里唯一"零成本、零外部依赖、出口天然是住宅"的那条，16:3x 被读数当场判掉了**（第六节）：
   真实小程序 `wx.request` 的 UA 带着 `MicroMessenger`，站方直接把请求送去微信授权那一页。
   ⇒ **六条里"免费"的那条没了，剩下的全都要花钱或要担形态风险。**
4. **第 3、4 条（自建一条家用移动出口）技术上就是今天的 58%**，作为"能不能通"的证据够了，
   作为"能不能当服务"不够：50 发里 21 发失败，且**失败会随全站流量集中在同一个 IP 上**。
5. 还有一件账他没算过但我必须说：这六条**全部只解决小红书一族**。
   微博那一族卡的是"渲染取地址＋带 Referer"（**跟出口无关**，本机现网都证明了访客渲染能过闸）；
   知乎那一族卡的是登录墙（**换出口也过不去**）。⇒ 花一个月费买出口，买到的是"一族 58%"。

## 五、这一轮我明确没做的事

- 没买任何代理、没注册任何服务商、没申请任何账号、没动服务器一行配置、没部署、没出包、没推远端。
- 没测带用户 cookie 那一档（上一条已经定：不拿你或用户的账号做实验）。
- 第 5 条**没有真机跑**，用的是更硬的一枚替身：从我们自己后台访问日志里抄出来的**真实安卓小程序 `wx.request` UA**
  （`… MMWEBSDK/20260902 MicroMessenger/8.0.79.3180(0x28004F7A) WeChat/arm64 Weixin … MiniProgramEnv/android`，
  那一条打的是 `POST /wtsj/api/auth/wechat`；日志里的 `MMWEBID` 与 devtools 那串 `token/…` 属于设备／会话标识，**没抄进这份文档**）。
  ⇒ 这一枚比"我在真机上试一次"更贴近真实用户发出去的那一发，因为**它就是真实用户发出去的那一发的头**。
  还缺一格：**iOS 真机小程序的 UA 在日志里没有样本**（那 265 条 iPhone 全是 `wechatdevtools` 模拟器），
  iOS 那一头如果 UA 里也带 `MicroMessenger`（大概率），这一条在两个平台上都是死的。

## 六、第 5 条为什么当场判掉（16:3x 补测，两入口两形状）

| 用哪一枚 UA 打 | 打分享址（带令牌） | 打短链（跟完跳转） |
|---|---|---|
| **桌面生产头**（我们服务器那套） | ✅ 58% 拿到笔记（第一节那 50 发） | ✅ 50% |
| **真实安卓小程序 `wx.request` UA** | ❌ 302 → `open.weixin.qq.com/connect/oauth2/authorize?appid=wx24d4366d90ac53a8&redirect_uri=…xiaohongshu.com/discovery/item/…` → 200／**1,033 B**／title「抱歉，出错了」 | ❌ 同一页 |
| 纯微信内置浏览器 UA（`MicroMessenger/8.0.50`） | ❌ 同一页 | ❌ 同一页 |

⇒ **同一台机器、同一个出口、同一条带令牌的地址，只把 UA 换成小程序那一枚，58% 直接变 0%。**
⇒ 机制与 §8.350 那条对上：站方看到微信 UA 就走"用户在微信里授权给小红书"那一支，
而 `wx.request` 是一个不执行 JS 的 HTTP 客户端——**它永远走不完那支**，所以这条路不是"暂时没配好"，是形状上不通。
⇒ 附带一条给未来的人：**"把第三方域名填进 request 合法域名"这一关字面上能过（官方只要求 ICP 备案），
真正的墙在站方看 UA，不在微信看域名。**

## 七、这一轮研究的落点（一句话＋三条）

**一句话：想稳定拿到小红书，需要的是"多 IP 轮换＋失败重试"，而"多 IP 轮换"在大陆就是被公安部点名整治的那个形态；
唯一一条免费又天然住宅的路（用户手机自己发）今天被读数判死了。**

1. 六条候选现在的状态：1 大概率白花（未测）；2 形态风险＋用户链接经第三方；3、4 就是今天那 58%，
   且各自带一条运营硬伤（家宽禁服务器化／物联卡常被停）；5 **已被读数否掉**；6 个人主体不通。
2. 58% 这一枚数是今天 50 发打出来的，**慢速不回血、快速不单调衰减** ⇒ 它是站方按请求掷硬币，不是我们把 IP 用脏了。
   要往上抬只有重试与换 IP 两把，**重试那把还没量**（一量就可能把"按请求判"变成"按次数判"，这一格必须小心）。
3. 就算全花出去，**买到的也只是小红书一族**：微博那一族要的是渲染＋带 Referer（与出口无关，已证），
   知乎那一族要的是登录态（换出口也没用）。⇒ 这笔钱与"截图那条 API 装不装浏览器"是两笔独立的账，别捆在一起拍。
