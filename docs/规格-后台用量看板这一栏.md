## 三、口径定死（四条正的＋一条附带，每条给唯一答案与理由，不摆甲乙）

**① 一个产品一张卡，屏上不存在"总用量"。**
次数（提炼／送检）与余额（元）加在一起没有任何含义，所以两张卡各写各的、各念各的单位，
判据里直接钉「`总用量` 这个字不许出现在这一段」。这条不是审美，是他那句「不要和小程序搞混了」。

**② 上游只给余额 ⇒ 不画曲线，也不假装画。**
要曲线就得按时采样余额再取差值：新表＋定时任务＋一套"采样点缺失怎么念"的口径，三件都不在他这句话里。
屏上因此明写这一句（不藏在小字里），他要不要那条曲线是一句新的决定（第七节）。

**③ "没有钥"包含"仍是占位符"那一种。**
判据共用 `llm.key_usable()`（`spot_draft.py:current_key()` 吃的也是这一句），不在本栏再造第二把尺子。
把占位符当"钥在（长度 24）"送出去，换来的是一次 401，屏上念"这把钥打不通"——那与"根本没有钥"是两句话，
操作者会去查一把本来就假的钥。

**④ 没人在记的那一档念"还没开始记"，不许念 0。**
`calls_today` 在库里 `roammark_draft` 一行都没有时回 **null**，页面念"这一档还没开始记"。
0 的意思是"今天没人用"，而真实情况是"这一件事没人在记"——两句话指向相反的决定（前者像"没人要"，
后者是"闸还没接"）。这一条是 `usage_board.board()` 文件头写死的判据，不是页面文案。

**⑤（附带）故意不 import `services/spot_draft.py`。**
那只文件今天还没上现网，import 它就把"本线只动四只文件"变成"必须跟另一路那批一起传"——
同一个坑在 `docs/版本与发布现状.md` 第三节记过（`main.py` 与那两只路由必须同批）。
所以"这一栏上现网"这句话现在只欠**本线四只文件**，不欠别人的批次。

## 四、屏上每一格念什么（左栏「数据 → 用量看板」，一栏一屏照旧）

**卡一「图麦笔记这一侧的调用计数」**（数据源＝`daily_usage`，一次都不出网）
- 今天已提炼（条）：`today / limit`，limit 现读 `limit_of()`＝50，不抄字面数；
- 今天已送检（次）：`today / 200`，副句念"几个账号在今天动过这一档"；
- 这 14 天合计（提炼／送检）：窗口按 `?days=` 走，缺的那天补 0（"三天没数"与"那三天没人来"得能分开）；
- 逐日那一表：三列（日期／提炼／送检），日期口径 UTC+08——与限额那句"明天再来"同一套日子；
- 卡头一句 ⚠：这张表**分不清验收号与真人**，所以数里含我们自己跑验收打的那些，看绝对值前先记住这句。

**卡二「RoamMark（iPhone 版）那一侧的 DeepSeek 余额」**（每次点开现读一次，上限 8 秒）
- 上游回的话：整句中文（`可用：CNY 共 11.02（赠金 0／充值 11.02）` 这个形状），副句念读取时刻（UTC）
  与"那条转发链此刻挂没挂在这台服务上"；
- 今天转发了几条景点初稿：`null` ⇒ 「这一档还没开始记」；有档 ⇒ 当日求和；
- 每一行余额一枚数：总额＋赠金／充值分列（两者同时在的时候官方口径先扣赠金，"会过期的那一部分"要看得分开）；
- 这一栏拿去打上游的那把钥：只有"有／没有"、长度、指纹，**值一次都不出去**；
- 那一行说明：官方只有查询余额一个口、没有按天用量／账单明细接口 ⇒ 不画曲线；token 明细只有 DeepSeek 控制台那一处；
- 一枚「重新读一次」按钮（这一栏自己重读，不牵动统计那八栏）。

## 五、三条纪律（缺一条这一栏就不该上现网）

1. **只读。** 这一栏不往 `daily_usage` 写一个字节：管理员看一眼余额既不是提炼也不是送检，
   记进去就把"真人今天用了多少"混进"我点开过几眼"。判据＝读余额前后行数与各行的 `updated_at` 逐枚相等，
   且库里不存在 `kind='admin_view'` 这种行。
2. **值只进不出。** 回体只有长度与指纹（同 `services/service_secrets.py` 第 1 条）；
   上游**非 200 时不转述回体**——那里面可能夹着账户信息，而这一栏的读者是浏览器。
   三条出口（回体、那一页 HTML、上游错误回体）用同一枚哨兵串扫。
3. **上游红了不许带走整栏。** `no_key｜timeout｜unreachable｜rejected｜ok` 五态各有各的 `sentence`，
   形状恒定；`httpx` 异常一律吞在这块里，小程序那一块照常出数。页面那一侧的红只有一句
   「这一栏没读到数：…」，`renderUsage`/`loadUsage` 里**不许碰 `#stats` 那个容器**（有用例钉）。
