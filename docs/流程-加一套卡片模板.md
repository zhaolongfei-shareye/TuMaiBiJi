# 流程：加一套卡片模板（2026-10-06 立）

一句话：**加一套新卡片＝往 `backend/seed/poster_extra/` 放一份 JSON**，`miniprogram/` 一行都不改、不出包。
规范（哪一层能动、十条硬规矩、负面清单）在 `docs/产品需求.md` §11，那份是唯一出处；这一份只讲**按什么顺序敲哪些命令**。

今天（10-06）这套流程的实况：`poster_extra/` 里只有一份**示例件**（`.example.json`，生成器按后缀跳过），
一条真数据模板都没有；整条链路一行都没部署。上面那两个把手的状态见 §11.4。

## 0. 哪三步需要你点头

| 步骤 | 为什么必须你点 |
|---|---|
| 第 2 步「看图」 | 判据全绿不代表图对（§11.2 第 4/5/6 条那三处毛病全是看了图才发现的），这一条机器代不了 |
| 第 4 步 开闸写库（`POSTER_TEMPLATES=1 bash deploy.sh`） | 这是整条流程里唯一往现网库里写东西的一步 |
| 第 4 步之后确认探针读数 | 探针只读，但它是唯一能证明"新那套真下发了"的读数 |

第 0、1、3 步全在本机，随时可撤（撤就是删那个 JSON 再重跑一次生成器）。

## 1. 写配方

```bash
cp backend/seed/poster_extra/模板-写法示例.example.json backend/seed/poster_extra/<你的模板id>.json
```

然后把里面**三处 id** 都换成同一个值（文件名、`template_id`、`recipe.id`）——三处不同名是那种"名字对、内容不对"的卡，
生成器、pytest、客户端闸门都会拦。字段：`label` / `label_en`（格子下面那两行字）、
`group_key`（只有 `classic`／`bold` 两档，界面那个分组名和括号里的数字自己跟着变）、
`sort_order`（包内那十套占 10～100，新的往 110 之后挑一个没人用的）、
`min_app_version`（只用现有十种 op + 三十条原语就写 `1.0.0`；写了 `1.9.27` 就是低于那个版本的包收不到这一套）。

配方才干条规矩照 §11.2 那十条走，其中三条最容易踩：**必须有一步 `let height`**、**不许写死颜色**（走 `token`／`scheme`／`paperOf`）、
**铺满整张的那张底色必须是第 1 层**（图层按数组顺序一张张贴，先画的被后画的盖掉，而这条判据全绿也看不出来）。

## 2. 跑流水线（两道关 + 三道护栏）

```bash
docs/工具/跑新模板流程.sh backend/seed/poster_extra/<你的模板id>.json
```

它按这个顺序敲，任何一道红就停：

1. **第 0 关（node，几秒钟）**：静态名单 → 下发闸门（`applyRemoteTemplates`）→ `recipeSource()` 读回 `remote`
   → 合并列表套数与新 id 位置 → 中英两份小样各跑一次 `planPoster(..., {strict:true})`
   → 高度合理、没有一层画到画布外、满铺底色打头。
   `strict` 不能省：非 strict 那一路跑不动会静默回退到 JS planner，"配方坏了"这件事就永远查不出来。
2. **三道护栏**（10-06 实测：第 0 关加这三道一共两三秒）：`验-模板配方等价.js`（480 组逐层指纹＝包内十套一张像素都不许变）、
   `验-模板配方可执行.js`（名单对齐、解释器、种子与盘上文件逐字节对账）、`验-模板配方下发.js`（整批合并、脏行整套丢、撤回当场消失）。
3. **第 1 关（模拟器）**：固定开销约 100 秒（`跑尺子.sh` 自己 quit + 重开 + `cli auto`），此后每套约 30 秒。
   `wx.request` 替身**只下发你这一条**
   （包内十套由 `templateList()` 自己并进来，不抄第二份），真进「我的 → 卡片模板」数格子，
   真从首页拿一篇真笔记当画芯（不自己造数据），真点那一格，轮询到 `picked` 对上且 `imagePath` 变了才搬图。

跑完它会把成品图路径和收尾两条读数打出来：

```
docs/design/新模板候选/新模板-<你的模板id>.png
```

全量日志在 `/tmp/ruler-出-新模板候选.log`。**红先分清是判据红还是环境红**：
`连不上 9431` / `MODULE_NOT_FOUND` 是环境红（端口没还、依赖被系统清了），不是你的配方坏了。

## 3. 看图（这一步没有命令，只有三句）

打开那张 PNG，逐块问：**这块该有字的地方有没有字**、**这条边是不是硬切出来的**、**这块颜色落在什么底上**。
第 0 关中英两份小样都在 node 里各跑过一次（那是规划层面：断行、字距、`fitSize` 全靠真 `measureText`）；
**画面上**这一趟出的是中文那一版。要英文版那张画面，先在「我的」里把语言切成英文，再跑第 2 步那一遍。
图不对就回去改配方，第 2 步整段重跑。

## 4. 进种子

```bash
docs/工具/跑新模板流程.sh --种子 backend/seed/poster_extra/<你的模板id>.json
```

它跑 `node docs/工具/出-模板配方种子.js`：种子那份 `backend/seed/poster_templates.json` =
**现读客户端代码的十套 + `poster_extra/` 里盘上的那几条**，`content_hash` 由配方现算（改了配方没重算 hash，
客户端那条"号没变就不重解析"就是假的）。然后复跑 `验-模板配方可执行.js` 与后端 `tests/test_poster_templates.py`。

**`poster_templates.json` 永远不许手改**——它是生成物。要改卡片就改 `poster_extra/` 里那份文件，再跑这一步。

到这一步为止，现网什么都没变：库里那一行还不存在，界面还是十套。

## 5. 上现网（§11.4，两步写库，都要点头）

```bash
bash deploy.sh                                # 只读体检：表、那条部分唯一索引、现有 live 条数
POSTER_TEMPLATES=1 bash deploy.sh             # 这一步才写库：先整批检查，全合格才逐行幂等落
.venv/bin/python probes/poster_templates_live_probe.py   # 部署完必跑（只读）
```

探针专抓那三种"部署漏了一半"的静默：404（客户端会把 404 咽掉、照画包内那十套，你会以为新模板生效了）、
响应行数与库里 live 行数对不上（表建了种子没灌＝空数组，现象与"只重启 worker 没重启 API"一模一样）、
每行八个字段与 hash 齐不齐。

## 6. 撤回来

**现网**（这一步是写库，要点头）：把那行 `status` 改成 `archived`，秒级生效、不发版，界面当场少那一格。
服务器上没有 sqlite3 CLI，只能走项目自己那个 venv：

```bash
cd /home/ubuntu/wtsj-backend && .venv/bin/python - <<'PY'
from app.db.database import SessionLocal
from app.models.poster_template import PosterTemplate
db = SessionLocal()
n = db.query(PosterTemplate).filter(PosterTemplate.template_id == '你的模板id',
                                    PosterTemplate.status == 'live').update({'status': 'archived'})
db.commit()
print('收了', n, '行；现在 live 有', db.query(PosterTemplate).filter_by(status='live').count(), '条')
PY
```

行不删——已经拿到过那份配方的老包要一直读得懂（`draft` 是另一档：不下发，用于"先在本地验"）。
**本机**更简单：删掉 `poster_extra/<id>.json` → 跑 `--种子` 那一步 → 种子回到十条。

## 7. 这套流程的边界（别拿它干这些事）

- 要**新画法**（第十一种 op）或**新排版原语**（第三十一条）：那是改 `poster.js`＝发版，不走这份流程。判据是 §11.1 那句
  "用现有十种 op + 三十条原语拼不出来"才允许谈。
- 要**下发代码／热更新**：官方一票否决（§11.5），这条路永远不开。
- 要**改包内那十套**的画面：那是 `miniprogram/utils/posterRecipes.js`，动它＝发版，而且 480 组等价基线会当场报红。
- `docs/design/新模板候选/` 里那两个演示件（`band`／`halo`）站长的口径是 10-05 那句**「不收」**，
  所以它们**没有**被搬进 `poster_extra/`，只当"这条路走得通"的证据留在原处。真要上新模板，从头写配方。
