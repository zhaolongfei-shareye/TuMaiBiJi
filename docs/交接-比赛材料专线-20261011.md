## 五、设计语言与自证方法（原 agent 踩过的坑，直接继承）

**配色只用官网三色**（源：`agentsbin.cn/assets/site.css`）：纸 `#F2EFE9`／墨 `#14161A`／陶 `#D2683F`，
另加纸卡 `#FBFAF7`、线 `#cfccc2`、灰填 `#E7E3D8`。

**插图是 SVG 线描**，class 约定：`.s`（描边 1.2）`.thin` `.a`（陶色描边）`.af`（陶色填充）`.cf`（卡面填充）`.pf`（白填充）`.gf` `.dash`；
文字 class `.tt .tn .tl .tm`；容器 `.il`（纸面板）+ `.ilcap`（图注）。**每张概念图都要标「概念示意」**。
箭头用每个 svg 自己的 `<marker>`，**id 必须在单个 svg 内唯一**（已用过的：m2／ar／arc／ar5／t1／t2／t3／t6）。

**SVG 布局五条已踩过的坑**：
1. 多条收敛曲线必须扇形分开、落到目标边不同的 y，否则会打结。
2. 回环／返回边不要终止在已经有前向箭头出发的那条边上，改从顶边进。
3. 浮动标签会跟贝塞尔曲线撞——分隔线的标签放在左端空处（anchor-start）。
4. 卡片内的字段标签放左、数据条放右，标签不要放到卡片右边框之外（会被切掉）。
5. `rotate(-90)` 的标签，x 要避开曲线经过的最大 x。

**渲染自证闭环（判据绿 ≠ 图对，必须用眼睛看）**：

```
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu \
  --no-pdf-header-footer --no-first-run --virtual-time-budget=20000 \
  --print-to-pdf=<绝对路径.pdf> "file://<绝对路径.html>"

python3 -c "import pymupdf; d=pymupdf.open('<绝对路径.pdf>'); [d[i].get_pixmap(dpi=80).save('/tmp/pg%02d.png'%i) for i in range(len(d))]"
```

然后用 Read 工具**逐张打开那些 PNG 看**。图的名字不等于图的内容。
