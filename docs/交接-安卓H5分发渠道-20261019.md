## 三、第 0 段＝现在就开工的那一段（零阻塞）

**范围**：`https://agentsbin.cn/app/` 一个**公开只读**网页版。
- 有：产品说明、笔记列表的**示例态**（可以是几篇虚拟笔记或后端现成的公开分享数据）、笔记详情阅读态、卡片成品展示。
- **没有**：登录、注册、发信、写入、支付、任何 `.env` 新键。
- 落点：`/var/www/agentsbin-cn/app/`（静态目录，走那枚现成的 `deploy-static-site.sh` 同形状发布）。

**验收判据（这四条全绿才算完）**：
1. 手机浏览器直接打开 `https://agentsbin.cn/app/` 出首屏，**不出现"请在微信中打开"**；
2. 证书链正常、无混合内容告警（页面里所有资源走 https）；
3. 首屏在 3G 模拟下可交互时间有读数（用 CDP 量，别用眼估）；
4. **对现网零写**：这一趟不新增任何写接口、不动小程序、不动后端路由——用 `git diff` 证明只加了静态目录与前端文件。

## 五、禁令（照 10-11 那份交接的写法，一条不许越）

- **不动小程序那 24,489 行**，不做 uni-app／Taro 迁移，不做 iOS 版。
- **不起新子域**（`h5.agentsbin.cn` 这类）——证书不覆盖，那要两趟现网写。
- **不往 `api.agentsbin.cn` 的 `/` 那一路塞东西**（它 proxy 到 `:8080`，是另一个项目）。
- 不在软著与 APP 备案齐之前上商店；侧载可以。
- 不引入手机号验证码；不接微信 APP 支付；不把 `hy3-preview` 改回 `hy3`。
- **凭据不进对话、不进 argv、不进 git**；`.env` 新增键必须落项目自己那份，且 `deploy.sh` 的少键自检同步加（10-13 那次丢三行导致提炼静默降级就是这条的代价）。
- 任何写现网的动作（deploy、`.env`、DNS、SES 控制台）要站长一句才动。
