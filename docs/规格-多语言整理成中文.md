# 规格：多语言原文 → 中文摘要（界面那枚「原文翻译」）

> 站长 10-15 18:3x 一句「把之前16国语言翻译的功能，整理一份MD给我」⇒ 本文件。
> **写之前先说清一件事**：这一条能力**不是"16 国语言翻译"**。产品里只有一处显式的"整理成中文"，
> 就是文字档那枚「原文翻译」开关；它管的是**提炼输出的语言**，原文一个字都不翻译、也不动。
> 本文件里每条断言后面都跟着出处；**没有读数支撑的地方一律写明"没有读数"**，不拿设计当已验证。

## 2. 三条录入路各自的语言行为（最容易说反的地方）

| 路 | 带不带这枚开关 | 给模型的提示词 | 结果 |
|---|---|---|---|
| **直接写**（贴文字） | **带** | 开＝`_LANG_ZH`／关＝`_LANG_KEEP` | 开→中文摘要；关→跟着原文语言走 |
| **贴链接** | **不带**（`None`） | 原始 `SYSTEM_PROMPT` | 模型自己决定，**不受这枚开关影响** |
| **拍照／截图** | **不带**（`None`） | 同上 | 同上 |

出处：`app/tasks/ingest_tasks.py:77`（链接）、`:121`（截图）都不传这个参数，只有 `:173`（直接写）传。
`app/services/llm.py:92-96` 那个 `system_prompt(translate=None)` 三档分流：`None` 回原样、`False` 加 `_LANG_KEEP`、`True` 加 `_LANG_ZH`。
**所以"链接和截图也走这枚开关"是错的**，`llm.py:83` 那行注释就是钉这件事的。

## 3. 提示词原文（两行，改字要同步改本文件）

```
_LANG_KEEP（关）：输出语言：标题、摘要、要点、标签都跟随原文的语言。原文是英文就写英文，
                 是日文就写日文，不要翻译成中文。
_LANG_ZH  （开）：输出语言：标题、摘要、要点、标签一律用简体中文写。原文是其他语言时先读懂，
                 再整理成中文。
```
`app/services/llm.py:84-89`。**注意它不是语言白名单**——提示词里没写"支持哪 16 种"，
只写"一律用简体中文写"。所以"支持 16 种语言"这个说法**不是代码给的**，是 10-14 那份探针的语料给的（见第 4 节）。

## 5. 边界与限制（这些是代码里读出来的，可当事实）

1. **正文 12,000 字截断**：`llm.py:114-117` 超过就切 12000 并追加 `[...内容过长，已截断...]`。
   ⇒ 长文／论文**不做完整总结**，这条同时是对外禁写项。
   ⚠ 同一个 12000 在云函数里又写了一份（`cloudfunctions/extract/index.js:16` 的 `MAX_INPUT = 12000`）——**两处各存一份真相**，改一处另一处不知道。
2. **入参上限**：`content` ≤ `MAX_BODY = 16000`（`app/api/routes/notes.py:48`），与内容安全送检窗口对齐（`wechat.py:28,34`：`2000 × 8`）。
3. **模型**：只走云函数 `cloud.ai()`，模型名 `hy3-preview`（`cloudfunctions/extract/index.js:15`，可用 `HUNYUAN_MODEL_ID` 覆盖）。
   全产品只用这一个模型（DeepSeek 已删）。
4. **降级不是失败**：云函数打不通时**照旧存原文**、任务不失败（`llm.py:110-111` 那句 `logger.warning` + `_degraded`）。
   10-13 那次现网就是靠探针当场捞出来的（`.env` 少三行 ⇒ 静默只存原文，当天 13:53 补回）。
5. **截图那条是"先认字再整理"，认字这一环另算**：OCR 是自建 RapidOCR（`app/services/ocr.py:1`，`PP-OCRv6_rec_small`），
   噪声过滤那一条按 CJK＋假名判（`ocr.py:31-33`）。**"只认中／英／日、韩文／西里尔／阿拉伯文返空"这句在仓库里也没有实测读数**
   （查过 `ocr.py`、PRD、监督记录）⇒ 同样不许当已验证事实写出去。
6. **生效时机**：这枚开关跟着**每一次提交**走，不是全局设置；存完归零。

## 6. 对外能说什么／不能说什么

- **能说**：贴外文原文、打开「原文翻译」，提炼出来的标题／摘要／要点／标签用中文写；原文照原样存着，随时切回来看。
- **不能说**：16 种语言实测通过（**没读数**）；任何国家／所有语言／全球资讯；论文一键总结（12,000 字就截断）；
  翻译原文（它不动原文）；链接和截图也吃这枚开关（不吃）；韩文／俄文截图能认（OCR 那半没读数）。
