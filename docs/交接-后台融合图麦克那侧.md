## 1. 对面要改的四步

行号是 2026-10-15 本机那份，**动之前按函数名 grep，别按行号跳**（那条线一直在改）。

| 步 | 改哪 | 改成什么 |
|---|---|---|
| **① 暗号** | `.env` ＋ 启动自检 | 加 `ADMIN_EXCHANGE_SECRET`（与我们同一个值，`openssl rand -hex 32`）。留空时换票口必须 **503**，不许"当没设=谁都能换"。 |
| **② 换票口** | `main.py`，紧挨 `@app.post("/admin/login")`（1286 那份）新增 `POST /admin/session/exchange` | ✅ **10-15 23:2x 已落码（对面仓库提交 `cea9b3f`，未部署、未重启容器）**。吃的就是下面那个契约：暗号先挡（不对就 401，**不往对面出网**）→ 打 `verify-token` → 用现成的 `_admin_session_token(sub, exp)` 签**自己的**票，`expiresAt = min(它的 24h TTL, 回体那个 exp)`。`_trusted_admin()` 与用户名＋密码那条口**一个字没动**。自测 `tests/regression/wtsj_exchange_test.py` 16 条全过（本机起一份图麦笔记后端，不打现网），两处变异各打红一条。 |

`_trusted_admin()`（`main.py:1181`）**一行都不用改**——它继续只认自己签的那枚票。这一步的关键就在这：对端不复制我们的判据、也不共用签名密钥，只在"进门那一刻"来问一次真伪。

## 2. 五条不许（越了就不是融合，是拆门）

1. **不许把 `ADMIN_EXCHANGE_SECRET` 或我们的 `JWT_SECRET_KEY` 写进前端**、`admin.html`、localStorage、URL。它只出现在"图麦克后端 → 图麦笔记后端"这一趟服务间调用里。
2. **不许在对端复制一份票的判据**（scope、`atk` 指纹、有效期算法）。复制了就会有"自己人打得开的票，换票口说它无效"那一天。
3. **不许让换进来的身份绕过钱那侧的审计**：`payments`／额度／模型配置那些口照旧逐口 `_trusted_admin`，`admin_users` 那套账号体系不许降格成共享口令（方案 §6 红线 1）。
4. **不许同表互查两个产品的用户数据**：融合的是入口与登录，不是数据池。图麦克的付费用户与图麦笔记的笔记／分享是两套对外隐私承诺。
5. **不许把回体里 `sub` 之外的东西当身份用**——它只有三个键，也不会再加。

## 3. 怎么算改对了（验收，逐条拿读数）

- 正向：我们的口令 → 换到它的票 → 用这枚票打它的 `/admin/dashboard` 应当 200。
- 反向三条，**少一条就是漏**：① 拿一枚过期票去换 → 401；② 拿一枚小程序用户 token 去换 → 401；③ **我们这边轮换 `ADMIN_TOKEN` 之后**，先前换到的那枚票在自然过期前**必须还能用到过期**（这是设计，不是漏洞——`atk` 指纹只作废我们这侧；要它立刻作废就得让对端每次打我们都验一次，那是二期的事，先说清别当 bug 改）。
- 应急通道：它的用户名＋密码登录照旧能进（融合不许把原来那条路堵死）。
- 暗号留空：换票口 503，且它自己那扇门照常开。
- 两边各部署一次（两台服务、两次 ssh），部署完跑 `docs/工具/探-现网后台融合.py`（口令与暗号走 stdin，不进 argv）。
