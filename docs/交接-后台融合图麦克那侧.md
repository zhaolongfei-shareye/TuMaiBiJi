## 1. 对面要改的四步

行号是 2026-10-15 本机那份，**动之前按函数名 grep，别按行号跳**（那条线一直在改）。

| 步 | 改哪 | 改成什么 |
|---|---|---|
| **① 暗号** | `.env` ＋ 启动自检 | 加 `ADMIN_EXCHANGE_SECRET`（与我们同一个值，`openssl rand -hex 32`）。留空时换票口必须 **503**，不许"当没设=谁都能换"。 |
| **② 换票口** | `main.py`，紧挨 `@app.post("/admin/login")`（1286 那份）新增 `POST /admin/session/exchange` | ✅ **10-16 已上线**（`cea9b3f` 落码 → `8977cf6` 改契约 → 容器重建）。⚠ `cea9b3f` 那一版写错了方向：它要**调用方**带 `X-Exchange`，而调用方是浏览器——那等于把红线 1 禁的东西发到前端去。现在这一版：**浏览器只交票，暗号只在这一台服务器上、只骑"图麦克后端→图麦笔记后端"那一趟**。判"来者是不是管理员"完全交回我们的 `verify-token`；暗号先挡那一步换成了**每进程 10 次/分钟**的闸（`_exchange_budget_available()`），因为没了暗号，任何人都能拿匿名请求把我们对面的 30/分钟额度打空——症状会是"操作者自己登不进"。空 ticket 那类不花出网的请求排在闸前面，不吃额度。签票仍是 `_admin_session_token(sub, exp)`，`expiresAt = min(它的 24h TTL, 回体那个 exp)`；`_trusted_admin()` 与用户名＋密码那条口**一个字没动**。自测 `tests/regression/wtsj_exchange_test.py` **28 条**全过（本机起一份图麦笔记后端，不打现网），七处变异各打红对应那一条。 |
| **③ 那一页** | `app/admin.html` 登录那一段 | ✅ **10-16 已上线**（`35c16ac`）。默认屏上只剩一个入口：一个口令框 → 打我们 `/wtsj/api/admin/login` → 拿到票再打自己 `/admin/session/exchange`。**两把各归各处**：它自己那把照旧进 `localStorage.adminToken`（这是它原来就在用的键与位置，不改——改了会把"刷新页面还要重登"这种老行为一起改掉）；我们那把进 `sessionStorage.opsSession`，**这正是 `/wtsj/ops` 自己读的那个键**，同一个标签页里登过一次，那边就不必再输第二遍。**反方向也通了**（`cc50ca2`）：从 `/wtsj/ops` 顶栏那枚「图麦克」跳过来，这一页开局看见 sessionStorage 里那张 `opsSession` 就自己去换一把自己的票，不再要第二次口令。报错话一律中文（那几口回的是英文 detail，抄上屏就成了中英夹着说）。**它自己那套邮箱＋密码的登录口保留**，收在「用图麦克本机账号登录」那一条链接后面，作为应急通道（红线 1）。 |
| **④ 登出** | 同上，登出那一下 | ✅ **10-16 已上线**（`cc50ca2` 修正过一版）。两把一起清，但**只清这一页自己写进去的那把**：落票时盖一枚 `opsSessionSetBy`，登出时拿当前那张票重算一遍指纹，对得上才删。第一版那枚戳写的是死字符串 `'admin'`，现网真点抓到它会连累后来那张新票——顺序是"这页登一次 → 回壳页、壳页自己又登一次 → 回这页点退出"，那一把不是这页写的，却被抹了。戳跟着票走之后这条不复现（判据 ⑦b 按真实顺序钉住，旧写法下它红）。 |

`_trusted_admin()`（`main.py:1181`）**一行都不用改**——它继续只认自己签的那枚票。这一步的关键就在这：对端不复制我们的判据、也不共用签名密钥，只在"进门那一刻"来问一次真伪。

## 2. 五条不许（越了就不是融合，是拆门）

1. **不许把 `ADMIN_EXCHANGE_SECRET` 或我们的 `JWT_SECRET_KEY` 写进前端**、`admin.html`、localStorage、URL。它只出现在"图麦克后端 → 图麦笔记后端"这一趟服务间调用里。
2. **不许在对端复制一份票的判据**（scope、`atk` 指纹、有效期算法）。复制了就会有"自己人打得开的票，换票口说它无效"那一天。
3. **不许让换进来的身份绕过钱那侧的审计**：`payments`／额度／模型配置那些口照旧逐口 `_trusted_admin`，`admin_users` 那套账号体系不许降格成共享口令（方案 §6 红线 1）。
4. **不许同表互查两个产品的用户数据**：融合的是入口与登录，不是数据池。图麦克的付费用户与图麦笔记的笔记／分享是两套对外隐私承诺。
5. **不许把回体里 `sub` 之外的东西当身份用**——它只有三个键，也不会再加。

## 3. 怎么算改对了（验收，逐条拿读数）

- 正向：我们的口令 → 换到它的票 → 用这枚票打它的 `/admin/dashboard` 应当 200。
- 反向三条，**少一条就是漏**：① 拿一枚过期票去换 → 401；② 拿一枚小程序用户 token 去换 → 401；③ **我们这边轮换 `ADMIN_TOKEN` 之后**，先前换到的那枚票在自然过期前**必须还能用到过期**（这是设计，不是漏洞——`atk` 指纹只作废我们这侧；要它立刻作废就得让对端每次打我们都验一次，那是二期的事，先说清别当 bug 改）。
- 应急通道：它的用户名＋密码登录照旧能进（融合不许把原来那条路堵死）。
- 暗号留空：换票口 503，且它自己那扇门照常开。
- 那一页真点过（本机桩后端）：`tests/regression/wtsj_exchange_page_check.mjs`，headless Chrome 真点——**23 条全绿**，
  含"页面加载不抛异常""默认只一个入口""口令错不落任何票""两把各落对地方""登出清两把""戳跟着票走、陈旧的戳不连累新票"
  "带着壳页那张票进来直接落地""换不到时留在口令框且说中文""应急通道照旧进得去"。
- **现网真点过（两个方向）**：`docs/工具/验-现网一次登录进两个后台.mjs`（口令走 stdin，不进 argv、不上屏）——**14 条全绿**：
  在 admin.html 输一次口令 → 两把落对地方 → 同标签页跳 `/wtsj/ops` 直接进壳页并读到数；反向在壳页输一次口令 → 点顶栏那枚「图麦克」→ 落地就是它的 dashboard；
  撤掉那张票，壳页立刻回口令框（钉住"它认的就是这一把，不是别处的缓存"）。屏照四张在 `docs/design/后台融合-自证-20261016/`。
- 两边各部署一次（对面容器重建两次、我们这侧第 29 次重启 `wtsj-api`），部署完跑 `docs/工具/探-现网后台融合.py`——**45 条全过**（对面那一段十一条在里）。
