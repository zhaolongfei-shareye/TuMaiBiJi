# 后台《用户隐私保护指引》填写文案

给谁用：微信公众平台 → `mp.weixin.qq.com` → 设置 → 服务内容声明 → 用户隐私保护指引 → 修改。

为什么必须先填再提审：平台原文是"仅有在指引中声明所处理的用户信息，才可以调用平台提供的对应接口或组件。若未声明，对应接口或组件将直接禁用"。也就是说不填的后果不只是驳回——发布之后相机、相册、剪贴板这三条功能会在用户手机上直接失效。体验版目前不受这条限制（1.1.2 那轮真机验过相机相册都通），所以这个雷是发布之后才炸。

**下面的清单是按代码里实际的调用点扫出来的，不是照着模板抄的。** 每一项都给了唯一调用位置，勾之前可以自己对一遍。勾选项的**文字**以后台实际列出的为准（微信这份枚举改过几次），按含义对，不要因为我这里写的名字和后台不完全一样就换别的一项。

---

## 要声明的四项

### 1. 摄像头 / 相机

用途说明（粘这段）：

> 用于「截图转笔记」里拍照识别文字的入口。照片只用于识别其中的文字，识别完成后不在服务器保存图片、不写入数据库。不需要此权限时，小程序其余功能（查看、搜索、编辑笔记）均可正常使用。

调用点：`miniprogram/pages/create/create.wxml:50`（`data-source="camera"`）→ `create.js:151` 的 `wx.chooseMedia({ sourceType: ['camera'] })`。

### 2. 选中的照片或视频信息（相册读取）

用途说明：

> 用于从相册选择截图进行文字识别。图片经 HTTPS 上传到我们自己的服务器，只在进程内存中暂存，识别完立即丢弃；超过 30 分钟未提交的批次自动作废。服务器不把图片写入磁盘、不存入数据库，也没有图片对象存储。

调用点：`create.wxml:55`（`data-source="album"`）→ 同一个 `create.js:151` 的 `wx.chooseMedia({ sourceType: ['album'] })`。

### 3. 相册（写入）

用途说明：

> 用于把生成的笔记卡片图保存到您的相册，方便您转发或留存。仅在您主动点击「保存到相册」时调用；拒绝授权不影响小程序其余功能。

调用点：`miniprogram/pages/share/share.js:423` 的 `wx.saveImageToPhotosAlbum`。

### 4. 剪贴板

用途说明：

> 读取：仅当您在新建页的链接入口点击「粘贴」时读取一次，用于取回您自己复制的网页链接。写入：仅当您点击「复制来源链接」或复制反馈邮箱、公众号名称时，把对应内容写入剪贴板。除这些您主动触发的操作外，不读取剪贴板。

调用点：读取 1 处，`miniprogram/pages/create/create.js:103` 的 `pasteUrl()`，只往链接输入框里填；写入 3 处，`pages/detail/detail.js:137`（复制这条笔记的来源链接 `source_url`）、`pages/about/about.js:159` 与 `pages/me/me.js:82`（两个同名的 `onCopy`，复制页面上 `data-value` 给的联系方式文本）。

## 明确不要勾的（我们确实不收集）

昵称、头像、地区、性别、手机号、位置信息、通讯录、运动步数、麦克风/录音、设备信息/IMEI、蓝牙、日历、通话记录、微信运动、发票、收货地址、车牌号。

代码依据：全项目扫描 `wx.getLocation` / `chooseLocation` / `chooseAddress` / `choosePoi` / `getPhoneNumber` / `createRecorderManager` / `startRecord` / `addPhoneContact` / `chooseInvoice` / `scanCode` / `getUserProfile` / `getUserInfo` / `chooseAvatar` / `requestPayment` **全部零命中**；`<button open-type>` 只用到 `share` 一种。

勾了用不到的项同样是审核风险（审核员会问"你声明了位置却找不到调用点"）。

## 其余必填字段

- **开发者处理的信息的目的、方式、范围**：写"提供把链接与截图整理成个人知识笔记的服务"，方式写"用户主动提交 + 服务端文字识别与大模型摘要"。
- **产品或服务提供者的名称**：与注册主体一致（个人主体填注册人姓名）。
- **联系方式**：填 `jacky28471258@gmail.com`，与「我的」页里显示的那个反馈邮箱保持同一个，别留两个不同的联系渠道。
- 若后台还要求填**个人信息保护专职部门或负责人**：个人主体没有这个部门，填注册人本人。

## 和小程序内文本的关系

小程序里「我的 → 关于图麦笔记 → 隐私」那一栏有十条，源码在 `miniprogram/pages/about/about.js` 的 `const PRIVACY`。那份是给用户看的，本文是给后台的，**两边口径必须一致**，否则审核员对照时会认为其中一份不实。已核对：关于页第 2 条「手机权限」写的正是相机、相册、剪贴板这三项，与上面要声明的四项一一对应（相册拆成读与写两项）；第 1 条写了"不收集通讯录、位置、麦克风、设备标识和浏览记录"，与上面「不要勾的」一致。

改动了后台的声明范围时，记得同步改 `PRIVACY` 那一段并重新出包。
