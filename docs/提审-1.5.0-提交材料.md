## 实际提交了什么（2026-09-27 11:53，agent 全程操作，已完成）

上面那份"要粘的文案"没有照粘——真到提审表单里，**版本描述那一栏默认装着 1.4.0 那五条**，上限 200 字，所以重写了一份 144 字的：

```
1. 外观设置重做：上面手机模拟预览、下面横滑壁纸条，点色块只试看，点手机才真正换上
2. 新增两套壁纸（象牙、天青），会连笔记列表左侧色块一起换色
3. 卡片图新增竖排模板「素宣信笺」；经典三款改名：玉版宣、摘句、叠翠
4. 修复：更换第二张头像预览不更新；深色壁纸下部分控件对比度不足
```

其余几栏：测试账号选的是默认那项「无需登录账号即可使用」（对的，微信授权登录、无注册无密码）；订单中心 path 留空（非交易类，那句红字提醒不适用）；用户隐私那栏保持「采集用户隐私」，指引四项没动；审核加急没点（额度已用完，提审页这次仍读到那句原文）。

**状态是从后台页面读回来的**：审核版本 `1.5.0`、`审核中`、提交审核时间 `2026-09-27 11:53:27`、审核说明"预计在 1-7 天内完成审核"。截图 `docs/提审-1.5.0-后台状态.png`。

**两处没做到、别当已验证**：① 版本描述**提交后没有回读入口**（「版本详情」只显示版本号/开发者/项目备注/两个时间），上面那份 144 字是点提交前从输入框读回来的，之后核不到落库值；② **小程序简介正文这次没读到**，所以"简介里是否还残留已下线的语音"这条**没核实**（缓解事实：1.4.0 就是带着现在这份简介过审并发布的）。

第②条当时记的原因是"那一页只渲染出页脚"，**这个诊断是错的，11:5x 之后回后台查清了**：公众平台的正文整个挂在 `<wujie-app>` 的 shadowRoot 里，顶层 `document.body.innerText` 永远只剩那 77 个字符的页脚，`take_snapshot` 也不穿 shadow 边界——读到"只有页脚"是读错了层级，不是页面没内容。穿进去之后回的是「请使用微信扫码」，那才是真原因：**后台登录态（或扫码二次验证）在这一步掉了**。要看一眼简介正文，得他重新扫码后进 设置 → 基本信息。


## 这一版和线上那一版的关系

线上现在是 1.4.0（2026-09-25 10:58 提审、已通过并发布）。**1.4.0 那个包里不含"换第二张头像预览不变"这条修复**（§8.42），所以线上目前仍有这个 BUG——这一版把它带上了。另外这批改动里撤掉的「界面字体」那一排也在 1.4.0 的包里（它两端真机都不生效），这一版一并撤干净。
