## 点哪里

mp.weixin.qq.com → 左侧「版本管理」→「小程序版本」→ 上半屏「开发版本」列表里找到 `1.5.0` → 该行右侧「提交审核」。

进去之后会逐条让你确认，按下面粘。最后一步「提交审核」点下去之前，页面会显示一个待提交清单，**别顺手点旁边的"加急审核"**——1.4.0 那轮实测读到过"当前加急额度已用完"，点了只会白报错。

## 提审之前还要瞄一眼的两处（都不是代码问题）

1. 后台「设置 → 基本设置 → 小程序简介」里**不能残留"语音"**。语音输入在 v2.1 就整体下线了，代码里 grep 零命中；但简介是后台字段，上次改过，这次进去顺手确认一下——简介里写着没有的能力，是会被按"实际功能与描述不符"驳回的。
2. 「设置 → 服务内容声明 → 用户隐私保护指引」那四项的状态应当仍是"已生效"。

## 提交之后

提交成功的那一页会把状态读回来（"提交成功，预计在 1-7 天内完成审核"之类）。**把那一屏截一张图**，或者把状态原文告诉我，我按原文记进 `docs/产品需求.md`，不猜。

## 这一版和线上那一版的关系

线上现在是 1.4.0（2026-09-25 10:58 提审、已通过并发布）。**1.4.0 那个包里不含"换第二张头像预览不变"这条修复**（§8.42），所以线上目前仍有这个 BUG——这一版把它带上了。另外这批改动里撤掉的「界面字体」那一排也在 1.4.0 的包里（它两端真机都不生效），这一版一并撤干净。
