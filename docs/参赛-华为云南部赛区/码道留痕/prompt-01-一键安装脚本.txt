项目背景：图麦笔记，一个微信小程序（原生小程序框架，JavaScript）＋ Python 后端（FastAPI＋SQLAlchemy＋Alembic＋pytest），后端现在跑在一台 Ubuntu 22.04 云服务器上，用 systemd 两个服务单元托管，仓库里已有 deploy.sh（重启＋五道自检闸门）和 upload.sh（整树上传）。图片走微信云开发存储，AI 提炼走云函数。

这次要你产出的东西（参赛包 readme/ 那一格里要用，只新增文件、不许改动仓库里任何一行现有代码）：

1. `install.sh` 一键安装脚本：
   - 同时支持 macOS（Apple Silicon）与 Ubuntu 22.04 两种环境，先判系统再走各自分支；
   - 检查 python3 版本与 venv 可用性，缺了要说清缺什么、给安装命令，不许静默失败；
   - 建虚拟环境、按 requirements.txt 装依赖；
   - 从模板生成 .env，键名逐个列出来，值一律写成占位符（例如 `<在此填入你的密钥>`），**绝对不许出现任何真实密钥、账号、AppID 或服务器地址**；
   - 结尾自动跑一次 pytest，并把结果条数念出来；
   - 每一步失败都要非零退出码＋一句人话说清为什么失败。

2. `README-deploy.md` 部署运行步骤：
   - 本地怎么起服务、怎么跑测试、怎么验证服务活着；
   - 现网那一侧：systemd 两个单元怎么重启、deploy.sh 里那五道闸门分别验什么、回滚怎么做；
   - 明确写出"哪些动作必须由项目所有者本人操作"（例如提审、发布、平台侧点击），不许写成脚本能自动完成。

3. `OPEN-SOURCE-LICENSES.md` 开源组件说明：
   - 从 requirements.txt 逐条列：包名、版本、许可证、在本项目里干什么；
   - 许可证拿不准的标注"需核对"，不许凭印象编。
