文件一 site_names.py（现状）：
```python
import re

MAX_SITE_CHARS = 20
_META_MAX_CHARS = 40
_META_SEPARATORS = (" - ", " | ", " _ ", " · ", "»")
_SUFFIX_WORDS = ("文章", "笔记", "网页", "网站", "页面", "客户端")


def _clean(raw) -> str:
    text = re.sub(r"\s+", " ", str(raw or "")).strip()
    return text if len(text) <= MAX_SITE_CHARS else ""


def _pair(zh: str, en: str = "") -> dict:
    zh = _clean(zh)
    if not zh:
        return {}
    return {"zh": zh, "en": _clean(en) or zh, "via": ""}


def _drop_mixed_name(raw) -> str:
    text = str(raw or "").strip()
    return "" if any(text.endswith(w) for w in _SUFFIX_WORDS) else text


def meta_site(raw) -> dict:
    text = re.sub(r"\s+", " ", str(raw or "")).strip()
    if not text or len(text) > _META_MAX_CHARS:
        return {}
    if any(sep in text for sep in _META_SEPARATORS):
        return {}
    out = _pair(text)
    out["via"] = "meta" if out else ""
    return out


def model_site(raw) -> dict:
    text = _drop_mixed_name(raw)
    out = _pair(text)
    out["via"] = "model" if out else ""
    return out
```

要重构的点（就这三条，别自己加）：
1. `meta_site` 里那行 `re.sub(r"\s+", " ", str(raw or "")).strip()` 与 `_clean` 是同一件事写了两遍，请抽成一个带长度上限参数的共用清洗；两处上限不同（20 与 40），不许并成一个常量。
2. `out["via"] = "..." if out else ""` 这两处同形，请收成一个"给结果盖来源章"的共用写法，但**必须保住那个不对称**：`model_site("网易文章")` 现在回 `{"via": ""}` 而不是 `{}`，这是盘上现读行为，用例钉死了，不许"顺手改对"。
3. `_drop_mixed_name` 只做"以那几个字收尾就整枚不认"，不许改成砍后缀，也不许把它挂到 `meta_site` 上（那道闸只属于模型那一级）。
