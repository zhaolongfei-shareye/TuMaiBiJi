## 二、怎么演示

1. 微信搜索小程序「图麦笔记」，或用体验版二维码进入（体验版需队长在后台把评审者加为体验成员——这一步只能人工在微信后台做，脚本做不到，也不该假装做得到）。
2. 后端服务与运营后台的对外地址不在本件里写，评审需要时我们单独提供并现场演示。

## 三、可演示的完整功能（均已在线上服务端生效）

| 功能 | 屏上表现 | 服务端事实 |
| --- | --- | --- |
| 链接转笔记 | 粘一条文章链接，几秒后出一条带标题、正文、配图、来源站名的笔记 | 支持形状按站点族区分（公众号正文与相册帖、微博 JSON 出口、小红书 `__INITIAL_STATE__`、搜狐、少数派等）；抓不到的走黑名单，不当成功回执 |
| 截图／照片转笔记 | 拍照或选图，滑条确认范围后出笔记 | 自建 OCR（rapidocr + onnxruntime），认不出字时降档成贴图笔记 |
| AI 提炼 | 右滑开始提炼，产出标题＋摘要＋标签 | 走云函数调混元；提炼失败不静默——降级为只存原文并如实标注 |
| 分享卡片 | 十套模板，左右滑切换，一篇一张码 | 模板配方存服务端，卡片图生成即上传云存储 |
| 扫码落地页 | 别人扫卡片上的码，浏览器直接看到这篇 | 匿名可读；「存入笔记」一键转存到自己名下（带图真复制一份） |
| 转存计数 | 列表上那枚星＝这篇有人转存过 | 服务端读 `invitations`，不是客户端本地数出来的 |
| 私密笔记 | 设密码后，锁着就不发正文与摘要 | 闸在服务端：不解锁不发内容；私密不能分享；改私密会关掉活码 |
| 分类管理 | 面板内增删、拖动排序、最多 8 格、名称最长 4 个汉字 | 分类名走词表翻译，不调模型 |
| 外观 | 四套界面壁纸＋五档彩色玻璃 | 心情只存本机，与壁纸对账后才生效 |
| 内容安全 | 违规内容当场拦下并说清是哪一张 | 文字九处＋图片送检；图片超 1 MB 先压；能自证有效的是"自家 OCR 取字→文字接口判"那条组合 |
| 运营后台 | 一处改，线上所有用户下次打开就变 | `/ops` 五栏已上线；Tips 与「关于」那段介绍都是后台配置 |
