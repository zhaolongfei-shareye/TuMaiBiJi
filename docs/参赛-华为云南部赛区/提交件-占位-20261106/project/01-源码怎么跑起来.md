# 这一格的源码怎么跑起来

> 对应赛题「提交作品」栏 project/ 那句「作品Demo，可演示完整功能」。
> 本目录里是**真在跑的三份源码**，不是裁剪过的演示壳。下面每一条都能在源码里翻到出处。

## 一、目录里有什么

| 目录 | 是什么 | 规模（现量） |
| --- | --- | --- |
| `backend/` | 服务端：FastAPI 应用 + 异步 worker + 数据库迁移 + 探针与测试 | 包内现量：应用代码 `app/` 1.5 MB、测试 `tests/` 1.3 MB、探针 `probes/` 0.6 MB |
| `cloudfunctions/` | 微信云函数三只：`extract`（AI 提炼）、`image_store`（图片直传登记）、`site_name`（来源站名） | 44 KB |
| `miniprogram/` | 小程序客户端：页面、组件、样式、工具、卡片模板引擎 | 约 1.9 MB |

## 二、服务端（backend/）

依赖与启动口径都写死在源码里，逐条出处：

- 依赖清单：`backend/requirements.txt` 钉版本（`fastapi==0.115.0`、`uvicorn[standard]==0.32.0`、`sqlalchemy==2.0.36`、`alembic==1.14.0`、`redis==8.1.0` 等）。
- 一键安装：`../readme/install.sh`（支持 macOS 与 Ubuntu 22.04；建虚拟环境、装依赖、生成 `.env` 占位、跑 pytest）。
- 配置：`backend/app/core/config.py` 里 `class Settings(BaseSettings)` 从 `.env` 读；模板 `backend/.env.example` 现量 31 只键（值全是占位符）。`DATABASE_URL` 缺失会在启动时直接报错而不是静默降级（`config.py:12` 默认空串，`:183-185` 空值即抛）。
- 数据库：默认 sqlite（`.env.example` 里 `DATABASE_URL=sqlite:///./tmbj.db`）；建表走 `python -m alembic upgrade head`（`backend/deploy.sh` 第 110–127 行）。
- 起服务：`cd backend && .venv/bin/python -m uvicorn app.main:app`，端口默认 **8000**（`deploy.sh` 第 17 行 `API_PORT=8000`）。
- 异步队列：worker 走 `rq worker default`（`deploy.sh` 第 10 行注释与第 534 行的进程识别口径），需要 Redis。
- 测试：`backend/tests/`，跑法 `pytest backend/tests -q`。

## 三、小程序客户端（miniprogram/）

用微信开发者工具打开 `miniprogram/` 目录即可，`project.config.json` 里已带 AppID。

两条需要提前说清的实话：

1. **登录与分享这两条链依赖微信开放接口**，在开发者工具模拟器里只能走通一部分，完整演示需要真机＋一个已备案的接口域名。域名与服务器地址不在本件里写，评审需要时我们现场提供并演示。
2. **云函数三只**（`cloudfunctions/`）要绑到微信云开发环境后上传部署才能生效；`extract` 那一只还依赖云侧的模型额度与 `.env` 里的密钥，这些是账号内资源，不能随源码分发。

## 四、这个 Demo 的边界（不吹）

- 源码里**不含任何密钥**：`.env`、`keys/`、微信小程序支付私钥、数据库文件全部没进包，包内只有 `.env.example` 那份占位模板。
- 不含 `.git` 历史、不含虚拟环境与 `node_modules`、不含内部设计文档。
- 语音录入已下线；海外网络环境不支持；HEIC 图片不支持；安卓独立 App 未上线。
