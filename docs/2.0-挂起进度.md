## 这一轮踩到的坑

- `wx.request` 默认 30 秒会把 60 秒的生图请求先掐断：前端看到"失败"，额度其实已经扣了。配图这条单独放宽到 90 秒
- `createShare` 每调一次就多一行分享记录，所以重画海报必须走缓存的 note/token/二维码，不能重新拉
- 沙箱与现网 AppKey 串用会得到 268490003 校验失败，因此订单行必须带 `env`
- 到账以 `query_order` 为准，`wx.requestVirtualPayment` 的 success 不算
- 测试进程必须 `XPAY_ENABLED=false`，否则一条用例就在打真凭据
- 测试建表走 `create_all`、线上走 alembic，两条路对不上时测试全绿而线上一条写入就炸——这就是 `deploy.sh` 要点名每张新表的原因
- `from __future__ import annotations` 会让 slowapi 的 `@limiter.limit` 读不到类型而崩，限流那条路由不能加它
