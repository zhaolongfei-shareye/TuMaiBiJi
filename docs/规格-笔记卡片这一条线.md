## 1. 功能规格

### 1.1 入口清单：屏上能出卡片的地方，一处都不许多

| # | 在哪 | 长什么样 | 点下去干什么 | 实据 |
|---|------|----------|--------------|------|
| 1 | 首页 · 详情窗右上那一格 | 有卡片＝那张缩略图；没有＝淡底方形 `+` | 拉起成品弹窗（模板能滑、名片能改、带不带码这一趟挑） | `pages/index/index.wxml` `.ds-entry` → `index.js onCardCell` → `_openPosterFor(note,'sheet')` |
| 2 | 首页 · 「笔记卡片」那一屏的格子小图 | 白垫里那张缩略图 | **直接拉那一张的大图**，不再先看原文（站长 10-04） | `index.wxml` `class="pad" catchtap="onCardTap"` → `_openPosterFor(note,'grid')` |
| 3 | 详情页（独立那一屏）右上那一格 | 同 #1，两态两画法 | 有那张→看大图（这一页没有画布，走 `wx.previewImage`）；没有→去 #4 那一页 | `pages/detail/detail.js onCardCell` |
| 4 | 笔记卡片页 `pages/share/share` | 整屏成品 + 底排「编辑个人名片」「保存到相册」 | 生成这一篇的第一张卡片；出图即记一笔台账 | `share.js onLoad` → `generateShareImage()` |
| 5 | 成品弹窗 · 已生成态底排三枚 | 通栏「分享卡片：微信好友 / 朋友圈 / 公众号」+「查看笔记」+「删除」 | 「删除」是这一篇**唯一**能重新出卡的口（删掉才能再生成；下面那句提示就是这句：「删除后可继续生成笔记卡片，已分享的依旧有效」） | `index.wxml` `.tpl-dock` `onShareCard`/`onViewNote`/`onDropCard` |

**不许存在的第二个把手**（这两处都已经被点名撤过，别再加回来）：

- 详情页底排那枚「生成笔记卡片」——10-07 撤（站长："生成后，不应该出现生成卡片的入口，很多余，为什么不干掉"）。
- 详情窗底排那枚「生成笔记卡片」——v22（10-03）撤，同一句理由："入口挪进右上这一格之后，同一件事不再有两个把手"。

**私密笔记**：右上那一格整块不渲染（两页都是 `.ds-rt` 上那条 `wx:if="{{!note.is_private}}"`），
服务端也不允许私密篇分享；#2 那枚小图点了走详情窗、不走大图（`_openPosterFor` 那一步会建活码）。

### 1.2 「一篇只留一张卡片」——判据只有一条

- **口径**（站长 10-03 定、10-07 报漏口）：无论有没有附图片，每篇笔记只能有一张卡片，**除非删了再生成**。
- **判据**：`utils/cardLog.js aliveFor(noteId)` ＝ 台账里有一条 **而且那张图还在**。四个消费者吃同一个谓词，
  不许再写第二份筛选：① 成品弹窗的已生成态（`posterHasCard`）；② 首页那一格画什么；
  ③ 详情页那一格画什么；④ 笔记卡片页那道闸（`share.js onLoad`）。
- **闸的位置**：必须排在 `generateShareImage()` 之前——那一趟第一件就是 `POST /api/shares/`（建活码）。
  挡晚了就等于"这篇不许有第二张卡片"和"这篇已经多了第二张活码"同时成立，而后者是写现网的。
- **图被系统清了、账还留着**那一态：算"没有"。那一格退回 `+`（不画一块白板），闸也不挡。
  台账记在本机 storage、图存在应用私有目录，系统清缓存能只清图不清账——10-03 模拟器实测到过这一态。

### 1.3 状态翻转的时机（10-07 漏的就是这一条）

| 什么时候 | 谁重读台账 | 屏上应当变成什么 |
|---|---|---|
| 从笔记卡片页生成完退回详情页 | `detail.js onShow → loadNote → detailCards: cardLog.aliveFor(note.id)` | 那一格当场从 `+` 翻成那张缩略图；屏上没有第二个入口 |
| 详情窗里出完那一张 | `index.js _openPosterFor` 现算 `posterHasCard`；收窗后 `_cardsOf` 重读 | 卡片那一屏的格子与详情窗那一格都换成新的那张 |
| 在成品弹窗里「删除」那一张 | `cardLog.dropNote(id)`（连文件一起撤） | 那一格退回 `+`，可以重新生成 |

### 1.4 开窗取数：正文每次现读，缓存只许留给码（10-07 真机报的那条）

- **站长原话**：「标题我已经改了，但生图时候还是旧标题。」（两张截图：详情窗里标题已是新那句，成品弹窗那张卡上还是旧那句。）
- **根因不在服务端、也不在编辑**：现读库里那篇 `notes.title` 已是新那句、`updated_at` 就是他改的那一刻；
  坏在 `pages/index/index.js _ensurePosterAssets` 原来一进来就 `if (this._posterAssets.noteId === noteId) return`，
  而 `_renderPoster` 画的是 `this._posterAssets.note`（同一份缓存里的 `token`/`qrPath` 也是它喂的）——
  **第一次开过那篇之后，改完标题回首页再开，画布照画缓存里那份旧字**。笔记卡片页（`pages/share/share.js`）没这个毛病，
  它每次 `onLoad` 现拉一次，所以症状只在首页这一层。
- **规矩**：**正文每次现读**（`api.getNote` + 那张分类表那趟）；**缓存只留给"码"**——`createShare` 与下载那张小程序码
  仍按 noteId 复用。理由不是省事：那一趟会往现网建/动一条活码，重开一次弹窗烧不起，也不该烧。
- 判据两层：静态在 `验-卡片那一格两页同源` §七（量的是**形状**——那次 `api.getNote` 之前一个 `return` 都不许有；
  反向⑤把老那句短路加回去必须红、反向⑥换成可选链绕字面也必须红）；
  运行时在 `验-成品弹窗现读正文-真跑`——**灌一份假缓存再开窗**，正文必须被真字换掉，而那两个假值
  （假 token、假码路径）必须原样留着，它们留着就是"`createShare` 没跑、这一趟零写现网"的证据。

### 1.5 这条线的已知代价（不要再当成 BUG 修）

- 台账在**本机**：换设备、清微信缓存、删掉小程序 → 这一格空了，闸也不再挡（同一篇能再出一张）。
  要跨设备得服务端加 `note_cards` 表 + 出图后上传 + 部署——**这条还没拍**（§4）。
- 成品图只存 JPEG 缩略那一份（`cardLog.copyIn`），发出去的 PNG 不留。

## 2. 设计规格（数值全部现读，改一边必须改另一边）

### 2.1 那一格有两画法，尺寸是同一套

| 件 | 数 | 出处 |
|---|---|---|
| 整列宽 | `252rpx` | `app.wxss .ds-rt` |
| 有卡片：白垫 | `252×352rpx`，圆角 `20rpx`，底 `#fff`，投影 `0 8rpx 22rpx rgba(8,10,14,.10)` | `app.wxss .ds-pad` |
| 有卡片：里面那张 | `232×330rpx`，`mode="aspectFit"` | `app.wxss .ds-pad-img` |
| ↳ 这组数的来历 | 逐寸按「笔记卡片」那一屏那枚白垫 `.pad 340×474` / `.pad-img 312×446` 乘 **0.7412** | `index.wxss .pad` |
| 一张都没有：淡底方形 | `176×176rpx`（吃列表那枚方块 `--blk` 的 176），圆角 `28rpx`，描边 `var(--w-edge) solid rgba(35,37,44,.10)` | `app.wxss .ds-swatch` |
| ↳ 底色 | **不是色号，是规则**：`palette.paleStep(当前壁纸)`，走 `style` 递进来，wxss 里不许写死 `background` | `utils/palette.js paleStep` |
| `+` 号 | `56rpx` / weight `200` / `rgba(35,37,44,.42)` | `app.wxss .ds-plus` |
| 左上角品牌 | 圆点 `28×28`、字 `16rpx`、底 `#23252C` 配 `#F2EFE9`；圆里那个字＝`poster.BRAND_GLYPH`（现网是「麦」）；品牌名 `18rpx`(`--fs-micro`) 字距 `1rpx` `rgba(35,37,44,.45)` | `app.wxss .ds-logo` / `.ds-logo-n` |
| 第一行小字 | `t.shareAsImage`＝「生成笔记卡片」，`24rpx`(`--fs-meta`) / 700 / `rgba(35,37,44,.9)` | `app.wxss .ds-e1`、`utils/i18n.js` |
| 第二行小字 | `t.noCards`＝「还没有生成过卡片」，`18rpx`(`--fs-micro`) / `rgba(35,37,44,.5)` | `app.wxss .ds-e2`、`utils/i18n.js` |

英文侧那两句是 `Make card` / `No cards yet`（字典里读，别在页面里写死中文）。

### 2.2 分栏（各页自己那份，格子必须一样）

| 屏 | 净宽算式 | 左列 + 缝 + 右列 |
|---|---|---|
| 首页详情窗 | `634 = 750 − 窗边 24×2 − .ds-in 内缩 34×2` | `358 + 24 + 252` |
| 详情页 | `638 = 750 − 容器 --sp-3(24)×2 − .hero-flat 内缩 --sp-4(32)×2` | `362 + 24 + 252` |
| 私密那一篇 | 右列不出 | 左列 `width:100%`（`.ds-hero.solo` / `.dt-hero.solo`） |

### 2.3 详情页底排（撤掉那枚之后剩下的两枚）

- `编辑`／`删除` 两枚等宽（`flex:1`）、`25rpx` / 700、`--chip-idle` 面、`--r-pill` 圆角、`white-space:nowrap`（英文不许折行）。
- 「生成笔记卡片」那枚连同 `.icon-btn.primary` 那条样式一起撤净——**不是**留着类名删按钮。
- 公开状态那一行照旧：左边「这篇已经公开，别人扫码能看」(`t.sharedNow`)、右边那枚动作是「撤掉分享」(`t.unshare`)，只有真公开着才出现。
- 详情页抬头**仍然不要色彩方块**（v4 那条口径没变），`hero-title` 是 `36rpx` / 800，这一轮没动它。

### 2.4 唯一出处（漂移就是从这里开始的）

| 什么 | 唯一在哪 | 不许在哪 |
|---|---|---|
| 那一格的样式 | `miniprogram/app.wxss` 的 `.ds-*` 十族 | `index.wxss` / `detail.wxss` 一条都不许有 |
| 那一格的处理函数名 | 两页都叫 `onCardCell`（绑定名同名，那一段才能逐字比） | 各绑各的名字 |
| "图还在才算有"这条判据 | `utils/cardLog.js aliveFor()` | 页面里自己 `accessSync` 筛一遍 |
| 淡底那格的色 | `utils/palette.js paleStep()` | 页面里自己算、或 wxss 里写死 |
| 品牌字 | `utils/poster.js BRAND_GLYPH` | 屏上直接写「麦」 |

## 3. 改动这条线必须过的尺子

```

node docs/工具/验-列表D2.js                  # 109 条：含台账倒序那条唯一的出处、两页共用开窗逻辑
node docs/工具/验-弹窗按钮不超四字.js
```

**要现网回体**（不连开发者工具，但得先去取一次真实回体；取法写在那把尺子的文件头）

```
node docs/工具/验-现网下发收得进.js          # 10 条：库里那十套客户端收不收、真在用它出图、480 组与基线逐组一致、反向两条（改数值要变、抬版本门槛要拒）

**为什么这一把不算多余**：现网探针查的是**服务端**那份名单，客户端另有自己那一份（`remoteRowProblems` + `appVersionOk`）。
两头都通才算通——中间对不上是**静默回退包内那一份**，画面看着对、下发其实没生效。读不到回体它退 3 报错，不许拿仓库种子顶替。

**真跑**（要先起自动化端口；每把之前重启一次开发者工具）

```
zsh docs/工具/跑尺子.sh 9431 验-详情页那一格-真跑   # 那一格两态真渲染、读数真从台账来、点两下各走对口、跑完原样放回
zsh docs/工具/跑尺子.sh 9431 验-成品弹窗现读正文-真跑 # 1.4 那条：假缓存里的旧字必须被现读换掉、码那两个假值必须原样留着（零写现网）
zsh docs/工具/跑尺子.sh 9431 验-一篇一张-真跑       # 闸挡在 POST 建码之前 + 图被清了不挡 + 反向对照

**跑的时候屏上要看对的四眼**（尺子绿了也自己扫一遍）：① 详情页右上有那一格、底排只有两枚；
② 生成一张之后退回详情页，那一格当场变成那张缩略图；③ 缩略图与点开的大图是同一套模板、带不带码也一致；
④ 换壁纸时那枚淡底方形跟着换档，不是一块近黑。

## 4. 还没拍的（不要自己补需求）

1. **跨设备的卡片台账**：要服务端加 `note_cards` 表 + 出图后上传 + 部署。现在换设备就"没生成过"。
   （建议：等这一条线的本机版真机上跑稳一轮再说，别和模板那条挤一批。）
2. **详情页那一格点了要不要也拉成品弹窗**：现在这一页没有画布，走的是 `wx.previewImage` 看台账那一张。
   **代价要说清楚**：走 `previewImage` 就只能用系统那个面板存图／发图，**这一页不再能直接"分享卡片：微信好友 / 朋友圈 / 公众号"**——
   要那三枚得回首页那格（详情窗或卡片那一屏）进成品弹窗。要统一成"跟首页那一格一模一样拉弹窗"，
   就得把画布那套（`poster` 渲染 + 台账记账 + 五枚面板）搬进详情页，或者把那一整层抽成一个共用组件。
   **这条是我按最小实现定的，他没拍过。**
3. **1.9.30 何时提审**（跟这一条线无关，记在这儿免得每次重问）。
